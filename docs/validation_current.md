# Aster 1.3.0-beta.20 验证范围

[详细记录](validation_results/1.3.0-beta.20/checks.json) · [文档记录](validation_results/1.3.0-beta.20/documentation_checks.json)

基础审查检查自动参数与按数据覆盖的关联路径，并整理现行文档；随后补充 Windows 窄面板布局修正。计算算法、默认值和数据库格式未改。基础审查的构建环境为 Linux x86_64、Qt 6.8.2、GCC 14.2、Release，启用收缩转换错误检查。

## 参数与输入关联

参数专项回归 783 项通过，联合输入相关回归 10 项通过，均无失败或跳过。QtTest 计数包含数据驱动用例及初始化、清理，不表示 793 个独立功能。范围包括：

- 未打开面板的数据仍使用确定的默认规则，运行时根据各自上游输出计算实际窗口与频率上限。
- 手动固定值、恢复默认后批量应用、尚未提交的键盘输入、切换数据及撤销重做。
- 同名数据按 ID 保持设置；分支隔离、输入替换、后加入数据、短输入失败与冻结运行请求。
- 逐点决定不跨数据广播；配对范围、删除后的失效身份、序列化与数据库重开。
- 预览和正式执行的实际输入一致；错误提示保持可读，旧预览失效后不展示旧参数摘要。

5000 输入批量操作检查同时核对数值缓冲共享，具体耗时见日志；它是本机单次测量，不是性能保证。

## 代码复用与文档

审阅参数编辑、工作流事务和预览/执行共用的有效参数路径。对项目 C++ 实现进行跨文件连续 80 个有效行的相同代码扫描，排除第三方源码，没有匹配；该扫描不能证明不存在所有语义相似代码，没有据此进行重构。

删除已完成的帮助精修计划，将仍有效的内容约定合并到文档维护；更新阶段计划改为当前更新模块契约。修复引用并清理用户指南中的对话式措辞。历史验证、科学参照、测试数据、许可证和第三方来源保持保留。

## 窄面板布局回归

[2026-11-17 验证记录](validation_results/1.3.0-beta.20/windows_layout_checks_20261117.json)。Windows 提交 `07ed6c11e7f1a6f1aaab553caddd1c8ae4eba128` 的完整日志为 2328 项通过、3 项界面断言失败，无跳过；算法、交叉谱及上一阶段异常退出的测试程序均通过。

修正输入操作按钮在窄面板下的挤压，以及样式面板中长按钮、复选框文字导致的横向溢出。文字随宽度换行，保留完整按钮文本、鼠标和键盘行为；文件行高测试使用列表字体及最小行高，等待主题切换后的布局更新。相关 C++ 模块重新编译后，完整 UI 测试 907 项、样式与导出测试 60 项通过，均无失败或跳过。环境为 Linux x86_64、Qt 6.8.2、GCC 14.2，Release 配置、`-O0`，不是 Windows 原生复验或性能测试。

新增范围包括中英文、10/14 磅字体、输入面板 220/270/340 像素宽度、样式面板四个标签页，以及换行后控件的点击、空格键操作和宽度恢复。QtTest 计数含数据行及初始化、清理，不能直接当作独立功能数量。

## 平台与验证边界

最新布局修正仍需 Windows/MSVC 原生回归及各平台最终程序包验收；GitHub 草稿上传、Gitee 写入与镜像匿名下载也需独立验收。排查 Windows 时可设置 platform=windows-x64、check_only=false、prepare_draft=false，使测试通过后直接继续打包。

更新下载与发布逻辑沿用 [beta.19 专项证据](validation_results/1.3.0-beta.19/checks.json)，未把其通过数量重复计入本版。没有重跑全部数值算法；大包吞吐、磁盘写满、原生字体/DPI 和 macOS Gatekeeper 仍未覆盖。
