## 下载与启动

**免安装，完整解压后即可运行。** Windows 双击 `Aster.exe`，macOS 打开 `Aster.app`，Linux 运行 `./AppRun`。请保留解压后的完整目录；下载步骤和各系统启动要求见[快速开始](../QUICK_START.md)。

<a id="overview"></a>
## 工作区与基本流程

Aster 用任务树组织数据处理与分析。任务页配置输入、连接步骤并查看输出预览；结果页浏览数据库中的完整运行记录、绘图和导出。

典型流程：选择数据源 → 核对坐标与采样 → 添加处理或分析节点 → 检查节点输出预览 → 运行流程 → 查看和导出结果。第一次使用可按[正弦信号示例](../QUICK_START.md)完成一次分析。

| 区域 | 用途 |
| --- | --- |
| 输入数据 | 选择文件、设置读取列与单位 |
| 即时预览 | 普通路径上方显示源数据，联合路径上方显示实际输入 A/B；下方显示当前节点输出 |
| 任务画布 | 组织任务、分支及数据连接 |
| 步骤设置 | 编辑当前节点的参数 |
| 任务目录 | 浏览或搜索可添加的任务 |
| 结果目录 | 筛选、打开和管理已保存的运行记录 |

面板间分隔条可拖动；侧边折叠按钮用于收起和展开面板。主题、语言及并行数据数在“设置”中调整。

<a id="inputs"></a>
## 文件与内置数据源

“输入数据 → 导入”支持 CSV、TXT、TSV、DAT 等分隔文本。一个序列需要 X、Y 两列；文件可以包含其他列。选择文件后核对分隔符、表头、列号和单位，再点击“应用到本文件”。列结构一致的多个文件可使用“应用到所选文件”。这些操作不改写原文件。

列表以状态灯显示文件状态，悬停可查看完整路径及状态。多文件输入执行相同的任务树；选择其中一份输入即可预览对应的处理过程。

“数据源”菜单提供正弦信号、合成轨道代理信号、ODP 数据及天文曲线。独立数据源不因导入文件数量增加而重复执行。ODP 记录的年龄/深度、代理指标与引用见任务帮助和结果的“来源”页；原始采样不一定等间隔。

X/Y 单位属于数据说明，不会自动完成单位换算。深度转年龄应使用年龄模型任务，不能仅把单位文字改成年龄。天文曲线与地质记录对比前，应核对时间单位、年龄基准和轨道解适用范围。

<a id="workflow"></a>
## 任务树与参数

从数据源开始，通过节点的后续或分支入口添加任务；也可在任务目录中双击或拖动任务。选中节点后，右侧显示参数。多个输出的任务应在连接时选择正确的上游输出，例如去趋势后的序列，而不是拟合趋势。

连接多个兼容输出时，选择窗口显示在来源节点附近。所有选项采用一致行高，默认输出以粗体表示；超过八个选项时可搜索并滚动浏览。悬停可查看完整名称，单击或按 Enter 确认，Esc 或点击窗口外取消。取消不会创建任务；仅有一个兼容输出时直接连接。

已有连线上的小“＋”用于插入步骤，也可将任务拖到该位置。要替换普通节点，右键选择“替换节点”，或把另一任务拖到节点上。确认窗口列出新步骤的输入及每个下游分支对应的输出，请核对数据含义；类型兼容并不代表科学含义相同。没有唯一对应输出时必须手动选择。新方法使用默认参数，确认后在步骤设置中调整；替换保留下游分支，插入保留原有节点。

确认前不会改动流程，取消保持原样；每次插入或替换可用一次撤销恢复。数据源、联合节点以及直接涉及联合输入/输出的连接暂不开放改写。插入需要为整个下游子树找到可用的逻辑网格位置，若无法放置会提示原因，不会删除其他分支。

参数有效时自动更新预览。步骤设置中的小数参数支持科学计数法，例如 `1e-15`；仍须满足该参数的范围。按 Enter 或 Tab 可确认输入，切换节点或运行前也会提交当前编辑。数值框只有主动点击或通过 Tab 聚焦后才接受滚轮调节；未展开的下拉框不因滚轮而改变选项。删除当前节点使用删除按钮或 Del，并核对确认提示中的影响范围。节点、连接、参数、导入文件列表、文件导入设置和数据配对支持统一撤销与重做，最多保留 100 次有效编辑。删除节点后撤销，可恢复其输入绑定和配对；移除配对成员后撤销，可恢复原数据身份。撤销不会还原磁盘上的文件内容，也不撤销已经保存的结果；请另行保留原始数据。运行期间不能编辑流程。

| 常见目的 | 任务选择与检查 |
| --- | --- |
| 清理重复坐标 | 排序与去重；检查合并策略是否符合数据含义 |
| 分析等间隔频谱 | 先检查采样间隔；必要时整理与重采样，再进行 FFT、Welch 或 MTM |
| 保留不等间隔采样 | 根据适用条件选择 Lomb–Scargle |
| 查看周期随时间或深度的变化 | 连续小波分析；先核对等间隔采样，再选择[功率计算约定](methods/cwt.md#conventions) |
| 去除长期趋势 | 比较原始分支与线性或 LOWESS 去趋势分支 |
| 年龄转换 | 建立或导入年龄模型，检查控制点和外推范围 |
| 时变周期结构 | CWT 或演化频谱；核对窗口、边界和显著性假设 |

详细参数、默认值与说明见[任务与参数参考](reference/task_parameters.md)。操作指南与参数参考跟随界面语言；缺少中文的条目使用英文。方法解释及适用限制见[科学方法目录](methods/README.md)。

## Welch 交叉谱与 A/B 配对

1. 在当前工作区准备待比较的数据，核对双方的 X/Y 列、横轴名称和单位。A、B 可以来自同一个上游节点、不同普通处理支路或不同数据源根节点，也可以是同一内置数据源的两个不同输出。
2. 在一条普通数据路径后添加“Welch 交叉谱分析”。如需预处理，先在 A、B 各自路径上完成。联合节点的树连接决定画布位置；实际计算输入以配对中的 A、B 为准。
3. 打开步骤设置中的“管理配对…”，添加并命名配对。点击 A 或 B 单元格（键盘可按 Enter），先选择来源节点，再选择该节点的数据与输出，点击“使用此输入”。节点序号对应画布节点的悬停提示；节点、数据与输出均可搜索，悬停可查看完整名称。两方选好后，确认配对窗口才会保存更改。同一个参考序列可以参与多组；来源节点、数据身份和输出端口完全相同的输入不能与自身配对；同一数据经过不同普通节点处理后的输出可以配对，完全相同的有序配对不能重复。
4. 在“预览配对”中选择一组。即时预览上方可切换 A/B，核对名称、单位和曲线；下方选择平方相干度、交叉谱幅值、相位等指标。画布显示这一组的 A/B 引用线；切换此处的配对只改变预览和引用线，正式运行计算所有已配置配对。
5. 设置段长、重叠点数、FFT 点数、窗及去趋势。默认段长 256、重叠 128；改变段长不会自动修改重叠，重叠点数须小于段长。至少需要两个完整分段；256 点输入可使用段长 128、重叠 64，形成 3 段。未构成完整段的尾部样本不参与估计。FFT 点数为 0 时采用段长，补零不增加原始分辨能力。
6. 点击“运行流程”，在结果目录打开配对名称对应的记录。普通上游/分支记录按数据保存；配对记录保存联合节点及其后续输出，并记录双方来源、参数及该配对所需的上游步骤。CSV 导出包含全部交叉谱列；PNG/PDF 导出当前选定指标及绘图样式。

矩形窗下，段内去均值或线性去趋势会移除直流分量，因此零频点的相干度和相位显示为未定义；这不表示计算失败。Hann 窗和非零频点不采用这一特殊规则。

对于原始采样位置不同的两条记录，分别设定相同的重采样间距仍可能得到不同的起点或长度。分析前应明确共同区间、相同起点及间距，并核对两条序列的实际 X 坐标；联合节点不会自动截取或插值。ODP 等内置记录的已发表年龄模型可能已含天文调谐，交叉谱一致性本身不能作为独立的天文成因证据。


A、B 必须等长，X 坐标严格递增、均匀采样，并具有相同的横轴名称与单位；对应坐标须在采样间隔的百万分之一容差内重合。程序不按行号猜测对应关系，不自动插值、换单位或转换年代基准。若坐标不一致，应先在联合节点之前明确整理数据。

各输出列与资源边界见[交叉谱方法说明](methods/cross_spectrum.md)。

平方相干度取值为 0–1，但这里不提供显著性阈值，不能将高相干度直接解释为统计显著。相位采用 `conj(A) × B`，沿数值递增的 X 轴解释；交换 A/B 会改变相位符号。年龄向过去递增时，不应直接套用时间向未来的领先/滞后解释。零功率下未定义的相干度或相位在数值表显示为 `—`、在 CSV 中留空，在曲线上不连线。

没有配对的数据不参与交叉谱，其普通分支仍可运行。移除被引用的节点或数据后，配对会标记为“来源已失效”，画布显示 A! 或 B!；在“管理配对”中重新选择，或撤销删除。重新导入同名文件不会自动替代原输入。取消配对窗口不保存修改；修改流程或数据后，已打开的选择窗口会关闭，需重新打开。预览与运行均读取当时的源文件，修改文件后应点击“重算”核对。运行前后仍需自行保存输入文件；批次清单不是源文件的字节副本。

beta 版建议使用独立数据库，并保留原库备份。含未定义值掩码的交叉谱表可由本版读取，但 1.1.1 无法读取这一表格格式。当前支持同工作区内跨支路和跨源根节点配对；不支持直接连接另一个已保存的运行批次，也不支持把联合节点及其后续输出再次配对。需要使用已保存结果时，可先将其导入为普通数据库数据源。

## 源数据、计算输入与节点输出预览

上方“原始数据”或“源数据”显示当前路径使用的数据源输出。多输出数据源跟随所选分支的连接；例如 MTM 接收 PT-ZB18a 的倾角时，上方也显示倾角。选中数据源本身时，恢复该节点上次浏览的输出，输出选择器控制上下两处显示，不改变已有的下游连接。一个数据源可连接多个使用不同端口的分支，因此返回源节点不会自动采用某个下游分支的选择。

下方“节点输出预览”显示画布所选节点的输出；输出选择器可切换功率谱、峰值表、曲线或热图等内容。相关背景和置信曲线可与主曲线合并显示。普通单输入路径的预处理结果在相应节点的下方预览中查看，上方显示源数据。联合分析路径的上方改为“计算输入 A/B”，显示所选配对实际传入联合节点的数据，包括已经完成的上游预处理。

选中“读取文件”节点时，预览显示导入的数据序列；选中分析节点时，显示该节点的输出。

预览在后台执行到当前节点，不写入结果库。大数据图形可能抽稀；显示的点数不等于参与计算的点数。“重算”重新请求预览，“适应”恢复绘图范围。返回任务页后，选择输入或节点可继续预览。

下游失败不会清除已经成功生成的源数据；下方显示失败步骤的诊断。若未出现预览，先检查所选节点、上游输出连接、输入文件和参数错误。科学方法可能输出表格而非曲线；应同时检查输出选择器和状态信息。

<a id="run"></a>
## 完整运行与结果

点击“运行流程”执行当前任务树并保存完整结果。完成后进入结果页。运行记录关联输入、节点参数、方法版本、输出及诊断信息；修改任务参数不会追溯改写旧记录，需重新运行生成新记录。

打开结果记录时，自动显示最后一个成功且可绘图步骤的默认输出；若只有表格，则显示最后一个成功步骤的表格。单击下方步骤可查看该步骤的默认输出。失败且没有输出的步骤显示诊断，已有图形保留。

相同输出已经打开时，直接选中并保留样式；新图默认放入新图页。可在“设置 → 默认投图位置”改为“当前图页”，当前页满四幅时新建图页。浏览或勾选输出不会改变默认输出或投图位置设置。

“步骤与输出”左侧选择一个步骤，右侧可跨步骤勾选多个输出；点击“已勾选”查看或取消，切换记录会清空勾选。勾选输出不改变投图目标。拖动分隔线可调整列表空间；点击“收起”扩大绘图区，再展开恢复原高度。

点击图页标签、子图标题或图形可选择投图目标，底部显示目标图页、子图及其记录和输出。

“添加绘图”按同一步骤的输出关系组合：频谱主曲线、背景、阈值与峰值标记共用子图；小波功率与影响锥共用子图。原始功率、尺度校正功率和显著性比值等不同含义的热图分别显示，其他输出保持独立。“更多 → 分别绘制”可逐个查看输出。

每页最多 4 个子图，超出时续建图页，总共最多 32 页。“添加绘图”按钮括号内显示将新增的图数，已有图保留。例如，全选四种小波热图和影响锥会新增四幅图，每幅附带影响锥。没有图形时也可直接添加。

“叠加到当前”始终使用提交时选定的子图，后台读取期间切换选择不会改变目标。普通曲线要求数据类型相同且 X/Y 单位兼容；同一小波步骤的影响锥可以叠加到其周期热图，已有辅助曲线不重复添加。不同物理量的热图不互相覆盖。不满足叠加条件时提示原因并保留原图。容量与组合规则见[绘图说明](ui/plotting.md)。“更多”还提供“新图页”和“替换当前子图（单项）”。普通数值表独立显示，交叉谱表在子图内切换指标。

普通曲线的 X、Y 单位文字均须一致；未填写单位的轴还须名称一致。叠加不自动换算单位，也不要求坐标范围接近或采样点数相同；使用前仍需确认物理量与坐标基准可比。

未主动缩放或指定范围的坐标轴，会在叠加成功后适应合并数据；已缩放、平移或手动设置范围的轴保持当前视野。点击“适应”可重新显示全部可见曲线。

右键“清空图像”保留子图位置和大小。选中空位、勾选输出后，点击“放入当前空位”可重新绘制曲线或热图；多项输出须能共用一个子图，原样式不保留。加载中或加载失败的子图不属于空位。清空图像不删除数据库结果。

子图布局可直接调整。三幅图默认上面两幅、下面一幅通栏；四幅图默认两行两列。鼠标移到子图间的间隙时显示分隔条，拖动调整比例，松手后更新图像，双击均分。窗口空间不足时可滚动查看。图例较多时也会保留足够的子图空间，不自动缩小字体或省略条目。

拖动子图标题调整位置：放到另一子图中央（包括标题中央）交换位置；放到其边缘时与它并排或上下排列；放到整个图页的外边缘时占满一行或一列。按落位预览放开鼠标，按 Esc 或拖到无效位置取消。标题右键菜单提供移到图页上/下/左/右、交换位置和恢复默认排布；恢复默认按子图的添加顺序排列。已手动调整的图页新增子图时，划分当前面积最大的一块，保留其他区域；删除子图时邻接区域补位。拖动只限同一图页。

移动子图保留数据、缩放、样式和已提交的叠加目标；切换图页保留布局与比例。布局仅在本次使用期间保留，不写入分析数据库。整页 PNG/PDF 使用当前排列与比例，单图导出占满页面；开始导出后再调整界面，不影响该文件的布局与样式。

CSV 与“用作数据源”位于右侧“导出”页，操作对象是当前浏览步骤的所选输出。输出列表的多选勾选用于绘图，CSV 按右侧所选输出导出。PNG/PDF 导出当前子图或图页，导出区分别标明操作对象。

浏览记录与选择图形相互独立，切换记录不会关闭已打开的图页。

删除来源记录会移除引用它的子图，并取消相关待完成的绘图操作；其他子图保留。

一个方法可能输出功率谱、背景、阈值、峰值表等不同数据。最先失败的步骤通常最接近问题来源；其下游未运行不能单独视为新的算法错误。

结果右侧的“绘图 / 导出 / 来源”分别用于样式编辑、文件输出和查看参数及数据引用。“绘图”中的“编辑对象”显示当前子图；未选择子图时，参数表不显示。

普通路径中，“并行数据数”限制同时处理的输入数量；关联联合批次中，它限制同时就绪执行的计算任务数量。默认值最多为 8 且不超过可用逻辑处理器数，已保存的设置会保留。大矩阵、CWT 或长序列占用较多内存时可降低并发。单任务内的线程行为由数值后端和方法决定。

<a id="plots"></a>
## 绘图、坐标与导出

鼠标停留在 X/Y 轴线、刻度或轴标题附近可查看提示：滚轮缩放该轴，拖动平移该轴；在绘图区操作同时调整两轴。“适应”恢复数据范围。

“绘图 → 坐标轴”顶部的 X/Y 选择器控制整页设置对象，滚动参数页时保持可见。两轴各自保留标题、范围、对数、反向、刻度与网格设置。指定范围时填写原始坐标值；对数显示要求正值，不会修改存储数值。

MTM 的“频率上限”以输入横轴单位的倒数填写。它会裁剪输出频谱、阈值曲线和峰值表，影响保存及下游可用数据；频谱估计、背景拟合和峰检测仍使用完整频谱。仅调整画面时应使用坐标轴缩放。输入框以数值 `0` 表示自动上限，旁边显示“0＝自动”；旧节点若沿用非默认比例，在上限框输入 0 并按 Enter 或 Tab 确认可恢复完整频段。窗口比例与频率上限是不同参数。

单击曲线采样点、峰值或热图格点可读取坐标；正频率可显示倒数周期。读数浮窗显示 8 位有效数字，“复制”保留当前取样值的完整数值精度；曲线颜色与线型标识帮助辨认来源。读数基于当前显示样本，抽稀预览不等于对任意原始数据点的精确查询。按 Esc、点击空白或调整视图可关闭读数。

| 导出 | 内容 |
| --- | --- |
| CSV | 所选输出的完整数值，不受当前视口裁剪 |
| PNG / PDF | 当前绘图与样式，受绘图显示预算和输出设置影响 |

结果图在首次显示及缩放、平移、调整大小后自动细化，热图下方标明当前网格精度。放大可查看更细的数据，平移不一定消除抽稀；概览可能遗漏小范围结构。自动色阶使用完整输出的范围，细化时保持不变。CSV 保留完整数值。

热图默认使用“彩虹”配色，可在“绘图 → 热图”调整配色、色阶和显示方式。CWT 周期热图及影响锥默认使用以 2 为底的对数周期轴，小周期在上、大周期在下；在“坐标轴 → Y 轴”关闭“反转方向”可改变方向。其他热图不自动反转 Y 轴。

预览、结果与图形导出共用默认样式。手动设置在图页打开期间保留，不改变数据库数值；关闭图页或退出程序后不恢复。“恢复默认”重置为当前版本的默认样式。小波影响锥、显著性轮廓和色阶的含义见[绘图说明](ui/plotting.md)与[统计限制](methods/statistical_limits.md)。

<a id="database"></a>
## 数据库、筛选与批量管理

结果保存在 SQLite 数据库。“设置”中的数据库路径决定当前结果库；切换路径不会复制或删除原数据库记录。通过“数据库 → 备份当前数据库…”生成备份，通过“合并数据库…”导入兼容的 Aster 结果库。合并时导入记录分配新 ID；不兼容的数据库无法合并。

结果目录的浏览选择与复选框勾选互不替代。筛选或分页不会清除已勾选记录。

| 操作 | 范围 |
| --- | --- |
| 全选 | 勾选全部筛选结果，包括未加载的页 |
| 取消勾选 | 取消当前筛选结果的勾选 |
| 清空全部 | 清除全部勾选，包括筛选范围外的记录；不删除数据 |
| 删除已勾选 | 删除勾选记录，须确认数量及筛选范围外的条数 |

可先全选，再通过筛选找到需要保留的记录并取消勾选，最后删除其余记录。执行批量删除前建议备份数据库。

<a id="shortcuts"></a>
## 快捷键

按键提示同时显示在按钮或侧栏把手的悬停说明中。下表使用 Windows/Linux 记法，界面提示按系统显示。

| 按键 | 操作 |
| --- | --- |
| F1 | 打开使用手册；设置窗口中同样可用 |
| Ctrl+, | 打开设置 |
| Ctrl+1 / Ctrl+2 | 切换任务页 / 结果页 |
| Ctrl+Shift+1 | 显示或隐藏即时预览 |
| Ctrl+Shift+2 | 显示或隐藏步骤设置 |
| Ctrl+Shift+3 | 显示或隐藏任务目录 |
| Esc | 关闭当前弹窗或清除绘图读点提示，具体操作取决于当前控件 |

三个侧栏快捷键仅在任务页生效；弹窗打开时，主窗口导航快捷键不触发。

<a id="help"></a>
## 查阅帮助

在主窗口按 F1，或使用“设置 → 使用手册”，可打开内置手册。参数旁的“?”悬停显示简短说明，点击定位到对应参数；方法标题旁的“?”定位到该方法。

手册支持返回、前进和当前页查找；输入搜索词后按 Enter，或用 Ctrl+F 聚焦查找框。内置页面离线可用。“在 GitHub 查看”打开对应在线页面；本地页面或章节缺失时也会打开在线对应位置。在线页面内容以仓库当前版本为准。

“设置 → 联系我们”打开作者与联系页面；“设置 → 许可证”离线显示版权、许可条款与源码获取说明。

<a id="troubleshooting"></a>
## 启动与故障排查

- 汉字显示方框：检查中文字体，Linux/WSL 安装方法见 [FAQ](../FAQ.md#linux-fonts)。
- Linux 窗口无法启动：检查 X11/XWayland、WSLg 与 xcb 依赖，见 [FAQ](../FAQ.md)。
- 绘图响应缓慢：分别检查输入规模、并行数、图形环境和显示预算；WSL 图形性能不能直接代表原生桌面性能。
- 参数或分析失败：先检查输入范围、采样、单位及最早失败步骤；保留参数与最小可复现数据。COCO 的深度单位、p 值为 1 和计算预算问题见 [FAQ](../FAQ.md#coco-units)。
- 更新：在设置中检查版本并下载完整程序包；本版不自动安装或替换程序文件。

反馈时提供 Aster 版本、平台、复现步骤、错误信息与必要数据；删除个人路径、访问令牌及不适合公开的数据。安装与运行问题的详细处理见[常见问题](../FAQ.md)，报告解释见[错误诊断](error_diagnostics.md)。
