# Aster 1.1.0 验证记录

本文件归档 **2026-11-04** 的验证批次，源码基线摘要与环境见 [结构化记录](validation.json)。以下计数和结论仅对应该批次，不表示后续同版本源码、全部平台或所有发行包均已重新测试。发布时须保留对应提交、程序包校验值、自动化日志和桌面验收记录，流程见 [发布维护](release_maintenance_zh.md)。

## 对应功能与检查范围

- 方法标题的帮助按钮跟随参数列表实际可见区域对齐，包含滚动条和复选框行。
- 数字编辑器补足最小文字留白；现有主题已提供留白时不重复增加。适用于设置、任务参数和绘图/导出数字控件。
- 设置窗口验证数据库时冻结待保存字段，避免验证期间改值却保存旧值；关闭窗口后忽略迟到的验证回调。
- 回归运行脚本识别 Windows `.exe`，统一日志编码，并保留多个 QtTest 测试类的完整统计。

并行数沿用已有用户配置。无配置时默认 `min(可用逻辑处理器数, 8)`，至少 1；可手动选择 1–32。原配置中的 2 不自动迁移为 8。

## 补充检查

- 峰值检测与 SciPy 1.17.0 的 900 组独立对照通过，覆盖随机数据、衰减尾部、平台峰、1e-150 至 1e149 的数值量级以及局部/全局突出度窗口。最小峰距为 1；有峰距竞争时 Aster 的优先规则有意不同，不以此宣称所有设置与 SciPy 等价。
- 19 项 qmake 配置分支检查通过，覆盖本地/环境路径优先级、带空格路径、Debug/Release/Profile 和缺失依赖；在 Linux 上模拟 Windows 条件，不等同于 MSVC 链接验证。
- 检查 JSON、Python、QRC 资源引用、界面翻译键及占位符；轨道数据工具 4 项测试通过。36 个英文方法/参数名称使用已有英文描述符作为回退，不是缺失界面文字。
- 回归脚本以本地 `.exe` 命名夹具验证文件发现、UTF-8 日志、多测试类统计及失败退出码；不是 Windows 原生执行。
