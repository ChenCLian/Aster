# Aster 1.3.0-beta.9 发布说明

本版集中处理演化谱默认设置、按数据解析自动参数，以及预览错误的可读性；同步更新相关中英文帮助。帮助窗口多级目录与全局搜索仍留待下一批。

- 新建演化 FFT 直接使用 20% 输入跨度、目标 500 窗口、4 倍 FFT、线性去趋势、矩形窗、逐窗归一化和功率平方根平滑显示，频率上限为自动。演化 MTM 默认值不变。
- 自动规则在每次预览和正式运行时按当前数据的实际上游输入解析；批量应用复制规则，未打开过参数面板的数据也有确定设置。手动固定值仍按固定值应用。
- 参数面板提供“恢复默认参数”，恢复当前数据／配对在本节点的默认设置；再使用批量按钮可统一当前流程的本节点。异常点的逐点决定保留，其他节点与流程不变。
- 兼容旧的固定窗口／步长／FFT 点数缺少模式字段的参数记录；已明确保存的参数保持原义，旧结果不会自动重算。
- 预览失败原因和处理建议放入图像区域，使用较大字号、自动换行、可复制文本及长内容滚动。
- 使用手册、功率谱说明、参数参考及程序内提示同步更新。预设的逐窗归一化会改变保存的功率，平方根及颜色插值属于显示设置。

完整验证范围见 docs/validation_current.md；本源码包不代表 Windows/macOS 原生程序包已经验收。
