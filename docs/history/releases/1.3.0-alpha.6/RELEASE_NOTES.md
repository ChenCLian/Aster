# Aster 1.3.0-alpha.6 发布说明

本版新增可编辑 Acycle LAH 风格预设、窗口比例/重叠率/FFT 倍数与振幅热图显示；左侧多选导入设置直接批量生效并提供操作帮助，右侧节点批量设置独立分隔并显示文件名。详细变更及实际验证见 [本版审查](REVIEW_CN.md)。


本次修复：样式/读取设置编辑器关闭时的失效回调；逐点决定提交后访问已释放节点内存的问题；批量读取设置绑定原数据身份；后台取消覆盖正在执行及排队的任务；结果目录服务在信号回调重入时保持顺序，并防止回调销毁对象后的访问。

**预发布版本** · Windows x64 / macOS arm64、x86_64 / Linux x64 · 中文 / English

Aster 1.3.0 提供按数据设置节点参数、数据树间移动、多坐标气泡，以及异常值识别与数值变换。MTM 峰值表增加 AR1、SWA 与 FDR 三态判定，便于 CSV 比较与筛选。当前为 alpha 预发布版本；各平台程序包以 [Release 附件](https://github.com/ChenCLian/Aster/releases)为准。

## 本版新增

- 节点参数按当前数据或配对独立保存；固定操作区可将当前节点的规则应用到全部数据，并支持整体撤销。逐点保留／排除决定不参与批量复制。
- 文件读取设置自动应用，批量操作按列号逐文件校验；支持将数据移动到已有或新建树，并单独选择是否复制处理步骤。
- 坐标气泡可保留多个、拖动及分别关闭；曲线线段附近的点击可吸附到实际采样点。提供“清除气泡”。
- 异常值支持 Hampel、全局 MAD、指定范围识别，默认仅标记，提供明确的排除与局部中位数替换及逐点记录；数值变换支持 ln、log10、asinh、tanh。
- MTM 峰值表以 1、0、-1 表示通过、未通过、未评估，覆盖 AR1 95%、SWA 95% 和 FDR q=0.05；图例简化名称，统计含义保留在方法帮助中。

同时改善数据移动后的定位与撤销／重做、坐标气泡的布局稳定性，并统一异常值图例名称。

## 本版兼容性

- 新版可读取旧结果，已有峰值表保留原列，不自动补算。新任务与按数据参数使用的新工作流元数据需要本版读取；请在旧版再次打开数据前保留备份。
- 数值后端与运行依赖未因本次功能变更增加。编译与打包仍须使用匹配的程序版本；打包成功不替代目标平台启动验收。
- 缺测区间与沉积间断不自动填补；异常值变换不构成显著性判据。

程序包免安装，完整解压后即可运行。启动步骤和系统要求见[快速开始](../../../../QUICK_START.md)与[常见问题](../../../../FAQ.md)。

## Welch 交叉谱与联合输入

- 在同一工作区内，将同一节点、不同普通分支或不同数据源的输出配为 A/B，支持多组配对、双输入预览及来源追溯。
- 提供交叉谱幅值、平方相干度、相位、实部/虚部及双方自谱；CSV 保留全部列、单位和未定义值。
- 双方须等长、均匀采样，具有一致的 X 坐标、名称和单位，且至少能形成两个完整分段。程序不自动插值、截取共同区间或转换年代基准。

本版不提供交叉谱显著性阈值，高相干度本身不代表统计显著。相位沿数值 X 递增方向定义，交换 A/B 会改变符号。配对步骤、参数示例与解释范围见[使用手册](https://github.com/ChenCLian/Aster/blob/main/docs/USER_GUIDE.md#cross-spectrum)和[方法说明](https://github.com/ChenCLian/Aster/blob/main/docs/methods/cross_spectrum.md)。

## 工作流编辑与预览

- 支持在连线上插入普通节点，通过右键菜单或拖放替换节点，并核对上下游输出连接。
- 节点、参数、导入设置及配对支持统一撤销/重做；输出和联合输入可搜索选择。
- 即时预览对应所选路径的源数据、实际 A/B 输入和节点输出；浏览预览不改变流程连接或计算参数。

## 结果浏览与绘图

- 选择记录或步骤即可查看默认输出；支持多图页、子图比较、兼容曲线叠加及空白子图复用。默认投图位置可在设置中调整。
- “添加绘图”按输出含义组合：频谱、背景、阈值和峰值共图，小波影响锥附于周期热图；不同物理量的热图分别绘制，已有图保留。
- 每页最多 4 幅子图，最多 32 页；可拖动标题调整排列、拖动分隔线调整比例，并按当前布局导出 PNG/PDF。
- 曲线和热图支持即时样式编辑、坐标读数及视区细化；CSV 导出完整数值。CWT 周期图默认采用对数坐标，小周期在上。

绘图样式和布局在图页打开期间保留，不写入计算结果数据库。预览、结果与图形导出使用统一的默认样式规则。详细操作见[绘图与导出](https://github.com/ChenCLian/Aster/blob/main/docs/USER_GUIDE.md#plots)。

## 演化频谱

演化 FFT 与演化 MTM 支持按实际频率输入上限（单位为输入横轴单位的倒数），并提供默认关闭的逐窗归一化选项。参数帮助说明窗口长度、移动步长与频率网格的换算关系，便于按研究尺度设置分析。热图继续默认显示清晰色块；历史流程与已有结果保持可读。

## 界面与使用体验

改善输出选择、面板空间分配、绘图操作和输入反馈，统一来源名称、提示文字及帮助说明，提高多数据分析与结果比较的便利性。

## 兼容性与功能范围

- 本版可读取旧版结果；**1.1.1 无法读取本版交叉谱表使用的未定义值标记格式**。使用预发布版前请备份原库，建议使用独立数据库。
- 已保存的数值、方法版本和参数保留原记录，打开旧结果不会自动重算。方法选项的显示名称调整不改写已保存参数。
- 联合节点及其后续输出不能再次配对；不提供任意节点互联或直接改写联合节点结构。使用已保存批次的结果时，须先导入为普通数据库数据源。
- 图页和手动样式不跨应用重启恢复；撤销不恢复外部文件内容，也不撤销已保存的计算结果。
