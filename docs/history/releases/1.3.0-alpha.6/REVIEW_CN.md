# Aster 1.3.0-alpha.6 修改与验证说明

本版基于已交付的 alpha.5 完整源码。

- 右侧当前数据改为文件名；批量设置用分割线、标题及作用说明区分。
- 删除左侧“应用到所选文件”按钮，改为多选后直接批量修改导入设置；新增 ? 快捷操作帮助与选择范围提示。不更改右侧节点参数。
- 批量修改按文件校验，保留格式不兼容文件；连续修改排队，捕获修改时的数据身份和选择，避免切换选择或删除重导入后的误写。
- 演化 FFT/MTM 新增窗口百分比、重叠率和 FFT 倍数输入，保留旧流程默认值。FFT 提供可编辑 Acycle LAH 风格预设。
- 热图新增振幅显示；归一化功率取平方根后为相对振幅。原始功率数据、平均谱、CSV 和探针读数不受绘图变换影响。

预设保留完整窗口边界，不自动重采样、不在时间两端补零；并非 Acycle 全部默认行为的逐点复刻。Windows/macOS 原生验收需要在对应平台完成。

## 实际验证

- 完整 Linux Release 与 ASan/UBSan 构建成功，启动及数值后端查询通过。
- Release：12 个测试程序，2185 项通过，0 失败、0 跳过。
- ASan/UBSan：9 个测试程序，1355 项通过，0 失败、0 跳过；执行路径未检测到地址或未定义行为错误。
- 数量包含 QtTest 初始化/清理及参数化数据行，两类运行分别计数。LeakSanitizer 因环境限制关闭。
- 版本文档 4 项、帮助生成器 7 项检查通过；双语参考同步 56 个任务、259 个参数。
- 真实主窗口在亮色和暗色主题下完成离屏渲染检查，确认文件名、独立分隔区、帮助入口与振幅预览显示正常。Windows/macOS 原生构建和人工验收未执行。

完整记录位于 `docs/validation_results/1.3.0-alpha.6/`。源码包含程序、测试和文档，不包含本机编译目录、临时数据库或临时渲染文件。
