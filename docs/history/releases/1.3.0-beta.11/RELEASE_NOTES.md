# Aster 1.3.0-beta.11 发布说明

本版针对近期自动参数、批量设置及帮助功能进行定向检查，修复批量操作中的参数保留问题，并加强来源校验。

- 修复恢复的节点将逐点保留／排除决定存放于基础参数时，批量修改普通参数可能丢失这些决定的问题。现有各条数据保留各自的有效决定，未来加入的数据不继承这些逐点决定。
- 批量应用与单条编辑统一校验来源数据／配对；拒绝已删除、空或属于其他流程的来源，失败不修改工作流和撤销历史。
- 补充同名输入重排、未访问面板、自动／固定参数混用、独立分支与流程隔离、保存重开、联合配对新增／删除及撤销重做测试。
- 检查自动规则对不同数据分别解析；短数据失败不会改写规则或阻止其他有效数据计算。补查快速切换数据后批量操作、帮助目录和检索。

本版不修改数值算法、任务默认值或数据库格式。测试范围见 docs/validation_current.md；本轮为新增功能及关联操作链专项检查，不替代原生平台发行验收或全软件 Debug。
