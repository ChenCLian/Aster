# Aster 1.3.0-beta.1 发布说明

本版进入 beta 测试阶段，保留此前完成的按数据／配对设置节点参数、流程内批量应用、输入列表多选操作，以及演化谱窗口／重叠率／FFT 设置和绘图振幅变换。

- 修复版本更新脚本漏改带 `v` 前缀的发布标签，避免文档中的标签与实际版本不一致。
- 同步 README、FAQ、中英文手册、参数参考和构建／发布说明；macOS/Linux Actions 在构建前检查版本及文档一致性。
- 加强 macOS/Linux 程序包的启动检查，排除开发环境库和插件路径的干扰。
- 纳入本版 Windows 大文件、取消、数据库回滚、重复操作和人工交互验收记录；详细范围见[验证记录](../../../validation_results/1.3.0-beta.1/checks.json)。

科学算法、数据格式和数据库 schema 未改动。请使用完整的新版本程序包，关闭旧程序后再更换；源码版本升级需要重新运行 qmake 并构建。

Linux CI 以 Ubuntu 22.04 为基线；macOS 分为 Apple Silicon 与 Intel，最低系统为 macOS 15，默认使用临时签名（未公证）。实际可下载的平台以发布页附件为准；本版源码检查不代表云端 Actions 或原生程序包已完成验收。
