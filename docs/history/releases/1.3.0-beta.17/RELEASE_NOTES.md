# Aster 1.3.0-beta.17 发布说明

本版完成轻量更新的第二阶段：在更新窗口内下载完整程序包，校验 SHA-256 后解压到新目录。不会覆盖当前程序、自动启动新版或删除用户数据。

- 有本平台下载信息时，显示包大小、来源和保存位置；旧 Release 没有下载信息时保留手动下载入口。
- 下载来源默认自动选择，可手动指定；自动换源始终从头下载相同版本、平台和 SHA-256 的完整包，手动指定来源不静默切换。
- 下载支持取消、超时和重试。校验失败不解压；目标目录已存在时不覆盖；完成后可打开新版目录。
- 使用 libarchive 统一读取 ZIP/tar.gz，检查路径、符号链接、包内版本与平台、启动文件和展开大小。保留 macOS/Linux 安全内部符号链接与执行权限。
- 新增下载信息生成工具，依据最终程序包生成 `Aster-update.json`，不需要签名私钥；各平台打包记录版本与平台。
- 源码构建新增 libarchive 依赖；同步现有 Actions 依赖安装与测试入口。草稿发布、Gitee 上传后核验及可独立查询的镜像通道索引留到第三阶段。
- 当前在线版本发现仍使用 GitHub Releases。尚未配置实际镜像来源，不把本地模拟下载测试视为线上更新已验收。
