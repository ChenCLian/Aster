# Aster 1.3.0-beta.5 发布说明

本次完成帮助内容 C3：平滑、去趋势、标准化、异常值、数值变换、滤波与包络。说明同时覆盖中文和英文，公共概念集中维护，参数面板保持简洁。

- 补充 14 个数据处理任务的使用条件、输出、单位、端点及失败处理。
- 纠正 LOWESS“保留原均值”的说明：加回拟合趋势的均值，而不是直接加回输入均值。
- 区分移动平均与 SG 的端点规则、LOWESS 邻域比例与物理跨度、标准化与谱归一化。
- 明确异常点手动决定优先于“仅标记”，局部中位数始终从本节点输入计算；解释逐点记录。
- 明确 Butterworth 单程截止与双向响应、带通边界与 Hilbert 包络的解释范围。

算法、默认参数、方法版本与保存格式不变。新版多级目录和全局搜索尚未接入 Qt。
