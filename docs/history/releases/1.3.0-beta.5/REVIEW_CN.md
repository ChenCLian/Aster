# Aster 1.3.0-beta.5 修改说明

本轮完成 C3 数据处理文档精修，覆盖 14 个任务。算法、默认参数、方法版本、单位处理代码与数据库格式均不变。

## 新增与完善

- 公共概念 `docs/concepts/data_processing*.md`：区分数值处理和绘图显示，解释邻域、缺口、边界、单位、去均值、Z-score、缩放和手动决定。
- 平滑与去趋势 `docs/methods/smoothing_trends*.md`：说明移动平均、SG、线性去趋势和 LOWESS 的输入、选择、输出和端点。
- 滤波操作 `docs/methods/filter_usage*.md`：补充 Butterworth 高低通、Gaussian／Taner 带通及 Hilbert 包络的频率设置、响应、边界和解释范围。
- 扩充 `docs/methods/outliers_and_transforms.md` 并新增英文对应页：补充参数生效条件、手动优先级、逐点输出、替换来源、定义域及尺度。
- 14 个任务及相关参数链接到对应长篇说明；同类参数共享公共主题。中英文离线资源、索引和用户手册同步，原有入口保留。

## 纠正的描述

1. LOWESS 保留均值实际为 `y−trend+mean(trend)`，旧帮助误写成加回输入均值；已修正双语提示与生成参考。
2. Butterworth 低通保留常量基线，不保证任意有限记录的样本均值完全不变；双向截止幅值为 0.5，功率比例为 0.25。
3. 异常值“仅标记”并不会取消手动排除；手动决定优先。中位数替换始终基于本节点输入邻域，不逐点迭代替换。
4. SG 与移动平均的端点规则不同；LOWESS 比例按点数确定基础邻域，不是物理跨度。窗口和阶数并非越大越好。
5. 数值变换输出无量纲；缩放不自动改写单位标签。tanh 在浮点计算中可以饱和到 ±1，不能承诺严格落在开区间。
