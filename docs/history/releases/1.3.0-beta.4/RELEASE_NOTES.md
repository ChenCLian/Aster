# Aster 1.3.0-beta.4 发布说明

本次完成帮助内容 C2：窗口与重叠、FFT 补零、频率和功率单位、演化谱归一化及热图显示，并调整帮助目录中的泛化措辞。

- 新增中英文公共参数说明和 FFT／Welch／演化 FFT／演化 MTM 操作说明，相关参数跳转到共用章节。
- 区分分析窗口、平滑邻域和窗函数；说明整数步长、目标窗口数、百分比窗口及尾部未覆盖样本。
- 区分 FFT 频率网格与实际分辨能力、PSD 与信号振幅、逐窗归一化与仅改变颜色的显示设置。
- 补充跨软件热图比较顺序，以及频带裁剪对输出网格和主要计算量的不同影响。
- 将热图“振幅”选项明确标为“功率平方根”，避免误认为原信号振幅；保存的计算值不变。
- 演示目录采用“频谱与时频分析”，当前手册入口统一为“方法说明”；保留必要的专业术语、引用与历史记录。

算法、默认参数、方法版本与结果格式均不变。多级目录与全局搜索仍未接入 Qt 窗口；本次更新现有离线帮助内容。
