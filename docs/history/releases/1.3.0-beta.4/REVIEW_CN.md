# Aster 1.3.0-beta.4 修改说明

本轮完成 C2：窗口、FFT、功率谱及显示说明，并整理目录和界面措辞。算法、默认值、方法版本与结果格式保持不变。

## 内容与名称

- 新增中英文公共主题 `docs/concepts/spectral_parameters*.md`，解释分析窗口、平滑邻域、窗函数、步长与重叠、FFT 补零、频率／PSD 单位、归一化和显示。
- 新增中英文任务指南 `docs/methods/power_spectra*.md`，覆盖整段 FFT、Welch、演化 FFT 与演化 MTM，补充输入要求、选择顺序、输出、边界、错误和资源限制。
- 修正百分比窗口的描述：当前换算得到整数点数，100% 对应 N−1 点；要用全部 N 点请使用点数模式。频带裁剪减少输出网格，不降低每窗 FFT 长度及主要预算乘积。
- 参数参考跳转到同一公共主题；原有手册入口和参数锚点保持可用。四个新文件已加入离线资源。
- 演示目录“科学分析”改为“频谱与时频分析”；文档总入口改为“方法说明”。保留“科学计算”等明确术语，不改历史证据或文献题名。
- 热图“振幅”显示标签改为“功率平方根”，说明它不等于原信号振幅。绘图变换及保存数值完全不变；中英文同步。
- 用户手册保留简洁操作指引，辅助解释移至公共主题，避免增加参数面板负担。

## 版本与交付

版本推进到 1.3.0-beta.4，更新公告和版本标记同步，beta.3 发布说明归档。仅提供以 beta.3 为基线的增量补丁；外层 PATCH_README／PATCH_MANIFEST 供阅读，项目文件单独放在 patch/。

仅将 patch/ 内的内容合并到源码根目录，再运行 qmake 并构建；仅覆盖文档不会更新已编译的离线帮助。新版多级目录与全局搜索仍为设计稿，尚未接入 Qt。
