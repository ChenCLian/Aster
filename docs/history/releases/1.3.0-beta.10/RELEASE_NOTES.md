# Aster 1.3.0-beta.10 发布说明

本版完成内置帮助窗口的目录与检索改造，并保留此前默认参数与预览提示修订。

- 左侧提供可折叠的多级目录，按快速入门、软件功能、通用概念与参数、常见问题与排查、关于与引用组织；章节从现有文档生成，公共说明继续集中维护。
- 新增全部内置帮助的离线全文搜索，支持正文、标题和参数标识，不区分大小写，多个空格分隔的词共同匹配。结果定位到章节；当前语言已有译文时不重复列出另一语言版本，未翻译资料在英文界面标明中文。
- 页内查找独立放在正文区，提供上／下一处、匹配数量与循环查找；Ctrl+F 打开页内查找，Ctrl+Shift+F 聚焦全文搜索（macOS 使用相应 Command 快捷键）。
- 返回／前进保留阅读位置；主页仍返回使用手册。参数帮助入口展开并选中对应目录章节，正文上方显示所在目录。
- 搜索索引分批建立，清空查询可回到目录；关闭窗口会停止尚未完成的搜索工作。
- 中英文使用手册、分类索引和维护说明同步更新。本版不修改算法、任务默认值或数据库格式。

完整测试范围及未覆盖平台见 docs/validation_current.md。程序内帮助需要重新编译后更新；源码包不是原生可执行程序包。
