# Aster 1.3.0-beta.16 发布说明

本版完成轻量更新方案的第一阶段：更新窗口重新设计。下载与自动解压、双来源选择和 Actions 发布同步尚未接入。

- 查询结果集中显示，区分正在查询、发现新版、没有更高版本、暂无发布、取消和错误；窗口首次显示时检查一次，关闭后停止请求。
- 正式版与 Beta 分开查询；默认选中当前版本所属通道，Alpha 不参与在线检查。
- 更新说明支持 Markdown 标题、列表和折叠详情；禁用远程图片、本地文件资源和自动打开链接。
- 精简仓库信息，将错误代码及完整网址放入可展开详情；中英文和明暗主题保持一致。
- 本阶段“前往下载”仍然打开官方发布页，用户手动下载完整包。不存在独立安装助手，不会覆盖当前程序目录。
- 后续阶段：官方 HTTPS + SHA-256 校验，解压到新目录；再完善 Actions 草稿发布、截图检查及 Gitee 同步。
