# Aster 1.3.0-beta.16 更新说明

本版完成轻量更新方案第一阶段：重做更新窗口及其查询交互。正式版/Beta 分开显示，查询结果更醒目，公告支持折叠，错误详情默认收起。Alpha 不进行在线检查，“联系我们”仍打开内置作者页。

本阶段“前往下载”只打开官方发布页。下载校验与解压将在第二阶段接入，Actions 草稿发布和 Gitee 同步为第三阶段；不包含安装助手或自动覆盖旧程序。

[实施计划](../../../development/updates.md) · [验证记录](../../../validation_current.md)

Linux 构建和定向测试已通过；Windows/macOS 原生验收与远端发布尚未执行。无需为了这一阶段立即重做完整发布，可待三个阶段完成后统一验收。
