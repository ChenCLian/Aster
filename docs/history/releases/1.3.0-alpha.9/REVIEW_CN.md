# Aster 1.3.0-alpha.9 代码检查与修复

本轮修复三处问题：大批量修改导入选项时，捕获选择和提交结果会对每个文件重复扫描数据列表；批量移除同样反复扫描列表；窄输入栏的文件计数挤压英文操作按钮。现在导入设置采用一次扫描建立索引，移除采用集合筛选，计数与按钮分行显示。科学算法及其数值结果未改动。

## 实测结果

| 操作 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 10000个小文件，输入单位直到全部提交 | 23.72秒 | 0.554秒 |
| 上述操作中的输入事件处理 | 10.91秒 | 32.2毫秒 |
| 移除10000个文件 | 274.7毫秒 | 58.4毫秒 |

同一Linux环境单次前后样本，不能视为其他机器上的保证。100/1000/10000文件均正确提交，无跳过。取消任务本次约2.26毫秒后返回；256×1024热图连续切换100次，中位耗时5.70毫秒、p95为7.07毫秒，原始数据哈希保持一致，RSS采样保持48948 KiB。稳定RSS不等同于已排除泄漏。

固定窗口演化谱分别测试1001、10001、100001点。高重叠率预设在两个较大输入上按既有计算量限制返回EVOLUTION_BUDGET；这是保护路径测试，不能把拒绝耗时当作计算耗时，也未放宽保护。

## 验证范围

- 完整Release构建成功，版本输出正确；12个C++测试程序共2188项通过，0失败、0跳过（含Qt初始化和清理）。
- 完整UI套件在AddressSanitizer/UndefinedBehaviorSanitizer下878项通过；未启用LeakSanitizer。本轮未重跑其他消毒器套件。
- 新增真实Qt控件键鼠事件检查：Ctrl+A、Ctrl取消选择、Shift多选、输入后立即切换文件、同名不同目录、移除、撤销/重做、后台校验期间外部改动的冲突保护。Qt离屏事件不等于Windows系统级输入验收。
- 9项版本更新、4项当前版本、7项帮助生成检查通过；双语56项任务/259项参数参考同步。主窗口中英文浅色/深色离屏渲染检查及270像素窄侧栏回归通过。

仅src/ui/panels/source_panel.cpp发生应用源码变更，其余src文件与上一版逐字节一致。性能工具、运行命令和原始JSON一并提供，见tools/performance/README.md和本版validation_results目录。

## 后续检查顺序

1. Windows原生：使用真实鼠标键盘检查Ctrl/Shift多选、中文输入法、125%/150%/200%缩放、窄窗口、对话框焦点和取消后关闭窗口。
2. 长时间混合操作：反复导入、修改、运行、取消、保存、重开和导出，结合原生内存分析；另测大文件读取与慢磁盘。本轮10000文件测试用的是每份4行的小文件。
