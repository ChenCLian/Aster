# Aster 1.3.0-beta.3 修改说明

本轮完成帮助文档精修 C1：采样检查、排序去重与重采样。所有算法、任务默认值、方法版本和数据格式保持原样。

## 内容修改

- 新增 `docs/concepts/sampling.md` 与英文对应页，集中解释 X／单位、重复坐标、间隔、插值、大间隔和三种数量限制。多任务通过链接复用正文。
- 新增 `docs/methods/preprocessing.md` 与英文对应页，说明三个任务的使用顺序、输入、输出、参数取舍、端点和失败处理。明确“不重采样”仍整理数据，插值不会自动避开大间隔，网格末点不一定等于原数据末点。
- 修正“明细表最多 4096 行”的歧义：统计检查完整输入，两张明细分别保留按顺序遇到的前 4096 行；截断内容不能靠导出恢复。预览显示预算单独说明。
- 补充任务专用的中英文参数帮助，不改变同名参数在其他任务中的通用短提示。参数参考仍从任务描述和语言资源生成。
- 在参考页加入可选的 `referenceguide` 链接，方法和参数均可进入离线长篇说明。已有方法／参数锚点不变；新增文件已加入 `resources/help.qrc`。
- 将每条数据参数与异常值章节提升为独立章节，避免误归入演化谱；明确实际计算摘要位于下方节点输出预览选择框与图像之间。

## 版本与交付

版本通过现有脚本推进，当前文档版本标记同步，上一版发布说明保留在历史目录。本轮没有实现 B 阶段的多级目录或全局搜索，现有帮助窗口继续可用。

补丁说明和文件清单位于包外层，实际项目文件置于 `patch/`。将其内容合并到 `Aster.pro` 所在目录后，重新运行 qmake 并构建。该包不是完整源码，也不是可直接启动的程序。
