# Aster 1.3.0-beta.3 发布说明

本次为帮助文档精修的第一批，集中说明采样检查、排序去重和重采样，让参数帮助能回答“何时使用、怎么选择、怎样理解输出”。

- 新增中英文公共主题“采样、重复坐标与插值”，多个任务及参数跳转到同一处解释。
- 补充三个任务的操作顺序、参数选择、网格端点与数据空缺处理；明确“不重采样”仍会排序和处理重复坐标。
- 区分完整输入统计、输出明细截断和绘图预览抽稀；明确 4096 行不是只分析 4096 个样本，导出也不能恢复计算阶段未保留的明细。
- 修正手册章节层级，将每条数据的参数和异常值处理恢复为独立章节；明确实际计算参数位于下方节点输出预览区。

算法、默认参数、方法版本、数据库和已保存结果格式不变。帮助窗口的多级目录与全局搜索仍为设计方案，本次未接入。其他科学方法及全部参数说明将在后续批次继续精修。
