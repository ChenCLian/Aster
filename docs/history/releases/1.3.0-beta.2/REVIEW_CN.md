# Aster 1.3.0-beta.2 修改与验证说明

本版为相对原 beta.1 的累计源码补丁，同时适用于已应用画布补丁或唯一连接补丁的 beta.1 源码。

## 本轮实际修改

- `src/processing/evolutionary_tasks.cpp`：FFT／MTM 新增目标窗口数步长模式，整数向上取整使完整窗口数量不超过目标；保存请求数量与实际参数。过低目标会给出最小可行数量，保留既有数值核心和预算。
- `src/ui/panels/parameter_editor.cpp`：按钮改为“应用演化谱预设”，使用目标 500 窗口替代固定重叠率。仅显示当前模式有关字段，预设后仍可编辑。
- `src/ui/panels/workflow_preview_panel.cpp`：在现有预览状态区显示两行实际窗口／步长／重叠率／FFT 摘要，说明数量保持可见；悬停显示数量、跨度和尾部点数。状态更新清除旧摘要。
- `resources/i18n/zh.json`、`en.json`：中英文任务说明、参数选用依据、具体例子及边界诊断；辅助文字放在帮助与悬停内容中。
- 中英文用户指南、方法文章、参数参考、诊断说明、发布公告和版本资料同步更新。帮助窗口本身的视觉重设计尚未实施。
- 数值／界面测试与近期功能性能工具新增或更新对应案例。

## 累计包含的前两份补丁

流程画布内部留出边框，去除滚动条交汇处残余；插入／替换节点在输入和每个下游映射均唯一时免弹窗，存在歧义时保留选择窗口，支持撤销／重做并给出非阻塞反馈。对应文件为 `src/ui/app/main_window.cpp`、`resources/themes/base.qss`、`rewrite_tests/rewrite_tests.cpp`，以及语言资源和手册。

## 兼容性与范围

数据库 schema 与结果数据格式不变。默认点数、旧流程点数／重叠率模式保持；点击新预设或切换新模式才改变步长。采用新目标模式的流程需 beta.2 或更高版本执行，不保证旧版识别新参数选项。旧结果不会自动重算。

预设不在时间／深度两端补零，不隐式重采样，也不增加二维平滑算法；参考来源与跨软件差异已放入手册。其他界面体验建议和帮助面板设计留待下一轮讨论。

## 验证与使用

Linux Qt 6.8.2 Release 构建与 2208 项 Qt 测试、142 项发布工具测试、7 项帮助生成器测试通过，0 失败、0 跳过。新增中英文界面在 100%、150%、200% Qt 缩放下验证；性能包含 9 个案例。详细环境、日志与未测范围见[验证记录](../../../validation_current.md)。本轮未声称完成 Windows/macOS 原生程序包或新一轮 Acycle 直接数值对照。

将补丁中的目录和文件合并到 `Aster.pro` 所在源码根目录，重新运行 qmake 并构建 Release。不要在本补丁后再次覆盖旧补丁，以免退回旧代码或文档。补丁包只包含变更文件；不包含完整源码或预编译程序。
