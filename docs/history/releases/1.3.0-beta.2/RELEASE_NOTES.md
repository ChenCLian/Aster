# Aster 1.3.0-beta.2 发布说明

本次更新让演化谱预设随实际输入长度计算窗口密度，并补充参数含义与实际计算值。界面采用中性功能名称，详细说明放在内置帮助中。

- “使用 Acycle LAH 风格预设”更名为“应用演化谱预设”；参考来源与差异保留在手册中。
- 演化 FFT／MTM 新增“按目标窗口数”步长模式。预设采用目标 500 窗口，实际整数步长与重叠率按当前节点的输入计算；窗口数不超过目标，不强制填满 500。
- 预览成功后简要显示实际窗口点数、步长、重叠率与 FFT 点数；悬停显示窗口数量和物理跨度，参数或输入变化时清除旧摘要。
- 完善中英文任务／参数帮助：选参依据、取整例子、归一化的影响、FFT 补零与显示插值的区别，以及跨软件比较条件。
- 纳入 beta.1 后的两个补丁：修复流程画布边框与滚动条交汇处残余；插入／替换节点在输入及下游连接均唯一时直接操作，保留歧义选择和撤销／重做。

**兼容性：** 数据库 schema 与结果数值格式不变；新建任务默认点数设置、旧流程的点数／重叠率模式保留，只有主动应用预设或切换模式才改变计算。使用新步长模式保存的流程请用 beta.2 或更高版本运行；beta.1 不认识该模式。旧结果不会因升级自动重算。新模式只计算完整窗口，不增加时间／深度端点补零。

本次提供源码增量补丁，包含上述前两份修复，可覆盖原 beta.1 或已打补丁的 beta.1 源码。合并后重新运行 qmake 并构建，使版本号与内置帮助生效。帮助面板视觉重设计及其他体验建议留待后续讨论。

验证范围见 [本版记录](../../../validation_results/1.3.0-beta.2/checks.json)。本地 Linux 检查不等同于 Windows/macOS 原生程序包验收；可下载平台仍以实际发布附件为准。
