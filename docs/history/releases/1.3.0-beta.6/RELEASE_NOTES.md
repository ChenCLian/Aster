# Aster 1.3.0-beta.6 发布说明

本次完成帮助内容 C4 第一批：MTM、Lomb–Scargle、Welch 交叉谱、连续小波与 AR1 全局检验，以及旧实验检验的解释范围。

- 新增双语统计解释公共主题，区分描述性功率、几何峰、局部阈值、FDR 和全局检验。
- 补充参数选择、单位、缺失输出、未定义值及常见错误；相关任务复用同一公共说明。
- 修正 AR1 检验频点范围的短提示，明确模拟次数是每个参考模型的次数。
- 将 FDR 的“假发现率”与单次检验误报概率区分，避免对拟合背景下的实际控制作出过度承诺。

算法、默认参数、方法版本、数据格式和帮助窗口交互不变。年代模型、天文数据与日常操作仍待后续文档批次整理。
