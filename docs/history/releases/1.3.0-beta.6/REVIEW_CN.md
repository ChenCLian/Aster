# Aster 1.3.0-beta.6 修改说明

本轮完成 C4a：MTM、Lomb–Scargle、Welch 交叉谱、CWT 与 AR1 全局检验，兼顾旧实验任务的历史解释。算法、默认参数、方法版本与结果格式不变。

## 文档修改

- 新增双语公共主题 `docs/concepts/statistical_interpretation*.md`，区分描述性功率、几何峰、局部阈值、FDR、全局检验、缺失输出和 COI。
- 新增双语操作指南 `docs/methods/spectral_inference*.md`，说明 5 项当前功能及 1 项历史功能的输入、设置顺序、输出、单位、边界和限制；原方法文档保留公式和证据。
- 修正 AR1 短提示：频点集合排除 DC 和偶数长度的奈奎斯特频点。模拟次数是每个参考模型的次数，不是整个任务总次数。
- 区分假发现率与单点误报率；不对拟合 SWA 背景下的实际 FDR 控制作出保证。
- 解释 MTM 参数按完整频谱作用、峰检测不等于显著性、Lomb 输出不是 PSD、交叉谱未定义值与相位方向，以及两种 CWT 功率约定。
- 任务和参数通过 referenceguide 链接复用公共章节；新增页面已内置，双语索引及旧入口保持可用。

## 验证和存档

Linux Release 构建、12 项 Qt 帮助检查、8 项生成器检查、142 项发布工具检查通过；细节和未测范围见[本版验证](../../../validation_current.md)。没有把旧版数值或校准结果当作本轮重新测试。
