# Aster 1.3.0-beta.12 关联交互检查与修复

## 编译兼容修正（版本号不变）

用户报告 help_catalog.cpp 第 57 行在 MSVC 下 C2397。标题级别字段为 int，而 QString::size() 返回 qsizetype；原代码在 GCC 下已有窄化警告，先前遗漏处理。现对正则限定为 1～6 的标题级别显式转换为 int，不修改目录或算法行为。

近几轮变更的 11 个 C++ 实现文件已通过 -Werror=narrowing 严格语法检查，帮助定向测试 9 项通过；未在本环境运行 MSVC。仅需替换此源文件并重新构建，无需改 Qt 或编译器配置。记录见 docs/validation_results/1.3.0-beta.12/build-fix/checks.json。


本轮继续围绕近期修改排查，未重复完整数值算法 Debug。五处问题均在修复前通过实际 Qt 交互或状态回归复现，最终通过后交付。

## 修复内容

1. **修改参数后立即删除当前输入**：延时提交尚未触发，删除使参数草稿的来源失效，旧界面无法继续提交并可能阻塞切换／撤销。现在先提交原输入参数，再删除；撤销删除恢复该输入及已提交参数，不把草稿写到剩余数据。
2. **修改参数后立即打开配对管理**：旧定时器提交改变工作流版本，把刚打开的窗口关闭。现在先提交参数，再取得配对窗口的工作流版本。
3. **同名内置／复用输入选择漂移**：列表刷新按名称恢复选择，可能跳到最后一个同名输入。现在按稳定数据 ID 恢复；重排和新增同名输入保持原选择。
4. **帮助检索旧结果误点**：改关键词后，在防抖等待期间仍能点旧结果。现在立即清除旧结果。
5. **首次全文索引期间按回车无效**：现在记录当前查询的请求，索引就绪后打开首项。继续输入、清空、切换语言或另行导航后取消旧请求，防止迟到跳转。

- src/ui/panels/pairing_panel.cpp/.h：打开配对窗口前回调。
- src/ui/help/help_dialog.cpp/.h：检索结果失效和待执行回车请求。
