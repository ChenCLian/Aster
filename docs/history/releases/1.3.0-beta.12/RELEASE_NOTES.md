# Aster 1.3.0-beta.12 发布说明

本版继续检查近期参数作用范围、预览联动和帮助窗口的交互边界，修复五处可复现问题。

- 参数尚未延时提交时删除当前输入，现在先提交原输入的参数，再执行删除；避免编辑器停留在已删除对象上并阻塞切换与撤销。撤销删除会恢复该输入及删除前已提交的参数。
- 打开配对管理前提交待保存的节点参数，避免延时提交把刚打开的配对窗口判为过期而关闭。
- 同名的内置或复用输入在刷新、重排及新增输入后，按稳定的数据 ID 保持当前选择，不再按显示名称选错对象。
- 帮助全文搜索更换关键词后立即清除旧结果，防止等待检索时误点旧章节。
- 首次建立全文索引时按回车，会在结果就绪后打开首项；继续输入、清空、切换语言或另行导航会取消旧的跳转请求。

数值算法、任务默认值及数据库格式未改。验证范围见 docs/validation_current.md；本轮仍为近期改动关联路径的定向检查，不替代完整算法复核或原生平台发行验收。
