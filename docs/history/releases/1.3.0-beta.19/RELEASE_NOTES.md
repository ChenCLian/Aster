# Aster 1.3.0-beta.19 发布说明

本版修复更新下载与发布脚本审查中发现的边界问题，计算算法和数据格式保持不变。

- 修复取消操作后仍可能继续发起网络请求的问题；取消后立即重试时，旧请求的处理不会干扰新操作。
- GitHub 版本查询成功但更新信息附件无法下载时，按同一版本回退 Gitee；主动取消和信息格式错误不触发回退。
- 取消更新信息读取后，窗口保持已取消状态，不再重新显示下载入口。
- 发布草稿上传前核对四个平台程序包、源码包与校验信息；复用草稿时校正正式版/Beta 标记并保留人工公告；每次上传前重新确认仍为草稿。
- 串行执行桌面发布工作流，避免不同分支同时向同版本草稿上传相互覆盖的附件。
- 最终包检查失败时覆盖旧成功记录并清理旧截图，保留超时前的诊断输出；为 Gitee 源码同步增加限时和错误详情。
- Windows Actions 增加已有 PowerShell 打包流程回归。

本地验证记录见[验证范围](../../../validation_current.md)。本版尚未执行远程 Actions、Windows/macOS 原生打包或 Gitee 上传。首次 Actions 建议关闭 `prepare_draft`，先验证四个平台；通过后再准备草稿和镜像。
