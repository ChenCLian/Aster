# Aster 1.3.1-alpha.1

开发预览，仅用于验证，不进入稳定版或 beta 更新渠道。

- 修复首次打开结果页、关闭最后一个图页时空白提示区域未铺满的问题。
- Hilbert 振幅包络新增“分析输入序列”输出，默认与包络共同显示；启用去均值时显示实际参与计算的去均值信号。Gaussian/Taner 的滤波序列与包络也默认共同显示。
- 修复包络、滤波输出因坐标名称变化而无法叠加的问题；明确单位冲突仍会阻止叠加。旧数据中的未注明单位曲线可在 X 轴兼容时显式叠加，不进行单位换算。
- 修复同节点输出组合时遗漏记录 ID 校验的问题，拒绝过期引用。
- 发布工具自动核验并复用官方已发布依赖源码附件，生成每个平台的依赖 JSON 清单；新增或变化的依赖重新收集。构建记录、许可证及二进制清单仍逐版生成。
- 测试运行器增加定时进度和实时日志位置提示。整理帮助说明与历史中间说明文档。

数据库格式不变，已有工作流的方法版本继续兼容。已保存结果不会自动重算；旧 Hilbert 结果若需新增的输入序列输出，需要重新运行。使用新增输出连接的工作流不保证能在旧版中执行。

本地验证与未覆盖范围见[验证记录](../../../validation_current.md)。新版本的原生构建、实际发布及跨版本更新验收尚未完成。
