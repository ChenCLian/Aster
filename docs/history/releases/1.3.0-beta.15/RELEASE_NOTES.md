# Aster 1.3.0-beta.15 发布说明

本版撤回 beta.13 / beta.14 中试验性的自动更新模块，恢复完整程序包手动更新。

- 移除签名清单、公钥配置、包下载器、Windows 更新助手、自动替换与恢复逻辑，以及对应的专用工具、测试和第三方实现。
- 保留“设置 → 检查更新”：按需查询 GitHub 版本并打开发布页，用户手动下载和解压。不在后台自动检查或安装。
- 保留“设置 → 联系我们”跳转内置手册作者页；中文和英文界面均可离线打开。
- Alpha 仅用于开发者测试，不参与在线检查，也不作为更新候选。
- 修复设置入口测试的模态窗口清理，断言在弹窗关闭后执行。
- 保留 beta.12 已完成的算法、参数默认值与批量应用、帮助手册、交互修复和 MSVC 类型收窄修复。数据库格式与算法输出未改变。
- 三个平台恢复原有打包路径，不再构建或打包 AsterUpdater；原有许可证及依赖材料工具继续保留。

请使用新源码目录、新构建目录和新程序包目录，避免残留更新器、旧 DLL 或旧测试程序。不要删除用户数据库和设置。
