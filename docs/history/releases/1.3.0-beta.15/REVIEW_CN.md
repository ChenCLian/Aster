# Aster 1.3.0-beta.15 更新说明

本版撤回试验性自动更新，回到“检查版本 → 打开发布页 → 手动下载完整程序包”。无需维护更新密钥、签名清单或安装助手。

“联系我们”保留打开内置手册作者页，支持离线查看。Alpha 仍只用于开发者测试。此前算法、默认参数与批量应用、帮助手册和兼容性修复保留。

请将完整源码解压到新目录，使用新构建目录编译根 Aster.pro；不要覆盖旧的测试安装目录。原有许可证和第三方依赖材料工具仍属于常规发布流程，独立于自动更新模块。

本地构建与定向检查已通过；原生 Windows/macOS 和云端打包未执行。具体范围见[本版验证](../../../validation_current.md)。
