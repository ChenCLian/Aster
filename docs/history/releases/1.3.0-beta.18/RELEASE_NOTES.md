# Aster 1.3.0-beta.18 发布说明

本版完善完整程序包下载后的发布与镜像流程，并统一文档链接；计算算法与既有工作区数据格式未作修改。

- 四个平台的 Actions 构建、回归检查与最终程序包启动检查全部成功后，才准备 GitHub Release 草稿。已有草稿中的人工公告保留，不覆盖已公开的发行版。
- GitHub 发布后，可按需启用 Gitee 同步：只上传四个确切名称的程序包和更新信息，源码保存到独立渠道分支；所有 dependency-materials 附件仅保存在 GitHub。程序包内的许可证保留。
- Gitee 文件超过同步上限时跳过，不重新压缩或拆包；下载后按原始 SHA-256 校验，通过后才公布镜像地址。Alpha 版本继续仅用于开发测试。
- 查询 GitHub 失败时可以回退 Gitee，并明确提示镜像结果可能滞后；不会将网络异常误报为最新版。
- 文档采用同一份 Markdown 正文：仓库与本地使用相对链接，内置手册解析本地页面，发布公告自动拼接对应平台和版本的文档地址。
- 补充最终程序包的中文/英文启动截图和日志。截图用于人工复核；自动启动通过不能保证字体和排版完全正常。

本地验证范围见[验证记录](../../../validation_results/1.3.0-beta.18/checks.json)。本次未实际执行远程 Actions 或向 Gitee 上传；Windows/macOS 原生打包和 Gitee 真实附件接口仍需首次流水线验收。
