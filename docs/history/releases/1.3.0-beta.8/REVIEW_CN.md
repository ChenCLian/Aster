# Aster 1.3.0-beta.8 修改说明

本版完成 C5，并收口 A/C 文档整理。完整源码包含 C1–C5 的累计修改；Qt 帮助窗口的多级目录与全局搜索仍为单独待办。

## 本轮修改

- 补齐 15 项任务的中英文长文入口：文件、内部序列绑定、四类数据库复用、五项 ODP 示例、正弦源、合成轨道源、选段和序列摘要。56 个注册任务现在均有长文入口，包括隐藏绑定／历史任务。
- 说明数据库来源引用、ODP 已发表年龄与采样、合成信噪比和标准化、选段含边界及留下的空缺、摘要总体方差与等样本权重。
- 中英文索引按快速入门、软件功能、通用概念与参数、常见问题、关于与引用组织；方法目录按功能分组。
- 两种语言的手册明确导入多选、单数据／配对参数、当前流程节点批量设置及绘图设置的范围，补充结果复用与筛选列表导出。
- “目录”按钮文字改为“主页”，与其返回使用手册的实际行为一致；说明页内查找不搜索全部文档。未引入新的目录树或搜索实现。
- 修正演化谱锚点定位，并补充 FAQ 中普通批次与联合批次并行设置的区别。

## 累计内容

C1 整理采样与重采样；C2 整理窗口、FFT、频谱单位及显示；C3 整理平滑、去趋势、异常值、变换与滤波；C4a 整理谱估计和统计解释；C4b 整理年代模型、COCO 和天文数据；C5 完成输入来源、日常操作入口及全任务覆盖核对。共用概念由各任务链接引用，主界面不增加长篇说明。

## 验证与交付

Linux Qt 6.8.2 Release 构建、14 项 Qt 帮助检查、8 项生成器检查及 142 项发布工具检查通过。打包和 Actions 仅做本地静态核对，未执行跨平台原生构建；本轮未重跑数值算法回归。详细范围见[验证入口](../../../validation_current.md)。

算法、默认参数、方法版本与结果格式不变。使用新构建目录重新编译根工程 Aster.pro，才能更新内置手册和程序版本。完整源码包不含本机 config/local.pri、用户数据库或已编译程序；请保留自己的依赖路径配置与数据。
