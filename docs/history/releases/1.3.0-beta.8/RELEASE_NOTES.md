# Aster 1.3.0-beta.8 发布说明

本次完成 C5 文档整理与 A/C 阶段收口：补齐文件、数据库复用、ODP 示例、正弦及合成信号、选段和序列摘要的中英文说明。

- 56 个注册任务均有长文入口，包括普通目录隐藏的绑定节点与历史任务；默认参数仍由程序定义生成。
- 文档索引按快速入门、软件功能、通用概念与参数、常见问题、关于与引用分类，增加英文索引，方法目录按功能分组。
- 明确文件多选、当前数据／配对参数、当前流程批量设置及绘图设置的作用范围。
- 补充结果复用的数据库依赖、筛选列表导出范围、预览与任务输出限制；修正演化谱章节入口位置。
- 现有帮助的“目录”按钮更名“主页”，与返回使用手册的行为一致；解释搜索只查当前页面。

算法、任务默认参数、方法版本、结果格式及打包流程不变。多级可折叠目录和全局搜索尚未接入 Qt，仍为独立界面改造事项。本版完成本轮 A/C 文档整理并提供完整源码；源码包不含已编译程序。
