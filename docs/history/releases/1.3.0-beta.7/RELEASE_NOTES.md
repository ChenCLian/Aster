# Aster 1.3.0-beta.7 发布说明

本次完成帮助内容 C4 第二批：年代模型、逐周期赋龄、目标周期、COCO 扫描与检验，以及天文曲线和日照。

- 新增中英文深度、年龄与速率公共说明，明确单位、年代基准、控制覆盖、转换后采样及外部文件重算。
- 补充 14 项任务的使用步骤、输出含义、参数选择与常见误解，相关参数跳转到共享章节。
- 区分 COCO 最佳匹配、点位 p、扫描校正 p 和全扫描 p；滑窗图不作为显著性检验。
- 说明轨道数据覆盖与相位可靠范围、ETP 区间标准化，以及日平均、季节平均与累计能量的区别。
- 修正日照短提示中“365 日历”的含混表述，明确固定无闰月日与实际积分时间的区别。

算法、默认参数、方法版本、数据格式和帮助窗口交互保持不变。日常操作与全目录核对留待 C5；Qt 多级目录和全局搜索仍为单独待办。按交付约定先保存工作快照，完成文档后统一交付完整源码。
