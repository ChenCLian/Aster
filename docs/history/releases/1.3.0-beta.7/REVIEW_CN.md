# Aster 1.3.0-beta.7 修改说明

本轮完成 C4b：14 项年代模型、逐周期赋龄、目标周期、COCO 与天文数据任务的双语帮助精修。算法、默认参数、方法版本和结果格式不变。

## 修改内容

- 新增深度、年龄与速率公共页，统一单位、年代基准、控制覆盖、转换后采样和外部文件重算的解释。
- 年代模型指南明确速率积分规则、首年龄位置、控制表的文件参数入口、默认超界报错和逐周期漏峰／多峰的影响。
- COCO 指南区分固定扫描、蒙特卡洛和滑窗图，说明目标功率、有效候选、点位／扫描校正／全扫描 p 及其适用范围。
- 天文指南说明数据覆盖与相位可靠范围、PT 表限制、ETP 的区间标准化、日平均／季节平均／累计能量和纬度—年龄图。
- 修正三个日照任务短提示中“365 日历”的含混表达；详细的历法和时间权重说明放在帮助文档中。
- 新增 8 个双语页面，任务与参数复用共享章节；旧方法文档保留公式和来源，并加入新指南入口。

## 验证与后续

Linux Release 构建、13 项 Qt 帮助检查、8 项生成器检查、142 项发布工具检查通过。细节与未测范围见[本版验证](../../../validation_current.md)。没有重新进行数值回归、统计校准或跨平台原生验收。

本批先保存完整源码工作快照和检查记录，不单独交付更新包。下一批 C5 整理日常操作、合成信号与示例数据说明，核对全目录入口及版本／发布文档的一致性，再准备完整源码交付。Qt 帮助窗口目录和搜索改造仍单独待办。
