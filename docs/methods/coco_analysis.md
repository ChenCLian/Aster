# COCO 蒙特卡洛与 eCOCO

本文说明输入、输出、数学约定与适用范围。验证批次、环境和范围见 [验证记录](../validation.md)。

## 任务与输出

| 任务 | 稳定 ID | 用途 | 默认显示 |
| --- | --- | --- | --- |
| COCO 蒙特卡洛检验 | `coco_monte_carlo` | 固定速率网格下的匹配检验；提供明确假设的 AR1 模型和可选随机谱峰参考模型 | 扫描校正 p 曲线 |

输入仍为两列 XY：X 为递增、等间隔深度，Y 为代理指标；非空深度单位必须与参数一致。不会自动排序、去重、重采样或插入 LOWESS。目标默认仅是近现代周期示例，古老地层应明确指定周期或选 Waltham 模型中点。

两项任务都有进度和取消，预览在后台运行。完成提示旁显示方法说明数量，悬停可查看零模型、扫描范围和其他解释边界；正式结果的参数/来源页也保留这些说明。切换输出或点击画布空白不会重新计算；改动已生效参数会触发新预览，旧计算按既有机制取消/丢弃。正式运行和预览使用相同执行实现。所有输出及完整参数、种子、模型、诊断进入数据库，可导出 CSV；曲线与热图沿用现有图形导出。热图输出不能连到只接受一维序列的任务。
## COCO 蒙特卡洛的数学定义

先按 [固定目标说明](coco_scan.md) 得到每个几何可用候选速率的 Pearson 相关 `r(s)`。用于显著性检验的统计量为：

`T(s) = max(0, r(s))`。

常数比较频带定义为 `T=0`（没有正匹配证据），包括模拟样本；不丢弃或重抽“不好看”的模拟。全部观测比较谱都无方差则任务失败。用于绘图的原始相关仍保留负值。

每次模拟使用同一几何可用速率集合、目标、前处理、频带和 FFT。设 B 为模拟次数、`T_b(s)` 为模拟值、`M_b=max_s T_b(s)`：

- 单个速率：`p_point(s) = (1 + #{T_b(s) >= T_obs(s)})/(B+1)`。
- 扫描校正：`p_scan(s) = (1 + #{M_b >= T_obs(s)})/(B+1)`。
- 全扫描：`p_global = (1 + #{M_b >= max_s T_obs(s)})/(B+1)`。

上尾比较含同值；浮点近同值采取保守容差。p 最小为 `1/(B+1)`，不会输出“p=0”。选择扫描中最大值后应使用全扫描 p 或对应的扫描校正 p，不能拿未经搜索校正的点位 p 代替。扫描校正 p 不小于点位 p，全扫描 p 等于最小扫描校正 p。

在预先指定的简单零假设下，观测与模拟统计量可交换，秩检验控制的是**该固定扫描家族的完整零假设**。它不证明混合真/假假设下的强 FWER，不覆盖反复改周期、权重、频带、速率范围、种子、多文件选择或整张滑窗图。也不是速率置信区间，更不证明天文因果关系。

`(b+1)/(B+1)` 的 Monte Carlo 秩 p 处理参考 Phipson & Smyth (2010), [DOI:10.2202/1544-6115.1585](https://doi.org/10.2202/1544-6115.1585)、[作者预印本](https://gksmyth.github.io/pubs/PermPValuesPreprint.pdf)。Aster 这里生成独立零模型样本，不是置换原始数据；该计数公式不能弥补错误的零模型。

### 固定参数 Gaussian AR(1)：默认

`Y_0 ~ N(0,1)`；`Y_i = rho*Y_(i-1) + sqrt(1-rho^2)*epsilon_i`，`epsilon_i ~ N(0,1)`，要求 `|rho|<1`。初值已经服从平稳分布，不以零起点假装平稳。默认 rho=0，即白噪声。随后应用与观测相同的去均值/线性去趋势/不处理和周期图计算。

rho 必须独立于本次待检数据确定。本任务**不从该序列拟合 rho**。若用户先从同一序列估计 rho 后填入，这只是代入参数模拟，不能再声称简单零假设的精确检验。默认去均值时整体偏移、方差比例不影响统计量；选“不去趋势”还要求零均值模型。上游滤波、LOWESS、插值等不会在零模型中重演；本节点检验的是当前输入是否符合声明模型，不能把预处理造成的相关结构忽略掉。

该模式适合边界明确、可校验的基础检验；不试图自动判断所有真实地层噪声。

### 随机谱峰：可选参考模型

参考 Li et al. (2018), *EPSL* 501, 165–179，[DOI:10.1016/j.epsl.2018.08.041](https://doi.org/10.1016/j.epsl.2018.08.041) 与参考源码中的 `randspec_sin.m`。在空间频谱上叠加非负半正弦峰，峰宽为 2 倍 Rayleigh，完整支撑位于 `[0, Nyquist]`，起点连续均匀随机，高度均匀分布于 `[0,1)`。峰数可手动输入；0 表示计数观测周期图严格局部峰（平台只计一次，排除 DC/Nyquist）。

这保留文献随机峰的基本思想，但不强行宣称逐点复刻：连续起点与 MATLAB 离散随机索引不同；未扣除 AR1 背景；目标为固定相位平均；增加扫描最大统计量及非零秩 p。自动峰数取自观测数据，参考谱也不是完整 Gaussian 时序零模型，因此结果明确标记为**随机峰参考 p**，不提供任意强红噪声下的误报率保证。

### 参数与输出

模拟参数默认来自 `CocoMonteCarloOptions`：B=199、种子=1729、rho=0、alpha=0.05、参考峰数=0。UI 根据模型只显示相关参数；手动周期、目标权重、速率与频谱设置复用原任务。正式分析可提高 B，但“更多模拟”不等于“模型更正确”。alpha 须不小于 `1/(B+1)`；判定用 p≤alpha，表内临界值仅作辅助。

| 输出 | 语义 |
| --- | --- |
| 原有五个输出 | 原始相关、可用性诊断、最佳候选的观测谱/目标谱、实际周期与功率 |
| `pointwise_p` | 固定候选的点位 p；无正匹配证据时为 1 |
| `scan_adjusted_p` | 在全部几何可用候选上校正的 p |
| `null_maxima` | 按生成顺序保存每次模拟的最大正相关，便于复核 |
| `mc_summary` | B、种子、模型代码、rho/峰数、alpha、观测最大值、全扫描 p、参考临界值、p 分辨率 |

摘要模型码 0=AR1、1=随机谱峰。另一模型不用的 rho/峰数列以 0 占位，列名已明确适用范围；报告保留 `null_model`，不用的 rho 为 JSON null。几何可用但观测比较带无方差的候选，p 曲线中保留为无证据 p=1；原始相关曲线遵循旧规则排除该点，诊断表可追溯。
## eCOCO：局部匹配图

窗口默认 512 点、步长 128 点，只取完整窗口，至少两个窗口和两个可用速率。不同窗口长度必须能分辨选定目标；不会通过删目标或补窗口掩盖分辨率不足。

每个窗口执行与固定扫描相同的去趋势、单边谱与目标匹配。固定窗口长度的目标谱只构建一次并缓存，在所有窗口重用。图的 X 是实际窗口首尾深度的中点，Y 是 cm/ka，颜色是原始 Pearson r（可为负）。没有按列额外归一化。存储布局为 `values[速率行 * 窗口数 + 窗口列]`。

| 输出 | 语义 |
| --- | --- |
| `correlation_map` | 深度—速率热图 |
| `best_rate` | 各窗最大相关对应候选；同值取较小速率 |
| `best_correlation` | 各窗最大原始相关 |
| `window_diagnostics` | 实际窗口起止/中心、最佳候选与相关 |
| `rate_diagnostics` | 对所有窗口通用的完整候选网格与几何排除原因 |
| `target_periods` | 实际使用的周期、频率和相对功率 |

这是描述图，**没有给滑窗结果标显著性**。相邻窗口重叠、相邻速率相关；局部最优线可以跳变，不进行路径平滑或自动生成年龄模型。不足完整窗口的尾部样本数写入报告。任何常数/无方差窗口都报出窗口序号与起始点，不用零值冒充结果，也不偷偷删除窗口。
## 实现边界与资源保护

- 新数值入口：`src/math/chronology/coco_analysis.h/.cpp`；公共目标/谱助手由 `coco_detail.h` 声明，在原 `coco_scan.cpp` 内实现。
- 新任务适配：`src/processing/coco_analysis_tasks.h/.cpp`。公共参数解析、输入单位检查、结果格式和异常边界由 `coco_task_support.h` 与原 `coco_task.cpp` 提供。
- 用 `SCIENTIFIC_METHODS` 增加两项注册，沿用分类、类型检查、参数表单和中英文资源；数据库不用迁移。
- 基础 COCO 上限继续生效。模拟最多 9999 次，缓存最多 800 万 double（约 64 MB），模拟/窗口比较预算 5 亿项。eCOCO 输入最多 100 万点、最多 512 窗、热图最多 200 万格。复杂输入在复制或分配大数组前尽早拒绝。
- 随机状态属于单次调用；固定 MT19937-64 高 53 位均匀数和 Box–Muller 顺序，便于复核。跨编译器的浮点最后几位可能不同，科学比较使用容差。
- 不在 UI 线程计算，不对单个任务再创建并行线程；保持原有不同输入间的有界并发。并发任务的内存总量仍随并发数增加，单任务上限不是整个进程的内存保证。

## 可选数值内存检查


有 GCC/Clang 和 OpenBLAS 开发环境时，可单独检查当前缓存/FFT 索引，不需要启动 Qt。`coco_bounds_smoke.cpp` 不参与桌面构建；它覆盖 24 组奇偶样本数/补零、两种零模型、滑窗和取消。

```sh
g++ -std=c++17 -O1 -g -fno-omit-frame-pointer -fsanitize=address,undefined -I src \
  analysis_tests/coco_bounds_smoke.cpp src/math/chronology/coco_scan.cpp \
  src/math/chronology/coco_analysis.cpp src/math/statistics/monte_carlo_test.cpp \
  src/math/backend/numeric_backend.cpp src/math/backend/pocketfft_backend.cpp \
  src/math/backend/lapack_backend.cpp -lopenblas -lpthread -o coco_bounds
ASAN_OPTIONS=detect_leaks=0 UBSAN_OPTIONS=halt_on_error=1 ./coco_bounds
```

该命令只检查指定数值路径，不代表整个 Qt 应用或系统 BLAS 已通过 sanitizer。sanitizer 的执行环境与结果须单独记录，不能由普通回归测试通过推定。
