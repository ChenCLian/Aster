# 谱估计、交叉谱、小波与 AR1 检验

[统计解释](../concepts/statistical_interpretation.md) · [窗口与单位](../concepts/spectral_parameters.md) · [English](spectral_inference_en.md)

本页按操作顺序解释任务；计算公式和历史验证保留在各方法的详细说明中。FFT、Welch 和演化谱见[功率谱指南](power_spectra.md)。

<a id="mtm"></a>
## MTM 多窗功率谱

要求有限、严格递增、等间隔的 X/Y，至少 4 点，并满足 NW 小于 N/2；默认 NW=2 因此至少需要 5 点。任务自动去均值，不自动线性去趋势或重采样。常量输入主谱为零，不评估背景显著性。

先选 NW，再考虑 FFT 长度。NW 是时间—半带宽积，可取 1 或 1.25～32；NW=1 使用 2 个 DPSS 窗，否则使用 `round(2NW)−1` 个。增大 NW 通常使谱更平滑，也使邻近峰更难区分。半带宽为 `NW/(N×Δx)`，它与 FFT 网格间隔不是同一量。FFT 0 在本任务使用 N 点，指定值须不小于 N；补零不增加观测时长。

`spectrum` 为单边物理 PSD，单位按 Y²×X 解释。频率上限只裁剪发布输出，背景拟合、自适应收敛、FDR 及峰检测仍基于完整频谱；裁剪后才保留位于范围内的峰。旧记录中的比例上限仍有兼容语义，核对报告中的实际输出范围。

AR1 和 SWA 默认开启。AR1 的背景平滑窗口是**频点数量比例**，不是样本点数；对数拟合改变背景拟合方式，不是对原始 Y 或颜色取对数。SWA 使用自身背景平滑规则，不由这个 AR1 窗口比例直接控制。各背景的名义阈值及 FDR 解释见[公共统计说明](../concepts/statistical_interpretation.md#fdr)。

背景拟合失败可能只省略相应背景／阈值，主谱与峰表仍返回；自适应迭代达到上限也会保留结果并警告。请查看报告，不把“任务成功”当作全部可选输出都有效。

输入最多 100 万点、FFT 最多 400 万点；DPSS 规模与估算工作区另有限制，不能同时把参数设为各自最大值。缩小输出频带不减少完整谱估计的主要工作区。[参数](../reference/task_parameters.md#m-mtm)。

<a id="peaks"></a>
## MTM 峰表与筛选

峰检测寻找内部局部极大值；端点不作为局部峰，平顶峰取中间位置。有效突出度阈值取绝对突出度、完整谱极差的相对比例和舍入量级下限中的最大值。默认相对比例为 0.1%，不是显著性水平。

峰宽在半突出度高度处计算，单位为频点，可为非整数；峰距也按频点计算。半径 0 表示搜索完整范围，正半径限制突出度寻找基底的范围。改变半径会改变突出度及峰宽。竞争峰优先保留突出度更大的峰，其次看峰高，再按位置排序。

峰表包含 frequency、period、power、prominence、width_bins，以及 AR1／SWA 95% 和 FDR 0.05 的判定列。1 为通过，0 为未通过，−1 为未评估或不可用；不是三种概率。周期为 1/频率，沿用 X 单位。数据库中的峰频率索引只帮助检索，不代表确认天文周期。

<a id="lomb"></a>
## Lomb–Scargle

要求至少 5 个有限样本、严格递增 X 和非常量 Y，允许不等间隔；不自动排序、补点或重采样。使用等权的正弦、余弦与浮动截距拟合，不提供逐点测量误差权重。

频率下限 0 表示 `1/T`，T 为首末 X 跨度；上限 0 表示 `0.5/相邻间隔中位数`。后者只是自动搜索规则，不是不等间隔采样的严格奈奎斯特上限。可根据采样与研究尺度明确指定频带，但需上限大于下限。

默认每峰采样数 5，频率步长为 `1/(T×每峰采样数)`；增大它加密网格，不增加独立信息。最高输出频点可能略低于设置上限。检查报告的 first_frequency、last_frequency、frequency_step 和 grid_points。

`periodogram` 为 `(chi0−chi_f)/chi0`，即相对常量拟合的残差平方和改善比例，范围 0～1、无量纲。它不是 PSD，不能与 MTM 峰高度直接比较，也没有 FAP 或显著性阈值。部分频率的拟合基底可能退化，报告 rank_one_bins／rank_zero_bins 提醒检查采样与频带。

最多 100 万样本、65536 个频点，`样本数×频点数≤5000万`；超限可有依据地收窄频带或降低网格密度。常量序列不能归一化。[参数](../reference/task_parameters.md#m-lomb_scargle)。

<a id="cross"></a>
## Welch 交叉谱

先在同工作区配置 A/B 配对。双方须等长、有限、严格递增、等间隔，并使用同一 X 网格；X 名称和单位去除首尾空白后须一致。只改标签不能完成真实的单位或年龄基准转换。Y 单位可以不同。

默认段长 256、重叠 128、周期 Hann、逐段去均值。至少两个完整段，因此默认至少需要 384 点；修改段长不会自动改变重叠。FFT 0 使用段长，显式值不得更短。尾部不满段的样本不参与估计，数量记入报告。两条数据采用同一套处理设置，不自动裁剪共同区间或补齐。

复交叉谱先按 `conj(A)×B` 逐段平均，再计算幅值、平方相干度和相位，不是逐段取模后平均。相干度 0～1，无量纲，但不是 p 值；本任务不输出显著性阈值。

相位沿数值 X 递增方向定义，交换 A/B 后反号（按圆周角比较）；年龄向过去递增时，不能直接套用时间向前的领先／滞后解释。低功率或低相干位置的相位可能不稳定。程序不自动展开相位或转换时延。

自功率为零时相干度未定义；复交叉谱为零时相位未定义。矩形窗配合去均值／线性去趋势时，DC 被明确置零并标记；Hann 不使用这一特殊处理。未定义值显示“—”、CSV 留空、曲线断开，不能填成有效零值。

完整列、单位与资源范围见[交叉谱说明](cross_spectrum.md)；配对操作见[用户手册](../USER_GUIDE.md#cross-spectrum)。

<a id="wavelet"></a>
## 连续小波

要求有限、严格递增、等间隔的输入，至少 6 点。任务去均值，不自动去除长期趋势。默认 Morlet 参数 6、dj=0.1；Morlet 参数至少 5，Paul 参数须为整数，DOG 须为偶整数，均受界面范围限制。切换母小波后应重新检查参数含义和边界约定。

dj 是 log2 尺度间距，越小尺度网格越密、计算越大；它不等于提高原记录的分辨能力。周期由尺度换算得到，不等于尺度本身。记录位置为列、周期为行，输出 Y 轴是周期而非频率。

默认“方差归一化与尺度校正”输出 `|W|²/(样本方差×物理尺度)`，单位为 X 单位的倒数，同时提供 raw_power 与 scale_corrected_power。切换“原始功率”后 power 为 `|W|²`，单位为 Y²；尺度范围与 AR1 背景估计也改变，并非仅换颜色。默认方式不接受常量输入，原始功率方式可输出零功率。

开启显著性时，`significance_ratio` 是原始功率与名义局部 95% 阈值之比，不是直接将当前显示的归一化功率除以任意曲线。背景无效时可能省略这一输出而保留功率。比值大于 1 和 COI 的解释分别见[局部阈值](../concepts/statistical_interpretation.md#local-global)与[影响锥](../concepts/statistical_interpretation.md#coi)。

输入最多 100 万点，但网格还受 1600 万单元与 512 MiB 估算工作区限制；默认方式保留多个网格，不能只看一个图的大小估算内存。超限时检查输入长度和 dj。详细输出及旧结果名称见[小波说明](cwt.md)。

<a id="ar1"></a>
## AR1 背景全局检验

直接输入序列，无需先接 MTM。要求 64～1024 个有限、严格递增、等间隔、非常量样本。它检验平稳 Gaussian AR1 噪声假设；通过输入检查不表示模型假设已成立。

NW=2、K=3、NFFT=N 和检验频点集合固定；不提供看到峰后缩窄检验频带的选项。标准精度对**每个参考模型**使用 999 次筛选模拟，其中前 199 次计算分析统计量；精细模式用 999 次分析模拟。不是整个任务总共只模拟这些次数。精细模式更慢，并可能因预算而拒绝某些大 N 设置。

内部 LOWESS 默认关闭；启用时默认比例 0.35、普通 LOWESS、稳健迭代 0，同时处理观测和参考序列。该比例仅在开关启用时生效。上游处理不会自动重放。种子用于复现，不能为获得显著结果反复挑选。

缓存默认开启，仅复用匹配的参考模拟，观测统计量仍重新计算。关闭缓存不改变检验定义；相同设置和种子重新生成不是一份新的独立证据。缓存不含用户原始序列，损坏或不匹配时重新生成，写入失败可能仅警告而保留计算结果。

默认输出 `ar1_global_test` 表：先看 test_available，再读 global_p 和 reject_global_null；alpha 固定 0.05，available=1 且 p≤alpha 才拒绝。空候选集合记 available=0、p=1，表示不可判定。另有 spectrum、ar1_global_background、ar1_analysed_series 供核查。

结论针对单条输入的完整预定频点集合，不提供每峰概率、CWT 全图检验或天文成因判断。数学依据、缓存位置和历史校准见[AR1 详解](ar1_global.md)。

## 旧实验 MTM AR1 检验

`mtm_ar1_simulation` 隐藏于任务目录，保留身份供历史记录解释。它的未知 rho 近似参数自举不等同于当前 AR1 全局检验；独立指定 rho 模式也不能把本记录估计值当作先验已知量。不要因参数名称接近而替换解释。旧结果应连同原方法版本、参数和适用范围阅读。[历史任务范围](statistical_limits.md#已隐藏的旧实验任务)。
