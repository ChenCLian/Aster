# 连续小波分析

适用版本：Aster 1.2.0-beta.7。

[使用手册](../USER_GUIDE.md) · [参数参考](../reference/task_parameters.md#m-cwt) · [统计限制](statistical_limits.md#cwt)

连续小波分析用于查看不同周期的信号强度如何随时间或深度变化。横轴沿用输入序列的时间或深度，纵轴表示周期，颜色表示所选功率量；亮色区域不自动等于显著的天文周期。

## 准备数据与选择参数

输入必须按 X 严格递增、等间隔采样，且不含无效数值。需要重采样或去趋势时，先添加相应处理节点；小波任务会去均值，但不会自动去除长期趋势。

默认母小波为 Morlet，参数为 6，尺度步长 dj 为 0.1。dj 控制相邻小波尺度在 log2 空间中的间隔；减小它会增加计算量和尺度采样密度，不会提高原记录本身的分辨率。母小波参数的含义随母小波类型而变，见[参数参考](../reference/task_parameters.md#m-cwt)。

<a id="conventions"></a>
## 两种计算约定

“小波计算约定”控制功率定义、尺度范围和背景估计。

| 界面选项 | 默认显示的功率 | 尺度与背景的区别 |
| --- | --- | --- |
| 方差归一化与尺度校正（默认） | 原始小波功率除以输入样本方差和物理尺度 | 最大尺度目标为 0.34 × 样本数 × 采样间隔，按尺度网格取值；AR(1) 采用滞后一阶协方差与方差之比的估计约定，不将有效的系数强制截为 0.99 |
| 原始功率（Torrence–Compo） | 小波系数模的平方，保留输入值的平方单位 | 尺度网格可延伸至约样本数 × 采样间隔；AR(1) 采用去均值后的滞后一阶最小二乘估计，并限制在 −0.99 至 0.99 |

两种方式使用不同的功率定义、尺度范围和背景估计。比较论文或其他软件的结果时，应核对这些约定以及采样、母小波、尺度步长和预处理。常量序列没有可用于归一化的正方差，默认方式会报错；原始功率方式可输出全零功率。

<a id="power"></a>
## 输出如何理解

令 W 为去均值后序列的小波系数，s 为物理尺度，σ² 为输入序列的样本方差（分母为 N−1）。周期由母小波的尺度—周期换算关系得到，不等于 s 本身。

| 输出 | 定义及用途 |
| --- | --- |
| 小波功率（按所选计算约定） | 默认方式为 abs(W)² / σ² / s；原始功率方式为 abs(W)²。须按所选方式解释数值和单位 |
| 影响锥 | 表示不同位置上受记录边界影响的周期范围，用作功率图的辅助曲线，不是独立的功率或置信区间 |
| 原始小波功率 | abs(W)²；默认方式下的附加输出，单位为输入 Y 单位的平方 |
| 尺度校正功率 | abs(W)² / s；默认方式下的附加输出，单位为 Y 单位平方 / X 单位 |
| 功率 / 名义95%阈值 | 原始功率与对应局部阈值之比，无量纲；仅在启用显著性计算且背景估计有效时提供 |

默认方式的显示功率单位为 X 单位的倒数。例如，X 为 ka 时其单位为 1/ka。

比值大于 1 表示超过相应位置的名义局部阈值，不代表整张图通过了全局或多重比较校正。默认方式若估计出不满足平稳条件的 AR(1) 系数（绝对值不小于 1），会保留功率并说明无法提供显著性输出的原因。周期大于影响锥曲线的区域受边界影响，应谨慎解释。

## 绘图与比较

周期热图默认使用 log2 周期轴、反向 Y 轴和“彩虹”配色，小周期位于上方。预览、结果与导出使用相同的默认样式。修改对数坐标、轴方向或配色只改变显示，不改变已计算数值；切换计算约定则会重新计算。

“添加绘图”将同一小波步骤的影响锥附于功率热图。原始功率、尺度校正功率及显著性比值含义不同，分别绘制。具体操作见[绘图说明](../ui/plotting.md)。

## 方法来源与旧结果

默认方式参考 Acycle 的小波计算路径；对照对象为已记录的 Acycle 3.1.1 验证快照，主要涉及 `wave_readGUI` 的 method 2、`wave_update_wavelet` 与 `ar1nv`。原始功率方式沿用 Torrence–Compo 小波方法的相关约定，并保留本程序明确的边界检查。参考软件的全部功能和其他版本不在这一对照范围内。

为识别已保存设置，两种方式的参数标识分别保留为 `acycle_cwt` 和 `torrence_compo`。较早版本界面中的“Acycle CWT（标准化、尺度校正）”即当前“方差归一化与尺度校正”。名称调整不改写旧记录，不改变默认值或计算结果。结果来源中的参考实现与方法版本也予以保留。

方法比较与验证范围见[与 Acycle 的方法对照](acycle_compatibility.md)，原始证据见[科学来源记录](../reference/scientific_evidence.json)。Acycle 的文献为 Li, Hinnov & Kump (2019), *Acycle: Time-series analysis software for paleoclimate research and education*, Computers & Geosciences 127, 12–22，[DOI](https://doi.org/10.1016/j.cageo.2019.02.011)。软件实现与第三方归属见[第三方说明](../third_party.md)。
