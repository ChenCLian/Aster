# 沉积速率与年龄模型

本文说明输入、输出、数学约定与适用范围。验证批次、环境和范围见 [验证记录](../validation.md)。

## 沉积速率转年龄模型

方法 ID：`sedrate_to_age`。输入是 **深度 X、沉积速率 Y**；输出 `age_model` 为深度 X、年龄 Y。输入深度必须严格递增，所有速率（含最后一行）必须有限且大于零。至少 2 点，最多 100 万点。

默认参数只有任务描述这一份来源，UI 与执行器共同读取：深度 m、速率 cm/ka、年龄 ka、首个深度年龄 0、年龄基准未声明、区间速率采用左端值。

设单位换算系数为 C，则年龄满足：

\[
 t(z)=t(z_0)+C\int_{z_0}^z\frac{1}{r(u)}\,du.
\]

- **左端恒定（默认）**：每个区间 Δt = C·Δz/r_left。与 Acycle 验证快照中的速率转换函数约定一致；最后一个速率验证但不参与积分。
- **随深度线性变化（可选）**：r₀≠r₁ 时 Δt = C·Δz·ln(r₁/r₀)/(r₁−r₀)；相等时用 Δz/r₀。实现使用稳定的 `log1p`/尺度分解，不直接用易溢出的 r₁/r₀，也不误用平均速率的倒数。

起始年龄属于**第一个实际输入深度**，不是深度零。例如深度 `[10,11,13] m`、速率 `[2,2,999] cm/ka`、首年龄 7 ka，默认结果为 `[7,57,157] ka`。

深度单位支持 m/dm/cm/mm/ft/km；速率选择 cm/ka、m/ka、mm/ka、cm/yr、m/yr、mm/yr、cm/Ma、m/Ma；输出年龄 yr/ka/Ma。已有单位标签不能与选择冲突。速率标签 kyr/ka、Myr/Ma 的时间别名可识别。无单位标签时使用用户明确选择的单位，并提示核对；不会猜测数值代表什么。

这不是间断、侵蚀或年龄不确定性模型。零/负速率报错，不能靠它表达无限时间或逆向沉积。
## 应用年龄模型

方法 ID：`apply_age_model`。主输入仍为 **深度 X、观测值 Y**。在步骤设置中选择一张深度—年龄控制表：可使用上述任务导出的模型 CSV，也可使用自己的控制点文件。一个模型可应用于多个输入文件。

控制表参数：默认第 1 列为深度、第 2 列为年龄；分隔符和表头自动识别；控制深度默认 m、年龄默认 ka。两列不能相同；深度和年龄必须各自严格递增，至少两行。文件最多 4 MiB、控制点最多 100000 行。

控制表与普通文件导入使用**同一解析器**，包括 BOM、CSV 引号、分隔符、表头和错误行诊断。这里不跳过无效数值行。控制表深度换算为输入深度单位后才进行匹配；控制表年龄列按选定年龄单位解释，不从标题猜测单位。

区间内使用分段线性插值：

\[
 t(z)=t_i+\frac{z-z_i}{z_{i+1}-z_i}(t_{i+1}-t_i).
\]

**默认拒绝超出控制范围的输入**，不会截掉两端数据。只有用户明确选择“允许线性外推”，才按首末区间斜率延长，并记录外推样本数。控制点处直接返回控制年龄。一个控制点不能决定斜率，因此拒绝，而不是假定深度与时间之间的单位斜率。

输出各自具有独立含义，不强制叠画：

| 端口 | 内容 | 预览/结果显示 |
| --- | --- | --- |
| `aged_series`（主输出） | 年龄 X、原观测值 Y，点数不变 | 下游默认输入；独立曲线 |
| `age_model` | 该次计算使用的控制深度与年龄 | 独立深度—年龄曲线，可导出 |
| `age_intervals` | 每段深度起止、年龄起止及平均沉积速率 Δz/Δt | 数值表 |

**不会自动重采样。** 非线性年龄模型会使原本等深度间隔的数据变成不等年龄间隔。后续 MTM/FFT 要求等间隔时，会按既有规则报错；需要时由用户明确添加重采样，或选择适用不规则采样的 Lomb–Scargle。

年龄基准选项（未声明、距 1950 年、距 2000 年、相对年龄）仅记录元信息，**不自动平移年龄零点，也不转换公历年份**。当前契约是年龄随深度增加；公历 AD 年份随深度减小的控制表须先明确转换年龄定义。
## 两项任务怎样衔接

1. 导入深度—速率文件，选择相符单位，运行“沉积速率转年龄模型”。
2. 导出 `age_model` 的 CSV。
3. 对深度—观测值数据添加“应用年龄模型”，选择该 CSV，并核对深度和年龄单位。
4. 预览检查后正式运行；原始数据、控制模型、转换结果和任务参数都保留在对应运行记录中。

年龄模型通过文件参数绑定；任务接收待转换的观测序列。模型表的 Y 表示年龄，与观测值区分。当前不提供交互式年龄控制点编辑器。

线性速率积分在**原始速率采样点**给出精确积分结果；把这些点导出后再用分段线性年龄插值处理中间深度，是另一个近似。它不会在控制点之间重建原来的连续线性速率积分曲线。速率变化大时需增加控制点密度。
## 读取、追溯与安全

- 每次节点执行捕获控制文件字节，用同一份字节解析并计算 SHA256；报告保留路径、列、表头、单位和哈希，输出保留实际数值控制点。
- 正式结果存入数据库后，查看和导出历史结果不依赖外部控制文件仍存在。
- 重新运行会读取该路径**当时**的内容。外部编辑文件不自动触发预览；点击预览“重算”即可重新读取。不是跨整批运行冻结文件的功能，执行期间请保持外部控制文件稳定。
- 类型、长度、有限值、单调性、单位冲突、资源预算和无法分辨的年龄增量均检查；错误进入统一诊断，下游阻断，其他输入按原有调度继续。
- 取消在读取、验证、积分、插值与构造输出中检查。计算约 O(N+M)，无 N×M 矩阵。
- JSON 只存参数/报告；数组继续通过类型化不可变 `DataRef` 流转。
## 与参考的关系和验证边界

- Acycle 验证快照中的 `acycleSedimentationRateAgeModel.m` 使用左端速率积分；本版默认遵循这一约定。此函数属于指定的验证快照，不能把它称作所有官方 Acycle 发行版的唯一实现。
- Acycle `depthtotime.m` 的区间线性插值和端点斜率外推是参照；本版对外推改为明确选择，并增加单位与严格单调性检查。
- 按滤波峰/谷逐周期赋龄由独立任务提供，见 [逐周期赋龄](cycle_tuning.md)。它与应用控制点年龄模型具有不同的输入和假设。
- 独立固定参照用 Python Decimal 70 位计算，普通线性速率情形另由 SciPy `quad` 积分交叉核对；C++ 测试检查解析解、单位换算、边界、取消、预览/正式一致、数据库与导出。
- 验证使用独立数值参照，未进行直接 MATLAB 运行对照。当前方法不提供贝叶斯推断或年龄置信区间；控制点的地质解释须独立确认。
