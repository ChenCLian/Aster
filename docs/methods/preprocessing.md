# 采样检查、排序去重与重采样

[公共概念](../concepts/sampling.md) · [方法目录](README.md) · [English](preprocessing_en.md)

这三个任务处理的是不同问题。先确认输入状况，再决定需要哪一步；不必每次都把三个任务全部添加。

| 目的 | 使用任务 | 是否改变传给下游的序列 |
| --- | --- | --- |
| 检查顺序、重复坐标和间隔 | 采样与间隔检查 | 不改变 |
| 只整理顺序并处理重复 X | 排序与去重 | 可能改变顺序、Y 和样本数量；不插值 |
| 整理后建立新的等间隔网格 | 整理与重采样 | 改变采样位置，按插值估计 Y |

<a id="inspection"></a>
## 采样与间隔检查

### 什么时候使用

导入新数据后，或者删点、截取区间后，可以先检查采样。它接受尚未排序的序列；后续频谱任务对输入的要求可能更严格。检查不会替你排序、去重或修复空缺，也不自动跳过无效值。

### 大间隔判定倍数怎么选

默认倍数为 3。程序收集当前输入中相邻 X 的正间隔，计算其中位数，再标记**严格大于中位数 × 倍数**的间隔；恰好等于阈值不标记。增大倍数会减少标记，减小倍数会增加标记。应结合采样设计判断，不能把默认阈值直接解释成沉积间断标准。

例如 X 为 `0, 1, 2, 8`，正间隔为 `1, 1, 6`，中位数为 1；倍数为 3 时，2 到 8 的间隔被标记。若输入存在逆序，负间隔不参与这个中位数；应先查看逆序统计，再决定是否整理后重查。若没有正间隔，报告会标记正间隔统计不可用；“没有大间隔”不表示采样正常。

<a id="inspection-output"></a>
### 输出怎样阅读

建议先看总体汇总，再用明细定位问题。

| 输出 | 内容 | 解释 |
| --- | --- | --- |
| 原始序列 `series` | 原样传递输入 X/Y | 检查后继续分析仍须满足下游输入条件 |
| 采样汇总 `sampling_summary` | 样本数、重复 X、逆序相邻对、相等相邻对、递增／等间隔判断及大间隔数量 | 统计覆盖完整输入；判断字段 1 表示成立，0 表示不成立 |
| 采样间隔 `sampling_intervals` | 原始相邻点的左右 X 和间隔 | 最多保留从输入开头起的 4096 个相邻间隔 |
| 大间隔 `sampling_gaps` | 满足阈值的点对及间隔 | 最多保留按输入顺序遇到的前 4096 条标记，不是最大的 4096 个间隔 |

明细列 `right_point_1based` 是右侧样本在本节点输入中的序号，从 1 开始；有表头、跳过无效行或上游处理时，它不一定等于原文件行号。

重复 X 统计为每组相同坐标中超出一个的样本数；即使相同 X 在输入中不相邻，也会计入。逆序和相等相邻对则按当前输入顺序统计。等间隔判断仅在严格递增时进行：以平均间隔为基准，最大相对偏差不超过 `1e-6` 时判为等间隔；这一数值容差不是测量误差评估。

**4096 行只限制任务保留的明细，不限制总体统计范围，也不会截短原始序列。** 例如输入 5000 个点，共有 4999 个相邻间隔；间隔明细保留前 4096 行，而汇总仍覆盖 5000 个点。导出该表也只有保留下来的行，不会重新生成遗漏的明细。

计算报告中的 `interval_details_truncated` 和 `gap_details_truncated` 分别说明两张明细是否被截断。预览表格还有独立的显示预算，因此屏幕上看到的行数也可能少于表本身；详见[三类数量限制](../concepts/sampling.md#limits)。本任务最多接受 100 万个样本；超出时拒绝计算，不会只检查前一部分。

<a id="cleanup"></a>
## 排序与去重

需要保留不等间隔位置、只整理数据时，使用此任务。X/Y 成对按 X 递增排序，再按选定策略处理完全相同的 X；不会改变单位或自动建立新网格。

默认平均合并重复 X 的 Y，也可保留首个、保留末个或遇重复时报错。策略的含义和小例子见[重复坐标](../concepts/sampling.md#duplicates)。至少需要两个有限 X/Y 样本，整理后还须有至少两个不同的 X。缺失值应先按导入策略处理，不能依靠排序去重自动丢弃。

详细参数：[排序与去重](../reference/task_parameters.md#m-clean_series)。

<a id="resampling"></a>
## 整理与重采样

### 按这个顺序设置

1. 确认 X 的数值和单位，检查是否存在不应跨越的空缺。
2. 选择重复 X 的处理方式。任务始终先排序、处理重复坐标。
3. 选择采样间隔方式。默认使用整理后相邻 X 间隔的中位数；选“不重采样”时，到整理完成为止，插值设置不参与计算。
4. 需要自定义间隔时选“指定间隔”，按 X 的单位输入数值；其他间隔模式下这个数值不起作用。
5. 选择插值方法并检查输出曲线，必要时再次做采样检查，再送入要求等间隔的分析任务。

各种间隔与插值方法的取舍集中见[公共说明](../concepts/sampling.md#spacing)。本任务默认线性插值；自然三次样条和 Akima 也可选。重采样时，去重后线性至少需要 2 个不同 X，自然三次样条至少 3 个，Akima 至少 5 个；样本不足会报错，不会自动改用线性。选择“不重采样”时不执行插值的最少样本检查，但整理仍要求至少两个不同 X。

<a id="grid-endpoints"></a>
### 输出端点为什么可能变化

新网格从整理后的最小 X 起，按选定间隔向前排列。它不在输入范围外外推，也不会为了包含末点额外添加一个不等间隔点。只有最大 X 落在网格上（允许浮点舍入误差）时，才作为末点保留。

例如 X 覆盖 0 到 10，指定间隔为 3，则输出 X 为 `0, 3, 6, 9`，不会追加 10；间隔为 2 时则为 `0, 2, 4, 6, 8, 10`。原来位于网格之外的内部样本位置也不一定保留。X/Y 单位沿用输入，但样本位置和数量可能改变。

<a id="resampling-failures"></a>
### 报错或形态异常时先查什么

| 现象 | 核对与处理 |
| --- | --- |
| 重复 X 或不同 X 太少 | 回查来源和重复策略；全部坐标相同不能建立重采样区间 |
| 输出网格不合法或点数太多 | 检查 X 单位与间隔；间隔大于跨度无法形成两个点，过小则可能超出网格预算 |
| 间隔无法用数值精度表达 | 避免在很大的坐标数值上设置极小间隔；按研究需要统一换算坐标与单位后重试 |
| Akima／样条样本不足 | 核对去重后的不同 X 数量；在方法适合的前提下自行改用线性，或使用足够的观测 |
| 长空缺中出现一条连续曲线 | 插值跨过了空缺；按研究背景分段，不把连接线当作新增观测 |
| 峰值附近产生不合理形态 | 比较插值方法、间隔及原始观测，必要时保留原采样位置 |

当前重采样网格要求 `(最大X−最小X)/间隔` 在 1 到 999999 之间，最多输出 100 万点；极小间隔还可能触及浮点精度限制。失败时不产生可供下游使用的有效输出。运行报告保留输入／输出点数、合并行数及实际间隔等信息。

默认值和精确范围见[整理与重采样参数](../reference/task_parameters.md#m-preprocess)；是否将输出保存到结果库，见[即时预览与正式运行](../ui/live_preview.md)。
