# 平滑与去趋势

[公共概念](../concepts/data_processing.md) · [方法说明](README.md) · [English](smoothing_trends_en.md)

平滑直接给出邻域估计；去趋势分别提供拟合背景和减去背景后的序列。使用前确认希望保留的是哪一部分，尤其注意后续节点连接的输出端口。

<a id="moving-average"></a>
## 移动平均

适合用简单的局部均值降低快速波动。要求有限、严格递增的 X/Y，至少 2 点；可接受不等间隔 X，但此时按相邻点平均，既不按时间长度加权，也不自动重采样。

默认窗口 11 点，须为不超过输入点数的奇数，允许 1～501。窗口 1 保留原值。内部用居中完整邻域，两端缩短到实际可用点。例如 Y=[1,2,3,4,5]、窗口 3，得到 [1.5,2,3,4,4.5]。没有补零，也不会只输出中间的“有效”区段。

输出 `series` 保留 X、点数和单位；均值、峰高及频率成分可能改变。不等间隔下会提示实际窗口跨度随位置变化。[窗口选择](../concepts/data_processing.md#neighborhoods) · [参数](../reference/task_parameters.md#m-moving_average)。

<a id="savitzky-golay"></a>
## Savitzky–Golay 平滑

对局部样本拟合多项式，取当前位置的拟合值。要求有限、严格递增且等间隔的输入，至少 2 点；不隐式插值。默认 11 点、二阶，窗口为奇数且不超过输入点数或 501，阶数 0～5 且严格小于窗口点数。

中部使用居中完整窗口；左端使用最前的完整窗口拟合并在相应位置求值，右端同理使用最后的完整窗口。它与移动平均的缩短窗口规则不同，即使 SG 取零阶，两端也不必一致。窗口 1 仅在零阶时合法。

增大阶数不是单纯“提高精度”：可能保留更多局部起伏，也可能产生过冲或负值。SG 不保证结果落在邻域最小值与最大值之间，不输出导数或置信带。输出 `series` 的 X、点数和单位不变。[参数](../reference/task_parameters.md#m-savitzky_golay)。

<a id="linear"></a>
## 线性去趋势

使用实际 X 拟合含截距的最小二乘直线，再从 Y 中减去它。至少 2 点，X 必须有变化；不要求等间隔。本任务不排序、不重采样，也不自动排除极值。

默认输出 `detrended` 为残差，`trend` 为拟合直线；两者保持输入 X 和 Y 单位，逐点相加可恢复输入 Y（浮点误差范围内）。报告给出斜率和截距。本任务没有“保留原均值”开关，常量基线与斜率一同移除。

最小二乘会受到强极值影响。去趋势后的低频减弱是操作本身的一部分，不能据此判断原始记录没有长期变化。[参数与输出](../reference/task_parameters.md#m-linear_detrend)。

<a id="lowess"></a>
## LOWESS 去趋势

稳健迭代大于零时，程序按点数 × 每窗邻点数 ×（稳健迭代次数 + 1）估算计算量。超过 10 亿次邻点计算会提前结束该节点。默认普通 LOWESS 使用单独的计算路径。

要求有限、严格递增的输入，至少 2 点；允许不等间隔。使用局部线性拟合，默认邻域比例 0.35、稳健迭代 0、不保留原均值。

比例取 0.001～1，基础邻域点数为 `max(2,min(N,floor(fraction×N)))`，按 X 距离加权。它不是 X 跨度的百分比；例如 101 点的 35% 基础邻域为 35 点。边缘邻域不对称，窗口不会自动避开大间隔。比例很小时可能几乎逐点追随输入，使残差接近零。

稳健迭代 0 为普通 LOWESS；1～10 启用残差重加权，5 是可选的 rLOWESS 设置。重加权降低部分大残差点对拟合的影响，不删除点，也不保证识别真实测量错误。增加迭代会增加计算量，不应只为让曲线更平滑而不断增大。

默认输出 `detrended=y−trend`，`trend` 是拟合背景；普通或稳健 LOWESS 的残差均值不一定严格为零。开启“保留原均值”后，输出为 `y−trend+mean(trend)`，从而保持输入 Y 的平均值；不是简单加回 `mean(y)`。趋势端口不变，报告 `mean_adjustment` 记录实际加回量。

两路输出保持 X、点数和 Y 单位。保留均值开启后，不能再用“残差＋趋势”直接恢复输入，还需减去均值调整量。[参数](../reference/task_parameters.md#m-detrend_lowess) · [单位与标准化](../concepts/data_processing.md#units)。

<a id="selection"></a>

长序列的普通 LOWESS 复用相邻窗口的加权和，仍在每个输入坐标上拟合。报告中的 `fit_evaluation` 记录求值方式。批处理显示当前文件的拟合进度，并可在拟合期间取消。

## 选择与核查

| 目标或问题 | 建议核查 |
| --- | --- |
| 希望输出局部平滑值 | 移动平均或 SG；检查实际窗口跨度和峰高变化 |
| 希望移除缓慢背景并分析剩余变化 | 线性或 LOWESS；同时查看 `trend` 和 `detrended` |
| 数据短于默认 11 点 | 主动缩小平滑窗口；SG 同时检查阶数 |
| SG 报输入不等间隔 | 先检查 X，再决定是否有理由重采样；不把允许不等间隔的移动平均当作等价替代 |
| 两端出现偏差或过冲 | 比较边界规则、邻域与原始值；不能仅靠扩大窗口解决 |
| 去趋势后几乎没有变化 | 检查所选输出、LOWESS 邻域是否过小，以及被移除趋势是否包含目标信号 |

移动平均和 SG 最多处理 100 万点，工作预算 `N×窗口点数≤1亿`；这不是推荐规模。LOWESS 需逐位置拟合，邻域比例和稳健迭代会影响成本，不套用平滑任务的窗口预算。精确默认值仍由参数参考给出。

这些任务不输出显著性检验、置信区间或“最佳窗口”。既有计算约定和参照见[平滑与频谱约定](smoothing_spectra.md)，当前版本验证范围见[当前检查](../validation_current.md)。
