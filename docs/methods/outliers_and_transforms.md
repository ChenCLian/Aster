# 异常值与数值变换

适用版本：Aster 1.3.0-beta.1。

## 异常值识别与处理

入口：数据处理 → 数据整理 → 异常值识别与处理。

- **Hampel**：以相邻采样点的局部中位数为中心，使用局部 MAD（偏差绝对值的中位数）识别尖峰。
- **全局 MAD**：使用整条记录的中位数与 MAD。趋势、层段差异或非平稳序列可能被误标。
- **指定范围**：在原始 Y 单位下设置上下限；恰好位于边界的点保留。

MAD 判据为 `|y − median| > threshold × 1.4826022185 × MAD`，默认倍数 3。MAD 为零时标记偏离中位数的点。局部窗口使用奇数点数，边缘缩短到实际可用点，不按地层距离推断窗口，也不自动识别缺测段。

默认“仅标记”不更改数值。可选择排除识别点，或以原始局部窗口的中位数替换；后者不使用迭代替换后的值。原始序列单独保留。排除不会自动补值，可能使采样变得不等间隔。

预览曲线的右键菜单提供“保留此点”“排除此点”和“此点使用识别结果”。这些决定只作用于当前数据，优先于识别规则。批量应用节点规则不复制单点决定。输入 X/Y 改变后旧决定失效并提示重新检查；此机制防止重采样或切换输入后错用点位。

识别是筛选依据，不是错误判决；真实事件、极端环境变化或测量尺度差异也可能导致极值。原文件始终不被覆盖。

## 逐点处理记录

| 列 | 含义 |
| --- | --- |
| `index` | 原始序列位置，从 0 开始 |
| `x`、`original_value` | 原始 X、Y |
| `result_value` | 处理后的 Y；排除点记为 -1，须结合 `action` 判断，原始负值不因此视为无效 |
| `detected` | 检测器是否标记：1 是、0 否 |
| `selected` | 应用逐点决定后的选择状态：1 是、0 否 |
| `action` | 0 保留、1 排除、2 替换 |
| `score` | 偏差与 1.4826 × MAD 的比值；未计算或无法表示时为 -1 |

算法上限为 200,000 点，局部窗口处理预算为 20,000,000 次样本访问，每条输入最多保存 5,000 个逐点决定。达到上限时提示调整参数，不静默减少计算数据。

## 数值变换

入口：数据处理 → 幅度 → 数值变换。尺度 `s > 0`，与输入 Y 同单位。X 不变，输出无量纲。

| 函数 | 计算 | 使用边界 |
| --- | --- | --- |
| 自然对数 | `ln(y/s)` | 全部 Y 必须大于 0，不自动平移 |
| 常用对数 | `log10(y/s)` | 全部 Y 必须大于 0 |
| 反双曲正弦 | `asinh(y/s)` | 支持正、负、零值；小幅值近似线性，大幅值压缩 |
| 双曲正切 | `tanh(y/s)` | 输出介于 -1 与 1，强极值趋于饱和 |

这些函数不判断哪些点错误，也不消除缺测区间。变换会改变幅度比值、分布和后续功率谱含义；应在方法报告中注明函数与尺度，并对照原始记录。
