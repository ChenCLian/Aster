# 异常值与数值变换

适用版本：Aster 1.3.0-beta.20。

[公共概念](../concepts/data_processing.md) · [English](outliers_and_transforms_en.md)

<a id="outliers"></a>
## 异常值识别与处理

入口：数据处理 → 数据整理 → 异常值识别与处理。要求有限、严格递增的 X/Y，至少 2 点；不要求等间隔。这里的“原始值”指进入本节点的输入，可能已经经过上游处理。

- **Hampel**：以相邻采样点的局部中位数为中心，使用局部 MAD（偏差绝对值的中位数）识别尖峰。
- **全局 MAD**：使用整条记录的中位数与 MAD。趋势、层段差异或非平稳序列可能被误标。
- **指定范围**：在原始 Y 单位下设置上下限；恰好位于边界的点保留。

MAD 判据为 `|y − median| > threshold × 1.4826022185 × MAD`，默认倍数 3。MAD 为零时标记偏离中位数的点。局部窗口使用奇数点数，边缘缩短到实际可用点，不按地层距离推断窗口，也不自动识别缺测段。

没有手动排除决定时，默认“仅标记”不更改数值。可选择排除识别点，或以原始局部窗口的中位数替换；后者不使用迭代替换后的值。原始序列单独保留。排除不会自动补值，可能使采样变得不等间隔。

预览曲线的右键菜单提供“保留此点”“排除此点”和“此点使用识别结果”。这些决定只作用于当前数据，优先于识别规则。批量应用节点规则不复制单点决定。手动排除即使在“仅标记”或“替换”模式下也执行删除，手动保留则阻止自动删除或替换。输入 X/Y 改变后旧决定失效并提示重新检查；此机制防止重采样或切换输入后错用点位。

选择顺序：先以“仅标记”检查候选点，再根据测量记录或研究依据决定是否排除／替换。MAD 阈值只用于 Hampel 和全局 MAD，范围法忽略它；局部窗口用于 Hampel 检测及任何方法下的中位数替换。即使全局 MAD 检测，替换值仍取局部中位数。

窗口须为 3～1001 的奇数，可大于输入点数，此时邻域按可用数据裁剪；程序仍校验窗口合法性。范围上下限也始终要求下限不大于上限，切换方法时注意遗留的非法设置。一次排除所有点会失败，不生成空序列。

识别是筛选依据，不是错误判决；真实事件、极端环境变化或测量尺度差异也可能导致极值。原文件始终不被覆盖。

<a id="audit"></a>
## 逐点处理记录

`series` 是处理后序列，`original` 是本节点未修改的输入。`outliers` 保存应用手动决定后选中点的**原值**，不一定等于已删除点；没有选中点时不生成这一路输出。`outlier_audit` 对每个输入点记录一行，不套用采样检查的 4096 行明细上限。

| 列 | 含义 |
| --- | --- |
| `index` | 原始序列位置，从 0 开始 |
| `x`、`original_value` | 原始 X、Y |
| `result_value` | 处理后的 Y；排除点记为 -1，须结合 `action` 判断，原始负值不因此视为无效 |
| `detected` | 检测器是否标记：1 是、0 否 |
| `selected` | 应用逐点决定后的选择状态：1 是、0 否 |
| `action` | 0 保留、1 排除、2 替换 |
| `score` | 偏差与 1.4826 × MAD 的比值；未计算或无法表示时为 -1 |

算法上限为 200,000 点，局部窗口处理预算为 20,000,000 次样本访问，每条输入最多保存 5,000 个逐点决定。达到上限时提示调整参数，不静默减少计算数据。

<a id="transforms"></a>
## 数值变换

入口：数据处理 → 幅度 → 数值变换。默认 asinh、尺度 1；接受有限 X/Y，本任务不要求等间隔，也不排序。最多 100 万点。尺度 `s > 0`，与输入 Y 同单位。X 不变，输出无量纲。

| 函数 | 计算 | 使用边界 |
| --- | --- | --- |
| 自然对数 | `ln(y/s)` | 全部 Y 必须大于 0，不自动平移 |
| 常用对数 | `log10(y/s)` | 全部 Y 必须大于 0 |
| 反双曲正弦 | `asinh(y/s)` | 支持正、负、零值；小幅值近似线性，大幅值压缩 |
| 双曲正切 | `tanh(y/s)` | 数学上位于 (-1,1)，浮点计算中可能饱和到 ±1 |

这些函数不判断哪些点错误，也不消除缺测区间。变换会改变幅度比值、分布和后续功率谱含义；应在方法报告中注明函数与尺度，并对照原始记录。

变换前先选择尺度，再检查定义域。尺度是与 Y 同单位的参照，不是缩放后的输出单位。例如 y=10、s=10 时，ln 输出 0，asinh 输出约 0.881374。自然对数与常用对数遇到任意零值或负值会使任务失败，不自动加常数或跳过该点。

不要为了让对数运行而随意给数据加一个常数；这会改变比值和解释。asinh 接受正负值，但并不等于“修复”了数据。tanh 的饱和会压平极值差异，不能从饱和后的数值恢复这些差异。图像的对数颜色映射只影响显示，与这里改变 Y 的对数变换不同。

详细参数：[异常值处理](../reference/task_parameters.md#m-outlier_handling) · [数值变换](../reference/task_parameters.md#m-value_transform)。当前版本检查范围见[验证记录](../validation_current.md)。
