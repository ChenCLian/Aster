# 目标周期与逐周期赋龄

本文说明输入、输出、数学约定与适用范围。验证批次、环境和范围见 [验证记录](../validation.md)。

## 米兰科维奇目标周期

入口：**数据来源 → 天文曲线 → 目标周期**，是无输入的独立起点。

- 地质年龄默认 **300 Ma**，限定距今 **0–4000 Ma**。Ma 是百万年；输出周期 ka 是千年，二者不能混淆。
- 默认分量是地轴倾角。另有四个气候岁差分量 P1–P4，以及约 405/95/124/99/131 ka 的偏心率分量。
- 主输出为所选分量的下限／中点／上限表；其他独立输出为地月距离（真正的 km）、日长（h）、平均地轴倾角（°）、地轴岁差周期（ka）。使用现有输出选择器查看，均可导出 CSV。
- 这里的“中点”是上下限的算术中点，不是对随机轨道解的期望或最优估计。**范围是模型包络，不是校准的 95% 置信区间，也不含可用于轨道调谐的相位信息。**
- 偏心率采用论文表 1 的固定频率包络，所以改变年龄不会改变这些周期近似。需要真实轨道时序时继续用既有轨道数据源。

依据 Waltham (2015) 的平滑与波动潮汐耗散模型及其作者计算器约定：先求历史平均耗散包络，再求地月距离、角速度及地轴岁差频率 k。频率使用角秒/年时，周期转换为 `P(ka)=1296/f`。倾角主频是 `k−18.848±0.066`；四个气候岁差分量分别采用作者计算器的频率偏移与范围。五个偏心率分量使用论文表 1 的频率与偏移范围。

独立实现保留公式与已发布常数，采用 `expm1` 和年龄零点的连续极限避免 `0/0`，并使用全精度 π。原 Acycle 转译中余弦使用 `3.14159`，对周期频率中的同因子会抵消，但对日长产生微小差异；该项差异在参照比较中单独记录，不要求逐位一致。Acycle 的距离变量内部为千 km、显示文字却为 km；本版输出乘 1000 后明确采用 km。

**300 Ma 快速核对**：倾角周期中点约 35.5 ka；P1–P4 约 21.7、20.60、17.66、17.80 ka；地月距离中点约 376600 km，日长约 22.88 h。这些是模型计算值，不是某个地层数据已通过天文检验的结论。

核对作者网页时发现：初始静态 P4 文字是 17.88 ka，但把年龄改为 301、再改回 300 并触发重算，页面给出 17.80 ka，与公式及 Acycle 源码一致。本版使用实际公式结果，不把旧的静态示例文字当成算法参照。
## 峰谷逐周期赋龄

入口：**数据处理 → 年龄与深度 → 峰谷逐周期赋龄**。

输入是 X=深度、Y=适当的周期信号（常见情况是已滤波的曲线）。可接 Gaussian/Taner 等现有滤波任务，但本任务**不强制、不自动滤波**，也不排序、合并、删点或重采样。两列必须有限，深度严格递增且至少有两个可选的内部同相位极值。空值、重复、倒序、单位冲突或不够的峰谷会记录结构化错误。

| 参数 | 默认及语义 |
| --- | --- |
| 深度／年龄单位 | m／ka。已有非空深度单位必须与声明一致 |
| 年龄参考 | 未指定；只记录参考，不移动时间零点 |
| 周期来源 | 手动输入；也可选目标模型中点，并自动换算 ka→所选年龄单位 |
| 周期长度 | 41（默认年龄单位为 ka） |
| 周期标记 | 波峰；可改为波谷，同一任务不混合峰谷 |
| 最小局部起伏 | 0，Y 单位；定义见下文 |
| 最小深度间距 | 0，输入深度单位 |
| 首个标记年龄 | 一个完整周期，符合 Acycle 约定；可改成指定年龄 |
| 延伸至输入两端 | 关闭；开启才按端部斜率外推 |

### 标记和赋龄规则

1. 非平台峰必须严格高于两侧；平台峰是一段连续相等值，只有两侧严格更低时才成立，只保留中间样点（偶数宽平台取左中点）。波谷对反号信号同样处理。接触数据端点的平台不作为完整峰谷。
2. 局部起伏为峰高减去左右相邻峰间谷底中较高者；最外侧谷底在峰与输入端点之间寻找。它不是跨越多个峰的全局突出度。先按该阈值保留，再做间距筛选。
3. 有间距约束时优先保留局部起伏较大的标记，同强度优先靠前者，恰好等于最小间距允许保留。筛选不会推断被漏掉的周期数。
4. 若选定深度为 z₀…zₙ，周期为 P，则 `tᵢ=t₀+iP`。默认 `t₀=P`。每个相邻标记都被假定相差**完整的一周期**。
5. 仅在用户开启端点延伸时，以首/末两个标记的 `Δt/Δz` 斜率外推到数据两端。区间沉积速率为 `Δz/Δt`。

Acycle `getpks.m` 对每个满足 `>=` 的平台点计峰，常数或平台会重复计数；本版明确合并平台。普通孤立峰和默认 `P×(1:n)` 赋龄约定保持一致。Acycle `AC.m` 的保存模型是锚点表，未受其绘图端点问题影响；其绘图端点外推使用 `Δz×沉积速率`，量纲不对。本版使用 `Δz/沉积速率`（等价于 `Δz×Δt/Δz`）并仅显式开启，不把这一问题扩展为对其整个年龄模型的否定。

### 输出

| 端口 | 内容与用途 |
| --- | --- |
| `age_model` | 主输出，深度—年龄模型，可投图／导出 CSV，接“应用年龄模型”使用 |
| `selected_extrema` | 原深度及原 Y 的选定峰谷；与年龄模型分开投图，避免混淆数轴 |
| `cycle_anchors` | 原样点序号（从 1 起）、深度、Y、年龄和局部起伏 |
| `interval_rates` | 每个模型区间的深度／年龄边界及沉积速率；如有外推，也包含外推区间 |

这里没有使用 MTM 的 `peaks` 保留端口，不会把深度峰谷误加入数据库频率索引。

输出、参数、模型范围和选择规则随运行记录保存。预览与正式运行共用执行器；选择输出不重新计算，编辑参数按原有防抖策略后台重算，失效旧任务不能覆盖新结果。两种任务的参数名称、说明、条件显示、菜单和分类均由描述与中英文资源产生。

### 使用边界

- 一个漏检或多检标记就可能带来整周期年龄误差；软件不能仅凭这些标记判定真实周期计数。建议检查“选定周期标记”和区间速率。
- 调谐会主动赋予周期性，不能把调谐后的周期峰当作天文驱动的独立证据。
- 只在选定区间采用固定周期。选用目标模型中点时，包络被记录但不传播为年龄不确定性；不是随地质年龄迭代的动力学年龄模型。
- 不实现停积、侵蚀或年龄反转，不自动移除端部数据。默认锚点不能覆盖原序列两端，后续“应用年龄模型”会按其默认规则拒绝超界；可明确选择端点外推或仅保留有控制的区间。
- 上限为 100 万输入点、10 万模型控制点（含显式延伸两点）。长扫描有取消检查；标准排序在两个取消检查之间完成，受输入上限约束。
