# Welch 交叉谱、相干度与相位

[A/B 配对操作](../USER_GUIDE.md#cross-spectrum) · [参数参考](../reference/task_parameters.md#m-cross_spectrum) · [方法目录](README.md)

## 输入与参数

本方法比较两条实数序列。双方必须等长，各自 X 严格递增且均匀；X 名称与单位去除首尾空白后须一致，对应坐标误差不超过双方较小采样间距的百万分之一。Y 的名称和单位可以不同。

输入可以来自同工作区的不同普通节点。算法不会自动截取共同区间、补齐较短序列、插值、平移、换算单位或转换年龄基准。同样的采样间隔不保证起点及长度相同。改变坐标标签不能替代实际转换。

| 参数 | 默认值 | 约束与作用 |
| --- | --- | --- |
| 段长 | 256 点 | 至少 8 点，至少形成两个完整段 |
| 重叠点数 | 128 点 | 必须小于段长；修改段长不会自动修改重叠 |
| FFT 点数 | 0 | 0 采用段长；显式值不得小于段长 |
| 窗 | 周期 Hann | 另可选择矩形窗 |
| 段内去趋势 | 去均值 | 另可选择无处理或线性去趋势 |

只使用完整段，尾部未进入完整段的点数记录在报告中。补零细化频率网格，但不增加观测信息；重叠段不能直接当作相同数量的独立重复。

## 计算与输出

各段先去趋势、加窗，再计算 FFT。复交叉谱按 `conj(FFT(A)) × FFT(B)` 做复数平均，并采用窗能量和采样频率的密度归一化；单边谱的 DC 与偶数 FFT 下的 Nyquist 不翻倍。幅值、相干度和相位都由平均后的复谱计算，不是先逐段取模再平均。该方向与密度约定参照 SciPy [csd](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.csd.html)。

平方相干度为 `|P_AB|² / (P_AA × P_BB)`，参照 SciPy [coherence](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.coherence.html)。它位于 0–1，表示当前分段与预处理条件下的频率相关结构；本版不输出显著性阈值，不能直接把高相干度当成统计显著或因果证据。

| 表列 | 含义 | 单位 |
| --- | --- | --- |
| frequency | 单边频率 | X 单位的倒数 |
| cross_magnitude | 平均复交叉谱的模 | Y_A × Y_B × X |
| coherence | 幅值平方相干度 | 无量纲 |
| phase_degrees | 平均复交叉谱的相位 | 度 |
| cross_real / cross_imaginary | 复交叉谱实部 / 虚部 | Y_A × Y_B × X |
| auto_a / auto_b | 双方自功率谱密度 | 各自 Y² × X |

相位采用 `atan2(虚部, 实部)`，交换 A/B 后符号反转（按圆周角比较），相干度不变。方向沿数值 X 递增定义；年龄向过去递增时，不可直接套用时间向前的领先/滞后解释。低功率或低相干度处的相位可能不稳定；不自动展开相位或换算时延。

## 未定义值

任一方自功率为零时，相干度无定义；平均复交叉谱为零时，相位无定义。矩形窗配合段内去均值或线性去趋势时，方法显式将 DC 自谱与复谱置零并标记相干度、相位未定义；Hann 窗不采用这一特殊处理。

未定义单元在表中显示“—”、CSV 中留空、曲线上断开，不替换成有效的 0 或 1。相位在 ±180° 包裹跳变处也不跨界连线。CSV 保存全部列和单位，PNG/PDF 保存所选指标的图形。

## 计算规模与使用范围

每方最多 1,000,000 个样本，FFT 长度最多 262,144，完整段数最多 20,000；每任务还有 10 亿估算工作单位上限。它是固定计算预算，不是实测时间或硬件评分。COCO 的 100 亿预算和模拟次数设置不适用于交叉谱。

批次调度另有缓存及待保存载荷预算；这些预算不等于进程总内存。长记录、大 FFT 或大量配对仍可能耗时，必要时降低并发。取消采用合作方式，单次 FFT 调用返回后才能响应。

当前不提供 MTM 交叉谱、交叉小波、显著性阈值或联合输出再次配对。ODP 等记录的年龄模型可能已经使用天文调谐，交叉谱一致性不能单独作为独立的天文成因证据。

数值方法版本为 2。独立参照、误差和平台验证范围见[当前验证入口](../validation_current.md)；实现公式及存储契约见[计算接口](../development/cross_spectrum_interfaces.md)。
