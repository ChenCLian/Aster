# Lomb–Scargle 与 Butterworth

本文说明输入、输出、数学约定与适用范围。验证批次、环境和范围见 [验证记录](../validation.md)。

## Lomb–Scargle

采用等权、浮动均值的广义 Lomb–Scargle。在每个频率 f，直接拟合原始采样位置上的

`y = a*cos(2*pi*f*x) + b*sin(2*pi*f*x) + c`。

不先插值成等间隔，不用平均采样率替代原始 X。参考模型是一个自由常数；输出

`P(f) = (chi0 - chi_f) / chi0`，

其中 chi 是相应最小二乘残差平方和。结果无量纲，范围为 0–1，表示正弦模型相对常数模型解释的方差比例。没有自动线性去趋势，没有逐峰 FAP、置信线或全局显著性保证。需要去趋势时由用户选择上游任务。

输入至少 5 对有限数值，X 严格递增但可以不等间隔。重复、逆序或常量 Y 给出明确错误；不悄悄排序、删除数据或将无定义的常量周期图伪装为有效结果。

| 参数 | 默认值 | 解释 |
| --- | ---: | --- |
| 最小频率 `ls_min_frequency` | 0 | 0 表示自动取 `1/T`，T 为首末 X 的跨度 |
| 最大频率 `ls_max_frequency` | 0 | 0 表示自动取 `0.5/median(diff(X))` |
| 峰宽采样数 `ls_samples_per_peak` | 5 | 频率步长 `1/(T*samplesPerPeak)`，整数 1–20 |

频率单位是 X 单位的倒数；例如 X 为 ka，则 f 为 1/ka，周期 100 ka 对应 f=0.01。自动上限只是实用搜索范围：不规则采样不存在由中位间隔给出的严格奈奎斯特界限。用户可按问题修改上下限；最后一点是步长网格上不超过所设上限的点（允许浮点舍入容差），不人为改变末端步长。

实现用去中心的谐波列、主元选择和重正交化求解；X 去除公共原点，Y 先数值平移并缩放以避免大基线损失精度。对退化频率只拟合可辨识子空间：一维谐波保留可辨识分量，零维返回 0，报告退化频点数量并警告。它们不被伪装为常规三参数满秩拟合。

资源范围：输入最多 1,000,000 点，频点最多 65,536，`N*频点数 <= 50,000,000`；频率乘记录跨度限制在 `1e-6..1e8` 周期。直接扫描的成本随点数和频点数相乘增长，后台运行并支持取消。超预算会提示缩小频带或降低网格密度，不截断输入或偷偷稀疏采样。这不是面向百万点全频带的快速近似 LS 实现。
## Butterworth 低通／高通

均匀采样序列上的 Butterworth IIR：模拟原型经双线性变换得到二阶节，使用二阶节级联和稳态初值，正向、反向各滤一次。中心段不引入相位延迟；有限记录的两端仍有边界影响。

| 参数 | 默认值 | 解释 |
| --- | ---: | --- |
| 单程截止频率 `butter_cutoff` | 0.05 | X 单位的倒数，**不是**奈奎斯特归一化频率 |
| 单程阶数 `butter_order` | 4 | 整数 1–10；双向后的组合阶数为两倍 |

必须满足 `0.0001 <= cutoff/Nyquist <= 0.9999`，`Nyquist=0.5/dt`。这个数值稳定范围是当前实现的明确边界，不能把截止设为 0 或奈奎斯特端点。默认 0.05 不适用于所有数据单位，参数不合法时要求用户修改，不自动换值。X 的均匀性沿用框架相对容差 `1e-6`。

**截止定义：单程截止处振幅为 1/sqrt(2)，双向组合振幅为 0.5，即约 −6.02 dB。** 不把它标成组合 −3 dB，也不暗中预补偿截止。输出响应画的是 `|H_single(f)|^2`（双向振幅增益），不是双向功率增益。后者为该曲线的平方。

端点采用奇对称延拓，每端 `3*(order+1)` 点，要求输入长度严格大于这个值；先反射、双向滤波、再裁回原长度。阶数 4 默认至少 16 点。延拓长度不是端点误差上界；截止极低、记录很短或端点突变时，受影响区域可能很长，需要结合数据长度判断，不因数值有限就宣称科学上可靠。

输入输出保留 X/Y 单位、X 位置和样本数。低通保留直流，高通去除直流；为减少舍入误差所做的内部平移会在低通结果中恢复，不是额外的去均值操作。响应为 0 到奈奎斯特的 513 点网格，另加入精确截止频率；有限数值溢出报错。最多 1,000,000 点，处理期间检查取消。

本任务不自动计算包络。需要时串接已有 Hilbert 振幅包络任务，或使用现有 Gaussian/Taner 带通及包络任务。
## 参考与验证边界

- 广义浮动均值 LS：Zechmeister & Kürster (2009), DOI `10.1051/0004-6361:200811296`，论文 <https://arxiv.org/abs/0901.2573>。
- 归一化约定：<https://docs.astropy.org/en/stable/timeseries/lombscargle.html>。
- 独立 LS 对照：NumPy 的完整最小二乘设计矩阵，另与 SciPy 浮动均值 LS 交叉核对：<https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.signal.lombscargle.html>。
- 滤波参照：<https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.signal.butter.html>、<https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.signal.sosfiltfilt.html>。固定参照显式使用本版的延拓长度，不依赖某个库的隐式默认值。

查阅了提供的 Acycle `evoplomb.m` 和 `plomb_robustar1.m`：前者存在用采样间隔构造调用/频率轴的路径，后者使用实际时间轴并附加背景/阈值。本版保留原始不规则 X，采用上述独立可验证定义；不复制与归一化不同的功率数值，也不把针对其他谱尺度的 AR1/卡方阈值直接贴到 0–1 的 LS 上。该模块没有运行 MATLAB，也不宣称与 Acycle 所有调用模式逐点相同。

已有 MTM 峰检测、频率索引、名义 FDR 和 CWT 行为不变。该模块未给 LS 增加数据库峰索引或显著性线；既有 MTM 频率匹配仍可用。

实际构建、24 组独立参照、解析性质、失败恢复、预览/正式运行/数据库/导出结果见 [验证记录](../validation.md)。这些验证覆盖声明的实现与输入域，不是对任何真实信号的结论保证。
