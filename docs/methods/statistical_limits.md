# 显著性输出的适用边界

## 普通 MTM 与 FDR

主谱、背景拟合与概率函数的数值正确性，和实际误报率等于名义水平，是不同的验证目标。普通 MTM 的 AR1/SWA 使用估计背景、固定 2K 近似自由度与带宽修正 FDR 约定。有限样本、强红噪声、谱泄漏、背景估计及频点相关性都可能使实际越线率偏离名义值；阈值未作经验倍率校准。

这些曲线作为名义参考保留。局部峰查找是几何峰检测，相对突出度不是 p 值；数据库频率索引不表示统计显著的天文周期。需要单记录整体检验时可显式使用 [AR1 全局检验](ar1_global.md)，但需满足其 Gaussian 平稳 AR1 输入假设，不能自动套用到任意处理后的序列。

## CWT

小波 `significance_ratio > 1` 表示超过对应位置的名义局部阈值，不是整张图的全局检验或多重比较校正。影响锥是母小波的边界衰减惯例，不是置信区域、统一误差界或固定污染百分比。功率归一化约定见 [连续小波分析](cwt.md#power)。

插值并不自带抗混叠滤波；序列重采样目前没有最大插值间隙规则或逐样本缺测掩码传播；表格结果的有效性掩码不改变这一限制。改变采样、去趋势、滤波或反复挑选分析参数，会改变推断所依赖的噪声模型。程序检查形状、有限性和声明的输入条件，不替用户证明科学解释。

## Welch 交叉谱

平方相干度是频率相关结构的估计，不是 p 值。本版没有交叉谱显著性阈值；单序列 MTM 的 AR1/SWA 曲线不能用作交叉谱阈值。输入对齐、预处理、段长及年龄基准须明确。相位方向采用 `conj(A) × B`，以数值 X 递增方向解释。未定义值与资源范围见[交叉谱说明](cross_spectrum.md)。

## 已隐藏的旧实验任务

`mtm_ar1_simulation` 仍保留稳定方法身份及历史记录解释，任务菜单不显示。未知 rho 的 plug-in 参数自举在近单位根条件下仍可能偏离名义水平，不能替代 `ar1_global` 的参数集合检验。已知 rho 模式要求 rho 独立预先给定；不能把在当前数据上估计的 rho 当成已知量。上游步骤不会自动重放。

共享数学模块 `mtm_simulation`、`ar1_nuisance` 也是当前全局检验的数值依赖。
