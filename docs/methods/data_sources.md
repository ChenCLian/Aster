# 文件、已保存结果与测试数据源

先按数据来源选择入口，再核对 X、Y、单位与采样。数据源的输出类型决定可连接的后续任务，名称相似不代表可以互换。

<a id="files"></a>
## 从文本文件开始

在“输入数据”中导入 CSV、TXT、TSV 或 DAT 等分隔文本。文件可以有多列，但每个序列选择一个 X 列和一个 Y 列。先核对分隔符与表头，再选择列和填写单位；界面列号从 1 开始。

表头自动检测是读取辅助，不能代替核查。默认不跳过无效数值行；启用“跳过无效行”会省略数值无效的样本，可能留下采样空缺，应查看读取报告。该选项不等于处理重复 X、排序或补值，后者需要单独的处理节点。

X/Y 单位文字是数据标签，不进行数值换算。读取和后续计算不改写原文件。文件发生外部修改后，点击“重算”主动重新读取；程序不会监视磁盘变化。

多选时按当前列号配置逐文件校验，不按列标题自动匹配。不兼容文件保留原设置并说明原因。多选和右侧节点参数的区别见[输入选择范围](../USER_GUIDE.md#input-selection)。

<a id="database"></a>
## 用已有结果继续分析

在结果页选择记录、步骤及输出，在右侧“导出”页点击“用作数据源”。入口绑定该数据库中的具体记录、节点与输出端口；不是导出图片，也不是自动选择当前图上所有曲线。

| 已保存数据类型 | 复用后的类型 | 需要注意 |
| --- | --- | --- |
| 序列 | 序列 | 可连接接受序列的处理任务 |
| 频谱 | 频谱 | 不会自动转成以年龄为 X 的序列 |
| 栅格 | 栅格 | 不会自动提取一条剖面或展平成序列 |
| 数值表 | 数值表 | 不会自动将前两列解释为 X/Y |

这四类节点由复用操作创建，不作为普通无参数任务让用户随意添加。若后续任务不接受该类型，不能靠更改名称完成连接。

节点读取的是数据库中的完整已保存输出，不是屏幕上抽稀的显示数据；但任务生成时已限制或截断的内容不会恢复。每次执行需要原数据库路径及记录仍有效。移动数据库、删除来源记录或改变文件权限后，原引用可能失效；仅切换当前结果库不会自动迁移引用。保留源库和备份，必要时从目标库重新创建引用。

复用不会重新执行原记录的上游流程，也不因原文件后来修改而更新已有结果。结果库保存的是当次运行的输出与说明；修改参数后需重新运行，再选择新记录。

<a id="bound"></a>
## 通用序列输入

“输入序列”是内部绑定入口，在一些既有流程中可能出现，不是文本导入对话框或空白表格编辑器。它直接输出执行环境绑定的序列，不排序、不换单位、不重新读取原始文件。

该入口在普通任务目录中隐藏。遇到缺少绑定或类型错误时，检查流程的数据来源，或通过文件导入／结果复用等实际入口重新建立流程；仅添加同名节点不能恢复丢失的数据。

<a id="odp"></a>
## 五项 ODP 示例记录

内置记录用于熟悉操作和可复核示例，不需要联网下载。默认 X 使用已发表年龄，也可选择复合深度。切换轴使用数据表中的对应列，不是运行新的年龄模型；不额外重采样。

| 入口 | 数据与年龄说明 |
| --- | --- |
| ODP 846 · 氧同位素、碳同位素 | PANGAEA.60254，Mix 等（1995）；数据档案本身含作者插值值，不能称为未经处理的原始测量 |
| ODP 1143 · 氧同位素 | PANGAEA.132801，Tian 等（2002）；已发表天文调谐年代，档案值在 C. wuellerstorfi 标度，Aster 不再追加种属校正 |
| ODP 926B · 碳同位素、亮度 L* | PANGAEA.743431，Pälike 等（2006）；年龄采用重新调整到 La2004 的可选年龄列，不是旧 La1993 列；程序不额外转换年龄零点 |

同一站点不同指标可能因所选 X/Y 缺失而保留不同样本；省略数量记录在来源报告中，不能默认两条曲线可以按行一一配对。已发表采样位置不一定等间隔，运行 FFT、MTM 或交叉谱前需检查实际坐标。

年龄轴可能已包含天文调谐，因此与轨道周期的一致性不是独立的天文成因证据。结果“来源”保留所用字段、数据引用、单位、缺失处理和采样说明。完整源表、目录元数据与 CC BY 3.0 许可随项目保留；正式使用请引用数据及对应论文。

数据档案：[ODP 846](https://doi.org/10.1594/PANGAEA.60254)、[ODP 1143](https://doi.org/10.1594/PANGAEA.132801)、[ODP 926B](https://doi.org/10.1594/PANGAEA.743431)。轨道数据另见[天文曲线指南](astronomy_usage.md)。

<a id="sine"></a>
## 正弦信号

用于核对周期、趋势处理和频谱操作。生成式为：

`X[i] = i × 采样间隔`，`Y[i] = 振幅 × sin(2πX[i]/周期) + 斜率 × X[i]`。

起点固定为 0，末点为 (样本数−1)×间隔；周期和间隔使用同一任意 X 单位，斜率为每个 X 单位的 Y 变化。输出没有随机噪声。默认斜率 0.15，因此默认曲线不是纯正弦；需要纯正弦时设斜率为 0。

例如 512 点、间隔 0.25、周期 4、振幅 2、斜率 0，理论正频率为 0.25。谱峰宽度与实际估计方法、窗和记录长度有关，不能要求所有方法输出一个无限窄峰。周期应由足够的采样点覆盖；参数合法不保证采样足以分辨该周期。

<a id="synthetic"></a>
## 合成轨道代理信号

该源构造包含五个岁差项、五个偏心率差频项、变沉积速率和 AR1 噪声的模拟记录，用于对比处理方法。它不是实际轨道解、实测 ODP 代理记录或独立测年结果。

默认采用 ODP 1260 的不等间隔深度模板，仅借用深度位置，不读取该站代理值。选择“等间隔深度”后，起始深度、厚度和点数才生效；网格包含两端，间隔为厚度/(点数−1)。默认模板下隐藏的这三个参数不会改变模板。

速率最小值必须严格小于最大值，单位 cm/kyr（与 cm/ka 的时长尺度相同）。模型生成平滑的逆速率变化，再在实际深度网格积分。真实相对年龄从第一个深度处的 0 ka 开始，没有绝对年代基准。改变网格或速率范围会改变时长和信号的深度域形态。

“信噪比”是干净信号方差／噪声方差，默认 2，不是振幅比或分贝。AR1 rho 表示相邻样本之间的相关，默认 0.5；不等间隔模板下不代表固定时间或深度距离上的相关。相同版本、种子、实现编号与设置便于复现；实现编号用于生成另一条随机记录。相同整数种子不保证与 Python/NumPy 或其他软件生成相同数据。

| 输出 | 含义 |
| --- | --- |
| `series` | 带噪代理值随深度的变化，合成后再标准化 |
| `clean_signal` | 总体方差为 1 的干净信号，X 为深度 |
| `scaled_noise` | 按信噪比缩放后的 AR1 噪声，X 为深度 |
| `age_model` | 深度—真实相对年龄（ka） |
| `sedimentation_rate` | 深度—真实速率（cm/kyr） |
| `time_series` | 与 `series` 相同的带噪 Y，以真实相对年龄为 X |
| `harmonics` | 实际频率、周期及干净信号标准化前的正弦／余弦系数 |

三个信号输出不能直接按“series = clean_signal + scaled_noise”复核，因为两者相加后还进行了标准化。报告保存合成前的均值和标准差；若要重建带噪序列，应使用这些量。具体为 (clean_signal + scaled_noise − raw_mean) / raw_sd。

等间隔深度不保证等间隔年龄，不等间隔模板也不能直接当作 FFT 输入。比较算法时，应统一横轴、采样和预处理，并保留真实年龄与周期表作为对照。参数变化的响应仅说明本合成模型中的行为，不能据此证明真实地层满足该模型。

模型移植与许可见随源码提供的 [NOTICE](../../resources/synthetic/NOTICE.md)；模板来源为 PANGAEA.817206。程序运行不需要安装 Python。
