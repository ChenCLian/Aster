# COCO 固定目标扫描

本文说明输入、输出、数学约定与适用范围。验证批次、环境和范围见 [验证记录](../validation.md)。

## 使用与输出

输入是等间隔、严格递增的深度—代理指标序列。深度单位显式选择；非空元数据必须匹配。没有单位的文件可由用户明确声明，结果保留警告。没有隐式排序、插值、LOWESS 或背景扣除。

来源单位 `mcd`、`rmcd` 按米制长度尺度与 `m` 匹配，来源元数据中的深度基准保持不变；这不代表不同深度基准已经对齐。年龄轴不能代替深度轴，重采样也不执行年龄—深度转换。

1. 导入数据，确认 X 是深度及其单位。
2. 加入 COCO 固定目标扫描。按研究年代选择周期；默认的近现代 7 周期不是全地质时期通用值。
3. 确定候选速率范围及步长、频带上限。预览和正式运行使用同一任务。
4. 查看相关性曲线，并检查诊断表中排除的候选。查看最佳候选的观测谱、目标谱与目标参数；可用现有结果绘图功能比较两条谱。

| 输出键 | 内容与单位 |
| --- | --- |
| `correlation` | 有效候选速率 cm/ka 与 Pearson 相关系数，不含无效占位行 |
| `scan_diagnostics` | 完整扫描网格、状态、可用标记、相关系数、范围内目标数、Rayleigh/Nyquist、比较频点数 |
| `best_observed` | 最高相关的有效候选对应的时间频谱，各自最大值归一为 1 |
| `best_target` | 同一候选、同一频点上的目标谱，各自最大值归一为 1 |
| `target_periods` | 实际周期 ka、频率 1/ka、相对功率；模型周期也按实际值保存 |

最佳速率、相关系数、实际扫描端点、完整参数、目标定义和范围检查规则同时进入任务报告与数据库。输出均可导出 CSV。没有自动生成年龄模型；不要把最佳匹配值直接称作已验证的沉积速率。

诊断状态：0=可用；1=频带上限超出 Nyquist；2=目标越过 Rayleigh/可用频点不足；3=常数频谱。COCO 扫描表沿用数值占位与可用性标志的输出约定：排除行的相关系数以 0 占位，**必须结合可用=1 使用**；这些占位值不进入曲线或最优值选择。
## 单一来源的默认值

| 参数 | 默认 | 约定 |
| --- | --- | --- |
| 深度单位 | m | 支持 m/dm/cm/mm/ft/km；内部统一换算 m |
| 周期来源 | 手动 | 默认 405,125,95,41,24,22,19 ka，仅为近现代示例 |
| 相对功率 | 1,1,1,0.64,0.36,0.36,0.36 | 是功率而非振幅；等价振幅 1,1,1,0.8,0.6,0.6,0.6 |
| Waltham 年龄 | 300 Ma | 仅选择模型时生效；取 E405/E124/E95/倾角/P1/P2/P4 中点 |
| 速率 | 0.5–20，步长 0.1 cm/ka | `min + k*step <= max`；不拼接不在网格上的最大值 |
| 频带 | (0,0.06] 1/ka | 排除 DC；需覆盖所有目标，古老短岁差可能需提高上限 |
| 补零 | 2 倍 | FFT 为不小于 2N 的 2 次幂；不提高 Rayleigh 分辨率 |
| 频谱前处理 | 去均值 | 可选不处理/线性去趋势；数据和目标基函数用同一规则 |

Task 描述负责界面和执行默认值；中英文资源只提供文字。设置面板与结果存储复用通用接口。
## 数学定义与核对边界

令候选速率为 `r` cm/ka，均匀深度间距为 `dx` m：

- 时间间距 `dt = 100*dx/r` ka；数据频率 `f_k = k*r/(100*nfft*dx)`。
- Rayleigh = `r/(100*N*dx)`，Nyquist = `r/(200*dx)`。
- 数据为矩形窗、单边周期图；统一 PSD 比例因子在 Pearson 相关中抵消。保留单边 DC/Nyquist 权重，比较时排除 DC。
- 对目标周期 P、相对功率 w，计算同 N、同补零及同去趋势方式的 `w/2 * (|FFT(sin(2πt/P))|² + |FFT(cos(2πt/P))|²)`，各目标求和，再用相同单边权重。
- 这等于独立均匀相位的谐波组合的**期望周期图**。证明来自 `sin(a+φ)=sin(a)cosφ+cos(a)sinφ`、均匀相位的二阶矩及不同分量交叉项期望为零。去均值/线性去趋势和 FFT 都是线性算子，因此结论也适用于选定的前处理。
- 该目标不需要给任意深度起点指定天文相位；它也不表示现实数据的相位独立性已被证明。目标是一项明确、可替换的匹配假设。
- 在候选的实际非 DC 频率网格上计算观测功率与目标功率的 Pearson 相关系数。没有跨采样范围外推或比较不同长度数组。
- 仅当完整比较频带处于 Nyquist 内、全部目标频率落在 Rayleigh–Nyquist 范围、至少 8 个比较频点时参与排名。相邻两个目标仍可能无法相互分辨，“范围内目标数”不是检出的天文周期数，也不是独立自由度。
- 同分时保留较小的扫描速率；显示谱的独立最大值归一只影响显示和导出幅值，不改变计算的相关系数。

参考 Li et al. (2018), *EPSL* 501,165–179, [DOI](https://doi.org/10.1016/j.epsl.2018.08.041) 的功率谱相关和单位关系，并检查 [Acycle 官方 COCO 说明](https://github.com/mingsongli/acycle/wiki/4.7.12-Correlation-Coefficient-(COCO)) 与验证使用的源码快照。该参照为修改快照，与官方原始发行版区分。

与 Acycle 的区别公开如下：

- 保留核心的候选沉积速率换算和功率谱 Pearson 相关。默认谐波振幅分组参考 `period2spectrum.m`，本任务显式输入其平方即功率。
- 该模块固定目标是上述相位平均，不是 La2004 原始片段的谱，也不是 `period2spectrum` 固定零相位叠加后的谱或自适应调权目标。因此**结果不保证逐点等于 Acycle COCO 输出**。
- 采用完整频带/目标范围检查，并保留所有排除原因；不会用少数落在可见范围的目标隐式替代整套目标。
- 不输出普通相关系数 t 检验 p 值、Fisher 置信区间，也不把多个候选的最大值当作未经搜索的单次检验。补零谱点并不独立。
- 固定目标扫描本身不计算蒙特卡洛 p 值。需要模拟检验时使用独立的 [COCO 蒙特卡洛任务](coco_analysis.md)，并核对零模型、预处理和扫描后选择的校正范围；单凭扫描相关峰不能认定显著天文驱动。
