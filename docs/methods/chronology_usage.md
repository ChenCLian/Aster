# 年代模型与逐周期赋龄：使用说明

这些任务分别负责速率积分、应用控制表和周期计数。它们不自动搜索最优年龄模型。先阅读共用的[坐标与年代基准](../concepts/chronology_coordinates.md)。

<a id="rate"></a>
## 沉积速率转年龄

输入 X 是深度，Y 是该位置的沉积速率；不能把代理指标直接作为速率。至少需要两个样本，X 严格递增，全部速率有限且大于零，包括最后一行。

先指定深度、速率和年龄单位，再设置第一个实际深度处的年龄。默认按左端速率计算每个区间：深度为米、速率为 cm/ka 时，年龄增量为 100 × 深度增量 / 左端速率。

例如深度 10、11、13 m，速率 2、2、999 cm/ka，首年龄 7 ka，左端规则得到 7、57、157 ka。最后一个速率仍被校验，但左端规则不使用它计算区间。

“速率线性变化”假设速率随深度线性变化，再积分速率的倒数；不是取两端速率平均值后相除。根据速率数据的含义选择规则，不能仅凭输出更平滑选择。

输出是深度—年龄曲线 `age_model`。零速率不能用来表示沉积间断。积分与单位细节见[方法定义](chronology.md)。

<a id="apply"></a>
## 应用年龄模型

主输入是深度—代理指标序列。年龄模型从参数中的控制表文件读取，不是通过第二个配对输入端口连接。

1. 选择控制表，核对分隔符、表头以及深度列和年龄列；默认取第 1、2 列。
2. 明确输入深度单位、表内深度单位、表内年龄单位及年龄基准；不从列标题自动猜单位。
3. 检查控制深度和年龄均严格递增、至少两个控制点；表中无效行不会静默跳过。
4. 确认模型覆盖整个输入。默认超界报错；端部线性外推须显式选择。
5. 运行后查看年龄轴、控制点和区间速率，再决定后续是否重采样。

| 输出 | 如何使用 |
| --- | --- |
| `aged_series` | 年龄 X 与原始 Y；样本数不变 |
| `age_model` | 本次实际采用的控制点 |
| `age_intervals` | 控制区间边界与区间速率，便于检查异常变化 |

<a id="linked-controls"></a>

### 直接连接控制点

在模型节点右边点击“＋”，添加“应用年龄模型（连接控制点）”。A 选择要赋龄的深度代理序列，B 选择模型的 `age_model` 输出。“管理配对”中能选择同一记录的其他处理步骤，或选择另一条数据树中的记录。沉积速率和代理数值往往来自不同序列，需要明确选择对应关系。

从“峰谷逐周期赋龄”添加时，已有记录按同一数据身份连接模型与传给周期计数的代理序列。也可在“管理配对”改选未滤波的原始代理。合成轨道数据可直接连接其代理与真实模型。模型之间采用离散控制点的分段线性插值。输出保留原代理值、模型年龄单位和年代基准。无深度单位的代理需先声明单位。默认遇到控制范围外的点会停止该节点，可显式选择线性外推。

峰谷标记通常位于记录内部。若要给整条序列赋龄，请先核对首末控制深度。可以选择只分析标记覆盖的区间，或在有地质依据时启用“延伸到输入端点”或线性外推。

外部控制点文件仍可通过“应用年龄模型”导入。

外部文件修改后的重算与结果保存见[文件约定](../concepts/chronology_coordinates.md#files)。当前控制表最多 4 MiB、100000 个控制点，输入最多 100 万点；超过限制应检查文件内容与必要精度，不要仅删除控制点以规避诊断。

<a id="cycles"></a>
## 逐周期赋龄

适用于已有地质依据、可以识别同相位周期标记的深度序列。节点不自动滤波、排序或重采样；需要的预处理应显式配置并检查其影响。

选择峰或谷，并设置周期长度。手动周期采用所选年龄单位；模型周期从 ka 换算到该单位。默认手动周期为 41 ka、首标记年龄为一个完整周期，因此首标记不是默认 0。需要绝对年龄或其他起点时选择指定首年龄。

先用最小局部起伏排除弱标记，再用最小深度间距限制过密标记。局部起伏采用邻近同类极值之间的谷／峰关系，不等同于频谱峰的突出度；间距单位是深度，不是频点或年龄。平台取中间样本，偶数长度取靠前者；触及输入端点的平台不作为内部标记。

| 输出 | 检查重点 |
| --- | --- |
| `selected_extrema` | 回到原信号检查是否漏峰、多峰或把噪声当成周期 |
| `cycle_anchors` | 原始样本序号、深度、数值、赋龄及局部起伏 |
| `age_model` | 相邻同相位标记之间恰好增加一个周期 |
| `interval_rates` | 由标记间距与固定周期得到的区间速率 |

至少需要两个有效内部标记。默认模型止于首尾标记，因此通常不覆盖原输入两端；随后应用模型时，应显式裁剪或有依据地外推。启用“延伸至输入两端”使用首尾标记区间的年龄斜率延长。

漏掉一个周期或额外识别一个标记都会改变赋龄。程序不自动推断遗漏数；调谐后出现目标周期也不能作为调谐正确的独立证据。模型周期包络不会自动传播为年龄不确定性。详见[逐周期方法](cycle_tuning.md)。

<a id="periods"></a>
## 米兰科维奇目标周期

这是独立数据源，无需输入序列。按指定地质年龄计算 Waltham 模型的周期包络，供选取目标周期和比较使用，不生成天文相位曲线。

默认年龄 300 Ma、组分为地轴倾角；输出周期用 ka。主表给出下界、中点和上界，中点是上下界的算术平均，不是最可能值；包络不是 95% 置信区间。偏心率组分使用固定周期表，不能因为输入年龄改变就认为它们也随年龄演化。

逐周期赋龄使用指定年龄下的一个固定周期；COCO 模型目标也采用相应中点。它们不会沿记录自动更新地质年龄并迭代周期。实际采用的目标应随结果一并检查。公式、来源及其余输出见[目标周期定义](cycle_tuning.md)。
