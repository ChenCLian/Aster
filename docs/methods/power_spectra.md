# FFT、Welch 与演化功率谱

[共用概念与参数](../concepts/spectral_parameters.md) · [方法目录](README.md) · [English](power_spectra_en.md)

本页说明整段 FFT、Welch、演化 FFT 和演化 MTM 的使用方式。它们都要求有限、严格递增且等间隔的 X/Y 序列，不自动排序、插值或重采样；输入有问题时先用[采样检查](preprocessing.md#inspection)。

| 想了解的问题 | 可用任务 | 输出 |
| --- | --- | --- |
| 整条记录的周期结构 | FFT 功率谱 | 整段单边 PSD |
| 将多个分析段的谱平均 | Welch 功率谱 | 各完整段 PSD 的算术平均 |
| 周期结构随时间／深度怎样变化 | 演化 FFT 功率谱 | 滑窗功率图和窗口平均谱 |
| 用多窗谱估计观察位置变化 | 演化 MTM 功率谱 | 各位置的自适应 MTM 功率图和窗口平均谱 |

四个任务的这些输出均为描述性结果，不提供 p 值或频谱／整图显著性阈值。演化 MTM 不继承独立 MTM 任务中的全部检验输出。

<a id="fft"></a>
## FFT 功率谱

使用整条输入作为一个分析段，至少需要 8 个样本。默认去均值、周期 Hann 窗，FFT 点数 0 表示输入长度；指定值不得短于输入。输出频率从零到可计算的最高单边频点。

先确认输入区段和去趋势方式，再选择窗函数；希望更密地读取峰附近的频率时，可增加 FFT 点数。补零、窗函数和单位的含义见[公共参数说明](../concepts/spectral_parameters.md#fft-padding)。输出 `spectrum` 的数值是 PSD，不是 FFT 复数系数或信号振幅。

详细默认值与范围：[FFT 参数](../reference/task_parameters.md#m-fft_spectrum)。

<a id="welch"></a>
## Welch 功率谱

默认每段 256 点、重叠 128 点，逐段去均值、周期 Hann 窗。段长不能大于当前输入，重叠必须小于段长。默认设置对短于 256 点的输入会报错，应根据研究尺度主动减小段长，同时检查重叠点数。

先选择段长，再选择重叠，最后设置 FFT 点数。FFT 0 表示使用段长，指定值不得小于段长。加长分析段有助于区分相邻频率，但同一输入可用于平均的段数通常变少；缩短分析段会增加平均的机会，同时降低单段的频率分辨能力。重叠段并非独立观测，不能把段数直接当作独立样本数。

只平均完整段，不在尾部补齐新段。例如输入 705 点、段长 128、重叠 64，则步长 64，共 10 段；最后使用到从 0 计数的第 703 个位置，剩余 1 个样本记入报告。这里的数值只是换算例子。

输出 `spectrum` 为各段 PSD 的算术平均，不保存逐段时频矩阵。希望查看功率随位置变化，应选择演化谱。报告记录实际段数、重叠、FFT 点数和尾部未用样本。

详细参数：[Welch 参数](../reference/task_parameters.md#m-welch_spectrum)。

<a id="evolution-settings"></a>
## 演化 FFT 与演化 MTM：设置顺序

### 1. 先确定分析窗口

新建演化 FFT 默认采用输入跨度的 20%、目标 500 个窗口及 4 倍 FFT；演化 MTM 仍默认窗口 128 点、步长 16 点、FFT 0。窗口至少 8 点且不得超过输入长度。当前输入是经过上游处理后的数据，而不是最初导入文件的行数。

选择输入跨度百分比 p 时，当前实现按 `L=round((N−1)×p/100)` 换算窗口点数，正数半值向上取整；少于 8 点时报错，不自动扩窗。窗口实际首末跨度仍为 `(L−1)×Δx`。因此输入 100% 会得到 N−1 点窗口，并不等同于整段 FFT；要明确覆盖全部 N 点，应选择点数模式并填写 N。

### 2. 再确定窗口位置密度

- 点数模式：直接指定整数步长 S，要求 `1≤S≤L`。
- 重叠率模式：`S=max(1,round(L×(1−重叠率/100)))`；实际重叠率以报告为准。
- 目标窗口数模式：输入目标 K≥2，取 `S=max(1,ceil((N−L)/(K−1)))`；实际完整窗口数不超过 K。整数取整后可能明显少于目标，不重复窗口凑数。

例如 N=1001、L=200、K=500，得到步长 2、401 个窗口、实际重叠 99%，尾部 1 个样本未使用。目标过小导致 S>L 时会报错，并提示最小可行目标数；不会自动跳过窗口之间的区段。

### 3. 选择谱估计设置

演化 FFT 可选周期 Hann 或矩形窗；演化 MTM 使用 DPSS 多窗、自适应谱估计。MTM 的 NW 可取 1，或 1.25～32，且须小于 L/2；NW=1 时使用 2 个窗，其他情况使用 `round(2×NW)−1` 个窗。NW 不是滑动窗口数量，较大 NW 通常增加谱平滑，也可能使邻近峰更难分开。

两种任务均可逐窗去均值或线性去趋势；FFT 长度可直接指定，也可用窗口点数的整数倍数。整数倍数 1 等于不补零，较大倍数加密频率网格。含义见[去趋势与窗函数](../concepts/spectral_parameters.md#taper-trend)和[FFT 补零](../concepts/spectral_parameters.md#fft-padding)。

### 4. 确认频带与是否归一化

频率上限使用 X 单位的倒数，0 自动使用奈奎斯特范围；超出奈奎斯特的设置会被限制，太低而不足两个输出频点时会报错。旧流程若保留历史频率比例，明确编辑该字段（包括确认 0）才清除旧比例。实际最高输出频点以报告为准，不一定恰好等于请求值。

新建演化 FFT 默认开启逐窗归一化，演化 MTM 默认关闭。比较窗口间绝对功率时保留 PSD，并确认单位及处理设置一致；比较谱形时可归一化，但不能再从颜色判断原始强弱。原理集中见[归一化说明](../concepts/spectral_parameters.md#normalization)。

<a id="evolution-output"></a>
## 演化谱输出与实际参数

`power_map` 的横坐标为窗口首末 X 的中点，纵坐标为频率；内部网格按频率行、窗口列存储。只计算完整窗口，因此图的坐标范围通常不覆盖原数据两端。窗口中心不是单个样本的瞬时测量位置。

`mean_spectrum` 是各窗口输出功率的算术平均。开启逐窗归一化后，它平均相对功率；否则平均 PSD。它不等于整段输入直接计算的频谱，开启平方根显示也不会将平均谱改为平均振幅。

预览成功后，“即时预览”列下半部分、节点输出选择框与图像之间显示实际窗口、步长、重叠率和 FFT 点数；悬停显示窗口数、跨度和尾部信息。参数变化后等待新预览更新。计算报告也保留这些数值，复现时优先核对实际值，而不只是界面上的百分比。

<a id="preset"></a>
## 演化 FFT 预设怎样使用

新建演化 FFT 直接使用这组默认配置：20% 输入跨度、目标 500 个窗口、4 倍 FFT、线性去趋势、矩形窗、逐窗归一化及功率平方根的平滑显示，频率上限 0（自动）。无需点击预设按钮，各参数仍可修改。演化 MTM 不采用这组默认值。

保存的是百分比、目标数量、倍率等规则，每次预览和正式运行都按当前数据在本节点的实际输入重新换算。未打开过面板的数据也按相同规则处理；批量应用不复制其他数据已算出的点数。窗口仍须至少 8 点，短输入会给出明确错误，不会静默改换算法或窗口。

“恢复默认参数”只恢复当前数据／配对在本节点的设置，包含自动频率上限；需要恢复整个流程本节点时，再点击下方批量按钮。旧流程已经保存的明确设置保持不变；旧参数只有固定点数而缺少模式字段时，继续按固定点数解释。详见[参数作用范围与自动设置](../USER_GUIDE.md#parameter-scope)。

先检查 20% 窗口是否容纳目标周期，再检查实际窗口数量和资源消耗。500 是目标数量上限，不是所有输入都会生成 500 个窗口。预设包含计算选项和显示选项，不能把变化全部解释为“平滑”。

部分选择参考 Acycle LAH，不代表所有版本默认值或边界处理一致。Aster 不在整条序列两端补零，不自动重采样，也不添加二维平滑滤波。跨软件比较先统一数值与坐标，再统一[显示设置](../concepts/spectral_parameters.md#display)；来源和既有验证范围保留在[方法对照](acycle_compatibility.md)。

<a id="limits"></a>
## 参数错误与计算规模

| 现象 | 首先检查 |
| --- | --- |
| 输入不等间隔／不递增 | X 单位、采样检查和明确配置的预处理，勿只增加 FFT 点数 |
| 窗口超长或不足 8 点 | 当前节点实际输入及百分比换算；先确定研究尺度 |
| 步长超过窗口／目标过小 | 增加目标数或窗口长度，按诊断核对可行组合 |
| FFT 点数小于窗口／段长 | 增大 FFT 点数或使用 0；0 的含义随任务而变 |
| 输出频带不足两个点 | 频率单位与上限；不要把周期数值直接填入频率框 |
| 网格或计算预算超限 | 根据报错减少窗口数、FFT 长度或输入规模；裁剪频带仅减少输出网格，不能缩短 FFT |

当前输入最多 100 万点、FFT 最多 262144 点、完整窗口最多 20000 个；演化图最多 200 万个网格单元。工作预算为 `窗口数×FFT点数×窗函数数≤1亿`，FFT 估计的窗函数数为 1，MTM 为实际 DPSS 数量；MTM 另有工作区限制。这些是程序上限，不是推荐设置，也不承诺达到上限时仍快速完成。

单段 FFT 的 FFT 长度不得短于整段输入，因而还受 262144 点上限约束。频带裁剪不降低上述工作预算乘积。遇到 MTM 未收敛警告时应查看报告并检查估计设置，不把该窗口自动当作已可靠收敛。

默认值和精确参数范围：[演化 FFT](../reference/task_parameters.md#m-evolution_fft) · [演化 MTM](../reference/task_parameters.md#m-evolution_mtm)。

<a id="band-power"></a>

## 周期带功率积分

在 MTM、FFT 或 Welch 的实测功率谱后添加本节点。演化谱可选择未逐窗归一化的 `mean_spectrum`，数据库中复用的实测谱也可接入。填写目标带的两个边界；参考带默认取上游实际发布的全谱，跨记录比较时可给各条记录设置相同参考带。两组边界使用同一个输入方式。例：原始时间以 ka 记录，目标周期 90–130 对应频率 1/130 至 1/90 每 ka；原坐标无单位时直接使用数值。

在频率轴上对线性功率谱密度分段作梯形积分，部分覆盖的首末频率间隔按线性插值处理。频率边界不会外推。输出表列出实际频率范围、目标功率、参考功率、功率比与百分比。分母为零会返回诊断。目标带宽须至少达到一个 Rayleigh 频率，其非零下界也须达到该频率。FFT 和 MTM 用记录长度，Welch 和演化谱用实际窗口长度计算这个下限，补零不会提高它。此项是基本分辨率检查，窗函数和 MTM 的平滑仍影响相邻峰的分离。积分占比是描述量。
