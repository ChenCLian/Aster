# COCO：目标设置、扫描与结果解释

COCO 在候选沉积速率下，将输入空间频谱与固定目标周期的谱形进行比较。它帮助比较候选速率，不直接建立年龄模型，也不验证天文成因。

<a id="inputs"></a>
## 输入和准备

输入必须是 X 严格递增、等间隔的深度—代理指标序列。节点不自动整理、插值或进行 LOWESS 背景去除。先检查采样和[深度单位](../concepts/chronology_coordinates.md#units)；年龄序列不能仅改名为深度后输入。

建议先运行固定目标扫描检查可用候选、频带和目标，再决定是否进行蒙特卡洛检验。上游滤波或插值会影响频谱与噪声结构，检验时不能忽略。

<a id="targets"></a>
## 目标周期、功率与比较范围

默认手动周期 405、125、95、41、24、22、19 ka 只是近现代周期示例，不是所有地质年龄的通用参数。模型目标使用指定年龄下的周期中点；它提供周期位置，不提供真实天文相位。

相对权重表示功率，不是正弦振幅。默认 1、1、1、0.64、0.36、0.36、0.36 与七个目标依次对应。改变周期列表时同步检查权重数量和含义。

速率范围默认 0.5–20 cm/ka、步长 0.1；按“最小值 + 整数 × 步长”取候选，不强行追加不在网格上的最大值。范围应有地质依据，细化步长不会产生新的独立证据。

比较频带默认为 (0, 0.06] 1/ka，排除零频率，必须包含全部目标，目标频率须严格小于频带上限。每个候选还须满足目标频率不低于 Rayleigh 频率且严格低于奈奎斯特频率、整个比较带不超奈奎斯特频率、至少有 8 个比较频点。增加补零只加密频率网格，不能解决记录长度不足。共用解释见[FFT 补零](../concepts/spectral_parameters.md#fft-padding)。

<a id="scan"></a>
## 固定目标扫描：先看诊断，再看最高相关

颜色或曲线值是 Pearson 相关，可为负。目标采用正弦／余弦功率的相位平均，不等于把某一真实轨道解按任意相位叠加。

| 输出 | 解释 |
| --- | --- |
| `correlation` | 有效候选的原始相关曲线 |
| `scan_diagnostics` | 完整候选网格、可用标记、排除原因及频带诊断 |
| `best_observed`、`best_target` | 最佳有效候选的观测谱和目标谱，各自按最大值归一化 |
| `target_periods` | 实际目标周期、频率及相对功率 |

诊断表中不可用相关的数值 0 是占位，必须结合可用标记解释，不能当作实测零相关。最高相关相同时选较小速率。独立归一化的两条最佳谱用于比较形状，不能比较绝对功率。

固定扫描不提供 p 值；最高相关也不是沉积速率置信区间。公式与状态码见[固定扫描定义](coco_scan.md)。

<a id="monte-carlo"></a>
## 蒙特卡洛：先声明模型，再选择 p 值

默认零模型是固定参数 Gaussian AR1，rho=0，即白噪声。程序不从输入自动拟合 rho。若从同一记录先估计 rho 再填入，结果属于代入参数模拟，不再满足独立指定参数的简单零假设前提。上游处理不会在模拟中重放。

“随机谱峰”是另一种参考模型，不是完整时序噪声模型；自动峰数还来自观测谱。因此其结果称为参考 p，不能据此保证任意红噪声下的误报率。公共统计概念见[背景模型](../concepts/statistical_interpretation.md#background)。

| 输出 | 适用问题 |
| --- | --- |
| `pointwise_p` | 事先指定的某个候选速率在声明模型下如何 |
| `scan_adjusted_p` | 考虑本次固定速率扫描后，该候选的正相关有多突出 |
| `mc_summary` 中的全扫描 p | 本次扫描的最大正相关有多突出 |
| `null_maxima` | 每次模拟的最大正相关，供复核 |

先搜索最高相关再解释时，应查看全扫描或扫描校正 p。校正不覆盖反复修改周期、权重、频带、速率范围、多文件选择或整张滑窗图；p 值也不表示某个速率为真的概率。

默认 B=199、种子 1729、alpha=0.05。使用非零计数公式，最小 p 为 1/(B+1)：199 次时为 0.005。alpha 不能低于该分辨率。增加次数改善模拟分辨率，不保证 p 更小，也不修正错误的零模型。固定种子便于复核，不应用于反复挑选较小 p。

统计量只计正相关证据。没有正匹配证据时 p=1；整条曲线为 1 不一定是故障。原始相关仍可为负。允许次数为 19–20000，但更大输入和更密速率网格还受工作量预算限制；按诊断给出的允许规模调整，不应把次数上限理解成所有配置都能运行。完整定义见[蒙特卡洛与 eCOCO](coco_analysis.md)。

<a id="evolution"></a>
## 滑窗 eCOCO：读取局部匹配图

默认窗口 512 点、步长 128 点，只计算完整窗口。至少需要两个窗口和两个可用速率；窗口必须足够长，能分辨选定目标。尾部不足一个完整窗口的样本不会补齐，其数量记录在报告中。

热图 X 为窗口实际首尾深度的中点，Y 为 cm/ka，颜色为原始相关，不按每列另行归一化。最佳速率线是各窗口独立选择的最大相关位置，可以跳变；没有路径平滑或自动生成年龄模型。

`window_diagnostics` 给出实际窗口边界与最佳候选，`rate_diagnostics` 给出各窗共用的速率可用性。`best_correlation` 可帮助判断“最佳”是否仅仅是较弱匹配中的最大值。

eCOCO 不提供显著性检验。相邻窗口重叠、相邻候选速率也相关，不能把连续色带当成多次独立证据。无方差窗口会报错并指出位置，不会悄悄跳过或涂成零相关。热图最多 512 个窗口、200 万格，仍受工作量限制。
