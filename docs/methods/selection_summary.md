# 选段与序列摘要

这两个任务分别改变保留的样本范围、汇总 Y 值。它们不重采样、不修复缺失值，也不执行频谱分析。需要检查 X 顺序、重复或大间隔时，使用[采样与间隔检查](preprocessing.md#inspection-output)。

<a id="interval"></a>
## 选择或移除区间

按当前输入的 X 数值指定下限和上限，要求下限不大于上限。边界值包含在区间内：保留模式保留 `下限 ≤ X ≤ 上限`，移除模式删除这些样本。

范围采用当前 X 单位；若上游已经换成年龄轴，应填写年龄，不能继续使用原深度。默认范围 0–1 只是初始值，运行前应改成需要的区间。下限等于上限时只匹配恰好等于该值的样本。

只筛选已有样本，保留顺序、X/Y 数值和轴说明。不在边界插值，不把首点重新设为零，也不裁剪磁盘文件。一个边界落在两样本之间时，结果从区间内最近的已有样本开始或结束；没有样本剩余会报错。

移除中间区间会留下真实的 X 空缺，并不会把两侧拼成连续等间隔记录。后续任务若要求等间隔输入，应重新检查采样，不宜仅为让任务运行而填平有地质意义的间断。

输出 `series` 是筛选后的序列；报告记录操作、边界和保留／移除数量。观察图形时注意折线可能跨越空缺连接，连续的线不代表空缺处有观测值。

<a id="summary"></a>
## 序列摘要

对当前输入 Y 计算一行数值表，适合比较处理前后的样本数、中心位置与离散程度。默认输出是表格，不显示曲线是正常结果；在输出选择器查看 `summary`。

| 列 | 定义 |
| --- | --- |
| `count` | 当前输入的 Y 样本数 |
| `mean` | 所有 Y 等权的算术平均 |
| `population_variance` | 以 N 为分母的总体方差，不是 N−1 样本方差 |
| `minimum`、`maximum` | 当前 Y 的最小值和最大值 |

最少一个样本；单点方差为 0。该任务不按 X 间隔加权，因此不等间隔数据中的密集区对均值贡献更大；均值不能直接当成整个时段的时间平均。方差的物理量纲是 Y 单位的平方，均值与极值仍是 Y 的量纲。

摘要不包含中位数、置信区间、标准误或采样质量判断；不要从这五列推断它们。需要保留序列继续计算时，可从上游节点另建分支；摘要表不能直接连接只接受序列的任务。

若用于比较处理效果，检查两条分支是否保留相同样本范围。均值或方差变化既可能来自处理，也可能来自选段或删除样本。
