# Gaussian、Taner 与 Hilbert

本文说明输入、输出、数学约定与适用范围。验证批次、环境和范围见 [验证记录](../validation.md)。

## 从界面使用

- `数据处理 → 滤波 → Gaussian 带通与包络` / `Taner 带通与包络`：默认输出 `filtered`，另有 `envelope` 和 `filter_response`。
- `分析 → 幅度 → Hilbert 振幅包络`：独立计算上游所选序列的包络；默认不去均值，不擅自加带通任务。另有正交分量 `quadrature`。
- `数据源 → 天文曲线 → 日照与季节积分 → La2004 多纬度日照图`：独立根节点，不需要导入文件；支持热图、色阶、CSV 和图片导出。

带通任务已经给出包络，所以普通用途无需再加 Hilbert；独立 Hilbert 用于其他上游序列。若特意连接 `Taner(filtered) → Hilbert`，其包络应与 Taner 自带包络相同。连接其他端口时严格使用用户选择的那个端口。

即时预览/结果页用输出选择框分别查看滤波曲线、包络和响应，不把频率轴上的响应默认叠到时间轴上。正式运行将具名输出和参数保存到结果库，可按记录 ID 与执行步骤回读；即时预览不写入数据库。
## 数学和参考版本

**验证参照：**验证归档 `Acycle_3.1.1.zip` 中 `acycleBandpassFilter.m`、`gaussfilter.m`、`tanerhilbertML.m` 已注明 `corrected-bandpass-v2`。数值参照为该修改快照，与官方原始发行版区分。文件 SHA256 记录在 docs/reference/scientific_evidence.json 的 filter_reference 中。未将其 MATLAB 源码复制到产品中。

令 `fl < fh`，`fc=(fl+fh)/2`，`b=(fh-fl)/2`，`a=ln(2)/2`。

- Gaussian：`H(f)=exp(-a*((|f|-fc)/b)^2)`。
- 验证快照中的 Taner 形式：`H(f)=exp(-a*(abs(|f|-fc)/b)^p)`，`p=log2(1+q*ln(10)/a)`，`c=10^q`。默认 `q=12`，支持 `(0,20]`；**q 不等于 dB/倍频程**。
- 两者在中心增益为 1，在上下限处幅度增益为 `1/sqrt(2)`，功率为 1/2。这里的上下限不是硬截断：Gaussian 尾部在通带外仍可能非零。
- 先减输入均值，再频域乘以实数偶对称响应。Gaussian 使用 `10*2^ceil(log2(N))` 尾端补零，逆变换后取前 N 点；Taner 使用 N 点周期 DFT。两者与验证参考的边界约定一致，不能期待二者在记录端点有相同形状。
- 包络为 `abs(x+i*Hhilbert(x))`，采用 N 点有限记录解析信号。实 FFT 正频率乘 `-i` 后反变换得到正交分量，DC 和偶数 N 的 Nyquist 正交分量置零；这里不能再额外将正频率乘二。它等价于完整复 FFT 的“正频率双倍、负频率零、DC/Nyquist 保留”方法。

Hilbert 定义对照 [MathWorks hilbert 算法说明](https://www.mathworks.com/help/signal/ref/hilbert.html) 和 Marple (1999), *Computing the Discrete-Time Analytic Signal via FFT*, IEEE TSP 47, 2600–2603。Taner 名称沿用参考包的命名，不把此中心对称带通形式和所有文献中的高/低通乘积形式混为同一参数化。

与验证参考不同的边界行为：常量和全零序列是合法数学输入，带通去均值后输出零；独立 Hilbert 可保留 DC。Aster 允许这些输入，而参考包要求正方差。相邻间隔容差沿用 Aster 全局约定 `1e-6`，参考包为 `1e-5`；对严格等间隔数据不存在此差异。不得自动放宽容差或强制插入重采样。
## 输入、输出与可解释性

- 输入为有限值、严格递增、等间隔的 `Series`，滤波至少 8 点；Hilbert 至少 2 点。预处理须通过显式任务完成；滤波不改变输入坐标。
- 频率单位为 X 单位的倒数，如 X 为 ka，参数就是 cycles/ka。默认范围 `.02..06` 是可编辑示例初值，并非对用户数据识别出的天文周期。
- 要求 `0 < fl < fh < 0.5/dt`。无效通带报出 Nyquist；重复、倒序和不等间隔沿用详细诊断；下游被阻断，其他输入可继续。
- 滤波/包络保留 X 和 Y 单位。响应是 `Series(频率,幅度增益)`，**不是 PSD**，也不插入数据库峰表。MTM 的峰频率索引保持。
- 有限记录的周期延拓、补零和截取会影响两端。零相位频域滤波不等于端点没有畸变。
- 宽带信号也能计算解析信号的模，但不应把它解释成唯一物理振荡的瞬时振幅。没有统计显著性含义，不输出新的 p 值/FDR。
- 过大的数值先缩放工作缓冲以降低 FFT 溢出风险；恢复单位后若不能用有限 double 表示，则返回数值错误，不能输出 Inf/NaN。
## 多纬度图约定

默认纬度 −90..90°、间隔 5°，年代 0..2000 ka、间隔 1 ka。行对应纬度、列对应年代，单位 W/m²。每一行直接调用已验证的单纬度日照任务，同参数下应逐点一致；未重复实现太阳辐射公式。365 日历日期仍沿用既有的固定月长/无闰日约定。

支持至少 2 个纬度、2 个年代；最多 361 个纬度、20000 个年代和 2000000 格点。按请求间隔采样，最后不足一个间隔的部分不强行添点。输出为“纬度 × 年代”的日平均日照图；不包含年内日期维度或季节积分。

日照图是二维数据，不能直接作为去趋势或滤波任务的一维序列输入。日照图显示物理强度，不包含 CWT 影响锥或显著性边界。
## 文件职责

`src/math/filtering/bandpass.h/.cpp` 负责纯数值计算；`src/processing/filter_tasks.h/.cpp` 包装三种任务；`src/processing/insolation_map_task.h/.cpp` 负责多纬度日照来源与预算。任务注册、参数界面及结果存储使用通用接口。
