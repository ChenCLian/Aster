# AR1 背景全局检验

`ar1_global` 是独立的 AR1 全局检验任务，通过模拟参考库计算统计量；普通 MTM 不会自动运行它。

它在声明的平稳 Gaussian AR1 噪声模型下模拟参考序列，比较观测统计量在参考分布中的位置。同一组设置可复用已生成参考库，减少重复计算。缓存是数值模拟的结果，不是固定分位数查表；缓存键不匹配时不会混用。

## 使用方法

在任务目录或节点添加菜单选择 **分析 → 频谱 → 显著性检验 → AR1 背景全局检验**。输入是数据序列，通常直接连接文件读取节点。它会自行计算 MTM，无需先连接 MTM 节点。数据须等间隔、X 严格递增、Y 有限且非常量，长度 64–1024。程序不自动插入预处理、不排序、不重采样、不截断；不合格输入返回诊断。

参数保留模拟精度、随机种子、可选内部 LOWESS 和缓存开关：

- 默认标准精度：每个参考模型 999 次参数筛选模拟，其中前 199 次计算检验统计量。精细精度为 999 次分析模拟，耗时更长，不保证大幅提高检出率。
- 可选内部 LOWESS：窗口比例默认 .35，普通 LOWESS、0 次稳健迭代。观测与模拟都执行相同处理；它不是强制步骤。
- 参考种子用于复现，不应反复改种子直到得到显著结果。
- 固定 NW=2、K=3、NFFT=N，检验整组正的内部 Fourier 频率，排除 DC 与偶数 N 的 Nyquist。不提供“看到峰后再缩窄检验频段”的操作。

若先在外部工作流做 LOWESS、插值、选段等处理，再把结果传给本任务，检验假设针对**传入的序列**。本任务不自动重放祖先节点，也不保证这些处理后的噪声仍是平稳 AR1。推荐预先确定分析方案；需要本检验内的 LOWESS 时使用其内部开关。
## 结果含义

输出包括全局检验数值表、功率谱、时间域拟合的 AR1 背景和实际分析序列。结果页显示全局 p 值与以下状态：拒绝所设 AR1 噪声假设、证据不足，或候选参数集合为空而不可判定。任务计算成功和统计显著是不同状态。

`ar1_global_test` 表中的 `test_available` 与 `reject_global_null` 使用 0/1；`alpha` 固定 .05。空集合保守返回 p=1、available=0，仍保留该次计算，不删除或重抽。

这是单条记录、预先固定频率集合的全局检验。显著表示数据与所设噪声模型不相容，**不是逐峰概率、FDR、确定周期或天文成因的证明**。未显著也不等于没有信号。多条记录、多种参数或多种方法挑选结果产生的选择问题不在本任务的控制范围内。

本任务与 MTM 的 AR1/SWA/FDR 及 CWT 局部显著性分别计算，不提供小波全图检验。
## 数学约定

使用保守参数集合方法。原假设为未知常数均值、正尺度、rho 预先限定在 [-.999,.999] 的平稳 Gaussian AR1。统计量为整组指定频率上的最大 MTM 功率 / 时间域重拟合 AR1 背景。每条模拟都重新执行内部处理、MTM 与背景拟合，不使用观测数据构建参考模拟。

参数筛选预算 beta=.005。连续 rho 网格通过 AR1 Gaussian KL 与 Pinsker 距离界控制，总变差预算不超过 .01；实际距离上界记为 epsilon。保留参数模型的分析概率取最大值，再加入 beta 与 epsilon，截断到 1。单个模型采用含观测的 `(1 + 超过观测的模拟数)/(B + 1)`，保守处理并列值。方法依据包括 Berger–Boos 的置信集合最大 p 值与 Monte Carlo 秩检验；实现细节见 `src/math/statistics/ar1_nuisance.*` 和 `ar1_global.*`。

这种误差预算会使检验偏保守，并不要求实际误报率精确等于 5%。其水平陈述针对参考随机性与独立观测的联合分布；不是每个固定缓存、任意真实背景或任意用户探索操作的保证。实现为浮点数与伪随机数，未做跨平台区间算术认证。
## 可核查的校准逻辑


设每个网格模型为 rho_j。对原始序列的去均值 lag-1 统计量作双侧模拟秩检验，得到 s_j；对完整分析统计量作单侧模拟秩检验，得到 a_j。每个 a_j 都重新执行相同的预处理和背景拟合。当前统计量为 max(MTM/时间域重拟合AR1背景)。拟合平稳 Gaussian AR1 的常数均值、rho 和创新方差，复用已有似然拟合函数；不使用真实生成 rho 计算观测统计量。

保留的模型集合为 C={j:s_j>beta}，默认 beta=0.005。最终概率为：

\[
p_{\mathrm{comp}}=\min\{1,\max_{j\in C}a_j+\beta+\epsilon\}.
\]

空集合明确返回无法形成候选集合的标志，并保守返回 p=1，不将它当作发现。

epsilon 来自分布距离的上界。对同均值、同边际方差、长度 N 的平稳 Gaussian AR1 分布，有：

\[
D_{KL}(P_\rho\Vert P_s)=\frac{N-1}{2}\left[\log\frac{1-s^2}{1-\rho^2}+\frac{2s(s-\rho)}{1-s^2}\right],
\qquad TV(P_\rho,P_s)\le\sqrt{D_{KL}/2}.
\]

初始点的边际分布相同，KL 来自 N−1 个条件正态转移。对固定 s，上式关于 rho 是凸函数，因此每个网格单元的端点界覆盖内部。程序在 atanh(rho) 坐标中细分，直到所有单元满足设定的距离预算。距离预算为 0.01，实际计入的是全部单元的最大计算界。长度 128 和 512 分别形成 4,096 和 8,192 个单元，完整覆盖预定区间。

证明要点：对任意真实 rho，固定选择覆盖它的单元 j。在网格模型 j 下，拒绝事件包含于“错误排除 j”与“a_j≤alpha−beta−epsilon”这两个事件的并集，概率至多 beta+(alpha−beta−epsilon)。将观测分布从网格模型换成真实 rho，最多再增加 epsilon。因此整体拒绝概率至多 alpha。筛选与分析可以相关；不需要额外乘以模型个数。

这个论证要求候选网格事先固定、模拟与观测独立、各模型下秩概率有效、观测与模拟采用同一统计量。参考模拟可在候选模型间共享随机创新项，但不能把观测当成参考模拟的一部分。均值/尺度的消除依赖统计量的平移与尺度不变性；改变统计量后必须重新确认，不能无条件套用。

它是完整噪声假设的全局检验，不是 FDR，也不是对每个谱峰的独立确认。跨记录、反复调参、反复选择频段和混合信号下的强 FWER 不由这一个概率控制。

## 后台、缓存与存储

- 该任务复用原继承/注册宏接口。`ExecutionContext::progress` 可选回调，经现有工作线程事件通道传到状态栏；原任务不必实现它。
- 同长度、全部设置、方法格式版本、数值后端与构建 ABI 匹配才复用参考库。缓存不含用户原始数据，缓存命中也仍重新计算观测统计量。
- 同一缓存键由文件锁串行生成；其他任务可等待并取消。校验文件长度、格式、所有数值、排序和 SHA-256；损坏文件重新生成。原子写入防止中断留下可用的半成品。
- 缓存位于 Qt `QStandardPaths::CacheLocation` 下的 `ar1_global/v1/`。Windows 通常在当前用户的 Local AppData 应用缓存路径；由 Qt 决定具体位置，不硬编码磁盘盘符。退出程序后可删除该子目录，下次自动重算，不影响数据库。
- 每个参考库内存预算 160 MiB，生成工作量有上限；精细精度在某些大 N 会被拒绝并报告原因。缓存清理目标为最多 4 个文件、384 MiB，正在使用的锁定文件不会被强删，因此并发时可暂时超出清理目标。
- 缓存目录不可写或保存失败时仍返回本次正确计算并给出警告。取消采用协作检查；第三方单次计算期间不能保证立即抢占。
- 参数、种子、缓存身份/命中情况、拟合参数、概率及全部类型化输出随原运行记录存入 SQLite；数据库 schema 3 和编码 v1 不变。CSV/数值表与图形输出沿用原功能。

## 验证与复现

固定参照、非法输入、缓存损坏/取消/并发、数据库往返和 UI 展示仍由当前自动化测试覆盖。最终离线验证工具保留在 [tools/ar1_global_validation](../../tools/ar1_global_validation/README.md)，只有显式 `CONFIG+=calibration` 才构建。

历史五种配置共有 11,000 次观测检验执行，失败 0，受测纯噪声条件的拒绝比例为 0%–4%。配置间配对复用观测，不能称为 11,000 条独立样本，也不能据此证明任意噪声或每个固定缓存均满足名义水平。原配置、种子、结果和区间汇总保留在 [科学验证证据](../reference/scientific_evidence.json)。这些历史实验不代表其他版本、参数或噪声模型已经完成校准。
