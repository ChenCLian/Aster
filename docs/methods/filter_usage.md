# 滤波与振幅包络

[公共概念](../concepts/data_processing.md) · [方法说明](README.md) · [English](filter_usage_en.md)

<a id="choose"></a>
## 先确定保留的频带

| 目标 | 任务 | 默认输出 |
| --- | --- | --- |
| 保留较低频率的变化 | Butterworth 低通 | `filtered` |
| 抑制较低频率的变化 | Butterworth 高通 | `filtered` |
| 提取一段频带并查看包络 | Gaussian／Taner 带通与包络 | `filtered`，另有 `envelope` |
| 对已有序列计算解析信号的模 | Hilbert 振幅包络 | `envelope` |

所有任务都要求有限、严格递增、等间隔的 X/Y，不自动重采样。频率单位为 X 单位的倒数；例如 100 ka 周期对应 0.01 /ka，不能把 100 填进频率框。奈奎斯特频率为 `1/(2×Δx)`。默认频率是初值，不是程序从数据中识别的周期。

先根据研究对象和原始频谱确定频带，再比较输出与响应曲线。滤出振荡不证明它来自轨道强迫，也不构成显著性检验。

<a id="butterworth"></a>
## Butterworth 低通与高通

默认单程截止频率 0.05、单程阶数 4；阶数允许 1～10。截止频率与奈奎斯特之比须在 0.0001～0.9999，避免过于接近零频或采样上限。

程序前后向各滤波一次。参数定义的是单程滤波器：在所填截止频率处，单程幅值增益为 `1/√2`，双向后为 **0.5**，对应功率比例 0.25。`filter_response` 显示实际双向幅值响应，不能按单程半功率响应解读。增大阶数使过渡带更陡，同时可能加剧有限记录的边界问题。

两端各作 `3×(阶数+1)` 点奇对称延拓，输入点数必须大于这个长度。默认四阶至少需 16 点。输出裁回原始长度，保留 X 和 Y 单位。双向零相位处理不等于端点没有畸变，也不是可直接用于实时数据的单向因果滤波。

任务不预先去均值；低通的 DC 增益为 1，高通为 0。低通保留常量基线，并不保证任意有限记录滤波前后的样本平均值完全相等。最大输入为 100 万点。

[低通参数](../reference/task_parameters.md#m-butterworth_lowpass) · [高通参数](../reference/task_parameters.md#m-butterworth_highpass)。

<a id="bandpass"></a>
## Gaussian 与 Taner 带通

至少 8 点。默认下限 0.02、上限 0.06，要求 `0<下限<上限<奈奎斯特频率`。两者先减去输入均值，再应用频域响应；输出不会自动加回均值。常量输入得到零滤波曲线和零包络。

上下限是半功率频率：幅值增益为 `1/√2`，功率比例为 1/2；中心频率增益为 1。它们不是硬截断边界，通带外仍可有非零响应。

- **Gaussian**：响应较平缓，尾端补零到 `10×不小于N的最小2次幂` 点，逆变换后保留前 N 点。
- **Taner**：使用 N 点周期 DFT；陡峭度 q 默认 12，允许 0.001～20。q 改变过渡带形状，不是 dB/倍频程，也不是 Butterworth 阶数。

两种边界约定不同，即使频带一致也不能要求端点逐点相同。Taner 的周期延拓把记录两端相接；Gaussian 的补零也不能消除边界效应。应检查两端及频带内周期相对于记录长度的比例。

带通任务同时输出 `filtered`、`envelope`、`filter_response`。包络由滤波后的 N 点序列计算，普通用途无需再接一次 Hilbert。若连接下游任务，请确认选的是滤波序列，而不是包络或频率轴上的响应。

输入最多 100 万点，FFT 最多 4194304 点。Gaussian 的补零规则使其有效输入上限更小：N≤262144；再增加一个点会触发下一档补零并超过 FFT 预算。报错时应有依据地缩短输入或调整处理方案，不静默截取数据。

[Gaussian 参数](../reference/task_parameters.md#m-gaussian_filter) · [Taner 参数](../reference/task_parameters.md#m-taner_filter) · [公式与参照版本](filtering.md#数学和参考版本)。

<a id="hilbert"></a>
## 独立 Hilbert 振幅包络

至少 2 点，最多 100 万点。任务直接处理选中的上游序列，不自动带通。默认不去均值；可显式启用去均值。常量 3 的包络为 3，去均值后包络为 0，因此基线选择会直接影响结果。

输出 `quadrature` 为 Hilbert 正交分量，`envelope=sqrt(y_work²+quadrature²)`；其中 `y_work` 是是否去均值之后的工作序列。两者都保留输入 X 和 Y 单位。使用 N 点有限记录解析信号，端点受周期边界影响。

对窄带、成分相对单一的振荡，包络可用于描述幅度变化；宽带、多成分信号也能计算包络，但不能直接解释成某一个物理振荡的唯一瞬时振幅。这里的包络与 PSD 平方根显示不是同一数量，不输出 p 值或显著性阈值。

[参数](../reference/task_parameters.md#m-hilbert_envelope) · [单位](../concepts/data_processing.md#units)。

<a id="outputs"></a>
## 输出、检查与常见问题

`filter_response` 的横轴是频率、纵轴是幅值增益（单位 1），不是 PSD。用它确认通带、截止处增益和过渡带，再看原始／滤波序列及包络。图片平滑只改变绘制效果，不能修正滤波结果。

| 现象 | 检查顺序 |
| --- | --- |
| 截止／通带非法 | X 单位、周期与频率换算、采样间隔及奈奎斯特限制 |
| 输入过短 | Butterworth 阶数对应的延拓长度，或带通／Hilbert 的最低样本数 |
| 排除异常点后不能滤波 | 采样是否变为不等间隔；先决定分段还是有依据地重采样 |
| 记录两端明显偏离 | 原始端点是否不连续、滤波边界约定、截止周期是否接近记录长度 |
| 包络与预期不同 | 是否接对输出端口、是否去均值、是否为多成分信号 |
| 不同滤波器结果不同 | 比较实际响应、DC 处理和边界；只匹配频率数字还不够 |

本页说明当前行为，不声称所有数据上的最优参数。既有参考约定见[滤波实现说明](filtering.md)和[扩展方法](spectral_extension.md)；检查记录见[验证范围](../validation_current.md)。
