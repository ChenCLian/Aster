# 1.2.0-alpha.6 输出选择与布局验证

范围：输出端口选择、菜单定位、字号与间距，以及相关界面与操作回归。环境为 Linux x86_64、Qt 6.8.2、GCC 14.2.0、Release、offscreen。

六组界面、联合流程、绘图导出、工作区、集成和更新测试共 996 项通过，0 失败；计数包含各 QtTest 测试套件的初始化与清理。四档缩放专项检查分别通过 9 项，不累计到上述总数。帮助生成器 6 项和许可证打包结构 2 项检查通过，54 个任务、233 个参数的双语参考与当前版本一致。

新选择窗口覆盖显式端口绑定、千项过滤、鼠标与键盘确认、取消、撤销、来源删除及窗口状态变化。布局检查覆盖中英文、深浅主题、窗口边缘和 100%/125%/150%/200% 缩放。结果目录标题支持换行，步骤状态列按语言文字宽度设置。

详细范围与日志索引见 [popup_checks.json](popup_checks.json)。Qt offscreen 的窗口置顶、键盘抓取和尺寸提示警告属于测试后端能力提示；本记录不替代 Windows/macOS 原生桌面验收，也不证明物理多屏行为。原生级联子菜单与按钮菜单仍由 Qt 处理屏幕边界。

本轮未改变算法、计算限额、数据库结构或数据载荷格式，未重复运行算法测试。此前的数值与性能证据分别保留在 alpha.4 和 alpha.5 目录，不能累计为本轮执行结果。跨节点联合输入、节点插入和替换不在本轮实现范围内。
