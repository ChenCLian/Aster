# 1.2.0-alpha.10 桌面联合输入验证

范围、环境、统计和复现命令见 [linked_input_ui_checks.json](linked_input_ui_checks.json)。12 个测试程序合计 1976 项通过，0 失败、0 跳过；跨节点专项 40 项通过。

覆盖来源节点与数据/输出选择、搜索及同名数据区分、跨根 A/B 配对确认、取消、撤销/重做、失效来源修复、运行锁与迟到选择拒绝。画布检查覆盖当前配对引用线、配对切换、后继节点选择、来源删除及撤销。既有真实 Welch 输入、预览、执行和保存一致性测试保留。

中文/英文、浅色/深色、窄窗口与 100%/125%/200% 缩放已检查；125% 与 200% 的附加界面记录分别见 `display_scale_125.txt`、`display_scale_200.txt`。选择窗口按可见区域限制尺寸，窄窗口采用上下布局，配对操作按钮换行。Qt 窗口截图用于检查文字裁切、列表可见性及引用线布局。

1000 组配对、1001 份输入的窗口打开与成员选择样本耗时为 223 ms，取消后全部配对保持不变。这是当前主机单次样本，不是跨硬件性能或进程总内存保证。参数参考生成检查和 6 项 Python 测试通过。

Linux/Qt offscreen 结果不能代替 Windows/MSVC、macOS 原生窗口与发行包验收，也不覆盖原生窗口管理器、多显示器移动等行为。算法、数值限额和格式未改变，历史科学验证记录保持原版本。
