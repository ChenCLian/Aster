# 1.2.0-alpha.7 统一编辑验证

本记录覆盖工作流编辑事务、源绑定与配对的统一撤销/重做、过期编辑拒绝、运行锁、导入设置及预览同步。详细环境、用例与限制见 [edit_checks.json](edit_checks.json)。

Linux x86_64、Qt 6.8.2、GCC 14.2.0 Release 构建通过。10 个回归程序的 QtTest 汇总为 1,907 项通过、0 失败、0 跳过，包含测试套件的初始化与清理。逐程序输出与本文件同目录保存。

新增 10 个核心编辑用例和 5 个桌面联合流程用例。10,000 份数据、9,999 组配对的首次提交及 10 次参数编辑共耗时 198 ms；这是当前环境的一次核心编辑测量，不含科学算法、文件读取或完整窗口重绘，不代表所有电脑的响应时间。数值缓冲区使用只读共享引用；最多 100 次历史可能延长这些数据的生命周期。

原有算法、交叉谱、界面、保存与导出回归已重新执行。本轮没有新增独立数值参考实现；此前的数值参考、性能和弹出窗口证据分别保留在 alpha.4、alpha.5 和 alpha.6 的目录中，不累计为本轮新增用例。

Windows/macOS 原生构建及桌面验收尚未完成。节点插入、替换入口与跨节点联合输入尚未开放。撤销不恢复外部文件字节、不删除已保存结果，也不恢复视口缩放或选择状态。
