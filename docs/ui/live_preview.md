# 即时预览

适用版本：Aster 1.2.0-beta.5。本文说明预览操作与显示范围。

## 使用

文件栏与画布之间为“即时预览”列，默认展开；可拖分隔线或右侧把手调整宽度，点击把手收起。上下图之间的分隔线可以调整高度。较窄窗口默认收起任务目录，必要时收起步骤设置，保持画布可用。

上方显示普通路径的源数据，或联合分析所选配对的“计算输入 A/B”；下方显示当前画布节点的输出。联合输入标题使用文件名与输出名称，悬停可查看完整来源。切换 A/B 只改变预览，不修改配对。

1. 导入并选择一个文件，上方立即预览原始数据；修改表头、分隔符、X/Y、单位、跳过无效行会同步更新。
2. 在画布选择节点，程序自动计算到该节点；联合路径按“预览配对”计算双方输入。下方显示该节点经过上游处理后的输出。
3. 有效参数编辑后自动更新预览；切换节点或正式运行前提交当前编辑。校验失败显示错误，预览不展示旧参数的结果。
4. 浏览任务目录或修改无关分支不重新计算。删除当前节点、移除输入或输入未就绪时，预览等待有效输入。
5. 通过下拉框查看曲线、热图或数值表等输出，无需重新计算。选中数据源时恢复其上次浏览的输出；选中下游节点时，上方显示该路径实际使用的源输出。浏览输出不改变已有连接。
6. “重算”用于主动重新读取文件/计算；“适应”和“图例”只影响当前预览图。正式保存仍用“运行流程”，即时预览本身不写入结果数据库。

左侧“应用到本文件/所选文件”用于保存文件导入配置。预览读取当前编辑值，正式运行前提交当前配置。预览与正式运行使用相同的表头及无效行处理规则；排序和重采样通过独立任务配置。

## 大数据显示与边界

计算使用完整数据，预览按显示预算缩略：每条曲线最多 4096 点，保留原始顺序、端点和轴极值；热图每轴最多 384 个坐标样本；表格最多 2000 行、256 列且不超过 200000 个单元。数据被缩略时明确提示；原始数值和正式存储不变。

功率热图和显著性比值使用相同坐标取样；显示不会把分块最大值移动到其他坐标。即时预览是有界概览，放大不会后台重新细化；细节查看与导出仍使用结果页。特别窄的尖峰或小轮廓可能在网格概览中遗漏，不把预览视为完整数值证据。

下游失败时，已成功生成的源输出仍可查看。错误提示给出最早失败的步骤、原因和建议，悬停可看详情；依赖该步骤的下游节点不生成输出。

外部修改源文件后，点击“重算”重新读取；程序不监视文件系统变化。后台预览可取消，第三方库计算期间取消可能需要等待；完整运行期间暂停预览。

执行、缓存与接口说明见[开发文档](../development/workflow_preview.md)。
