# 即时预览

本文说明预览交互、执行策略与显示范围。验证批次、环境和范围见 [验证记录](../validation.md)。

## 使用

文件栏与画布之间为“即时预览”列，默认展开；可拖分隔线或右侧把手调整宽度，点击把手收起。上下图之间的分隔线可以调整高度。较窄窗口默认收起任务目录，必要时收起步骤设置，保持画布可用。

上方显示原始数据及文件名；下方“节点输出预览”显示当前画布节点的方法名、文件名，悬停可查看完整上游路径。独立生成源、数据库来源显示源数据及来源名称。所有方法/端口名称来自注册描述及语言资源。

1. 导入并选择一个文件，上方立即预览原始数据；修改表头、分隔符、X/Y、单位、跳过无效行会同步更新。
2. 在画布选择一个节点，下方自动执行从数据源到该节点的路径。选中“读取文件”时，下方显示读取结果；选中 MTM 时则包含上游预处理。新节点计算完成前清除旧图，避免将上一节点的输出标为新节点结果。
3. 有效参数编辑后自动更新预览；切换节点或正式运行前提交当前编辑。校验失败显示错误，预览不展示旧参数的结果。
4. 浏览任务目录、点击画布空白、重复选择同一个节点、修改无关分支不重新计算。删除当前节点、移除输入、输入未就绪时清除失效结果并待机。
5. 下拉框选择该节点的具名输出。MTM 继承结果页的频谱关联曲线；普通 Series 按当前输出显示，Grid 显示热图及已有 COI/显著性轮廓，Table 显示数值表。切换输出复用当前计算结果。
6. “重算”用于主动重新读取文件/计算；“适应”和“图例”只影响当前预览图。正式保存仍用“运行流程”，即时预览本身不写入结果数据库。

左侧“应用到本文件/所选文件”用于保存文件导入配置。预览读取当前编辑值，正式运行前提交当前配置。预览与正式运行使用相同的表头及无效行处理规则；排序和重采样通过独立任务配置。
## 执行与并发

参数编辑合并间隔为 260 ms，预览请求合并间隔为 220 ms；面板宽度范围为 300–720 个逻辑像素。

- `prepareNodePreview` 从当前节点回溯单父节点路径，保留 NodeId、方法版本、参数、父输出端口和布局，用现有 WorkflowModel 校验并冻结。其他根、兄弟、后代不进入请求。
- 多起点按根 ID 匹配左侧输入；不把另一个根的文件隐式借给当前节点。独立生成源无需文件。
- 预览与正式运行共用 WorkflowExecutor、数学计算和端口转发；原始数据与算法输出通过只读 DataRef 传递。
- 一个后台 worker 执行预览，最多保留一个最新待执行请求。请求代次和取消令牌双重校验，旧任务完成后不能覆盖新选择。
- 修改参数时立即让旧结果失效，而不是等防抖到期再取消。正在等待原生库返回时，界面仍可操作；取消是合作式，不强杀线程。
- 运行完整批次时暂停节点预览；结束运行及返回任务页时重新同步当前输入。收起预览列或离开任务页时取消请求并释放显示数据。关闭窗口时取消预览，后台任务未结束时延迟关闭，避免在 GUI 析构阶段同步等待长计算。
- 原始文件概览与节点执行各自调用同一个读取器；算法使用完整数据，4096 点概览仅用于显示；文件按请求读取。完成执行后，原始图以该次路径实际读取的根输出为准，保证与下方结果对应。当前版本不缓存整条上游计算链。
- 如果文件在磁盘上被外部修改，不提供文件系统实时监视；点击“重算”或下一次有效流程变化重新读取。相同参数的确定性算法与正式运行一致；含随机性的任务仍遵守算法自己的种子设置。
## 大数据显示与边界

计算使用完整数据，后台生成显示副本。统一预算在 `PreviewLimits`：每条曲线最多 4096 点（保留原始顺序、端点和轴极值），Grid 每轴最多 384 个坐标样本；Table 最多 2000 行、256 列且不超过 200000 个单元。数据被缩略时明确提示；原始数值和正式存储不变。

Grid 功率和显著性比值使用相同的坐标取样规则，不能使用块最大值把局部显著性扩大。即时预览是有界概览，放大不会后台重新细化；细节查看与导出仍使用结果页。特别窄的尖峰或小轮廓可能在网格概览中遗漏，不把预览视为完整数值证据。

任务错误显示最早失败步骤的名称、摘要、建议和悬停详情；依赖失败步骤的下游节点不生成输出。初始化没有数据或节点时不启动计算。
## 文件职责

| 文件 | 职责 |
|---|---|
| `src/ui/services/workflow_preview_controller.h/.cpp` | 构造祖先路径、请求去重、防抖、后台执行、取消和过期结果隔离 |
| `src/ui/panels/workflow_preview_panel.h/.cpp` | 两个区域、上下文信息条、输出切换、忙碌/待机/错误状态 |
| `src/ui/results/preview_data.h/.cpp` | 有界显示副本；上下预览共用，不参与算法或持久化 |
| `src/ui/panels/file_preview_panel.h/.cpp` | 文件读取、原始顺序绘图与内嵌概览 |
| `src/ui/panels/parameter_editor.h/.cpp` | 自动提交、防抖和输入即失效信号 |
| `src/ui/panels/source_panel.h/.cpp` | 当前根/文件与草稿列选项的统一预览选择快照 |
| `src/ui/panels/collapsible_panel.h/.cpp` | 共用收缩/拖动把手，支持左右边缘和展开宽度上限 |
| `src/ui/app/main_window.h/.cpp` | 装配、画布选择来源、正式批次暂停和关闭协调 |

新增普通读取/计算任务只需继续声明输入类型、具名输出、defaultOutput、参数和翻译，即可进入菜单、编辑器和预览。具有发送、写文件或删除记录等外部副作用的任务，需要独立的预览执行策略，禁止直接接入自动预览。
