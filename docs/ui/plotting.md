# 绘图交互与样式

适用版本：Aster 1.2.0-beta.6。

## 结果目录

每条记录显示 ID、时间、名称和状态；悬停可查看完整路径。单击记录浏览结果，复选框用于批量操作。

目录底部的“全选”勾选全部筛选结果（含未加载的页），“取消勾选”仅清除筛选范围内的勾选，“清空全部”还包括筛选范围外的勾选。切换筛选条件与分页不改变已有勾选。

## 步骤、输出与投图

打开结果记录时，自动显示最后一个成功且可绘图步骤的默认输出；若只有表格，则显示最后一个成功步骤的表格。单击下方步骤可查看该步骤的默认输出。失败且没有输出的步骤显示诊断，已有图形保留。

相同输出已经打开时，直接选中并保留样式；新图默认放入新图页。可在“设置 → 默认投图位置”改为“当前图页”，当前页满四幅时新建图页。浏览或勾选输出不会改变默认输出或投图位置设置。

“步骤与输出”左侧选择一个步骤，右侧可跨步骤勾选多个输出；点击“已勾选”查看或取消，切换记录会清空勾选。勾选输出不改变投图目标。拖动分隔线可调整列表空间；点击“收起”扩大绘图区，再展开恢复原高度。

点击图页标签、子图标题或图形可选择投图目标，底部显示目标图页、子图及其记录和输出。

“添加绘图”按同一步骤的输出关系组合：频谱主曲线、背景、阈值与峰值标记共用子图；小波功率与影响锥共用子图。原始功率、尺度校正功率和显著性比值等不同含义的热图分别显示，其他输出保持独立。“更多 → 分别绘制”可逐个查看输出。

每页最多 4 个子图，超出时续建图页，总共最多 32 页。“添加绘图”按钮括号内显示将新增的图数，已有图保留。例如，全选四种小波热图和影响锥会新增四幅图，每幅附带影响锥。没有图形时也可直接添加。

“叠加到当前”始终使用提交时选定的子图，后台读取期间切换选择不会改变目标。普通曲线要求数据类型相同且 X/Y 单位兼容；同一小波步骤的影响锥可以叠加到其周期热图，已有辅助曲线不重复添加。不同物理量的热图不互相覆盖。每个子图最多 8 组输出、合计 64 个引用，同一已识别频谱族计作一组；检查失败提示原因并保留原图。“更多”还提供“新图页”和“替换当前子图（单项）”。普通数值表独立显示，交叉谱表在子图内切换指标。

普通曲线的 X、Y 单位文字均须一致；未填写单位的轴还须名称一致。叠加不自动换算单位，也不要求坐标范围接近或采样点数相同；使用前仍需确认物理量与坐标基准可比。

未主动缩放或指定范围的坐标轴，会在叠加成功后适应合并数据；已缩放、平移或手动设置范围的轴保持当前视野。点击“适应”可重新显示全部可见曲线。

右键“清空图像”保留子图位置和大小。选中空位、勾选输出后，点击“放入当前空位”可重新绘制曲线或热图；多项输出须能共用一个子图，原样式不保留。加载中或加载失败的子图不属于空位。清空图像不删除数据库结果。

CSV 与“用作数据源”位于右侧“导出”页，操作对象是当前浏览步骤的所选输出。输出列表的多选勾选用于绘图，CSV 按右侧所选输出导出。PNG/PDF 导出当前子图或图页，导出区分别标明操作对象。

浏览记录与选择图形相互独立，切换记录不会关闭已打开的图页。

删除来源记录会移除引用它的子图，并取消相关待完成的绘图操作；其他子图保留。

## 结果侧栏导航

右侧“绘图 / 导出 / 来源”分别用于样式编辑、文件输出和查看参数及数据引用。“编辑对象”显示当前子图；选择子图后，可在“画布、坐标轴、曲线、热图”中调整相应设置。

## 默认样式与存储边界

预览、结果与 PNG/PDF 共用默认样式。手动设置后，切换图页和后台细化均保留这些设置；“恢复默认”恢复当前版本的默认样式。

绘图设置不修改已保存的计算结果，也不需要重新运行分析。关闭图页或退出程序后不恢复样式；计算参数、单位、数值和来源仍保存在结果记录中。

批量叠加会先检查全部所选输出；检查失败时，已有图形及其样式保持不变。

## 样式设置

| 页 | 设置内容 |
|---|---|
| 画布 | 标题与字体、背景、图例与方向 |
| 坐标轴 | 顶端固定 X/Y 选择器；坐标与范围、主轴与刻度、主网格、次网格、对侧轴 |
| 曲线 | 显示与图例、线条与连接、数据点标记、基线填充 |
| 热图（仅当前子图为热图时启用） | 配色与色阶、数值到颜色、像素显示、显著性边界 |

X/Y 选择器固定在坐标轴页顶部，控制下方整页的编辑对象，滚动设置列表时保持可见。两轴参数分别保存。

样式修改后即时更新图形。启用“填充至基线”后可设置填充颜色；启用数据点标记后可设置其填充和边框。

热图提供蓝绿黄、灰度、热力、发散、彩虹五种配色，默认彩虹，均可反转；颜色级数 2–1024，默认 256；可隐藏色标。线性/对数指**数值到颜色的映射**，与 X/Y 轴对数设置相互独立。对数使用正值范围，零/负值像素留空；当前没有正值时拒绝新启用对数并保留上一个有效样式。固定范围要求有限且递增，对数下限必须为正。自动范围来自完整输出，细化、平移和缩放保持该范围，控件同步显示实际范围；跨图比较请使用相同固定范围。清晰色块/平滑显示只改变视觉插值。

这些选项只影响显示，不修改已保存的数值或 CSV。改变配色和数值映射时保留当前视区。

## 单轴操作

鼠标停留在 X/Y 轴上可查看操作提示：滚轮缩放该轴，沿轴拖动平移；在绘图区操作则同时影响两轴。数值框只有主动点击或通过 Tab 聚焦后才接受滚轮，关闭的下拉框不响应滚轮选择。

选择热图后可使用“热图”设置，其他类型的子图中该类别置灰。

## 显示精度状态

结果图在首次显示、平移、缩放或调整大小后自动细化，完成前保留原图。热图下方显示“显示网格 / 当前视区原始网格”尺寸，未缩减时显示“原始采样”；悬停可查看完整信息。

平移不保证转为原始采样；只有当前视区样本量满足显示预算时才显示全部样本。自动颜色范围基于完整输出，细化时保持不变，PNG/PDF 使用导出开始时的色阶设置。“恢复默认”会按恢复后的范围重新读取显示数据。

## 小波影响锥与显著性轮廓

CWT 周期热图及独立影响锥默认使用以 2 为底的对数周期轴，周期热图默认 Y 轴反转，即小周期在上、大周期在下；影响锥和显著性轮廓使用相同坐标转换。需要相反方向时，在“坐标轴 → Y 轴”关闭“反转方向”。该默认适用于 CWT 周期热图及其影响锥，不改变 COCO 沉积速率或其他热图的坐标方向，不重排数据库或 CSV 中的网格。

小波的“功率 / 名义95%阈值”输出用于显著性轮廓，“影响锥”用于标示边界效应区域。两者来自独立输出，不能只凭影响锥判断显著性。

轮廓绘制 **功率 / 局部 95% AR1 阈值 = 1** 的边界，默认开启，黑线配一条细浅色衬线保证深色配色中的可见性；颜色、宽度及开关独立设置。影响锥在“曲线”页编辑。该边界表示局部名义检验，不控制整张热图的全局误报率。

绘制约定参考 Torrence–Compo 作者的 [wavetest.m](https://github.com/ct6502/wavelets/blob/main/wave_matlab/wavetest.m)：在显著性比值 1 处绘线，周期为对数显示时在 log2(period) 坐标上插值。

没有轮廓可能有多种原因，面板会区分：

- 没有存储比值：计算时关闭了显著性，或红噪声估计不适用，应查看任务报告。旧记录若已保存该输出，直接重新打开即可；未保存的需要重新计算。
- 当前网格没有跨越 1：全部低于或全部高于都不会产生内部闭合边界；仅凭没有闭合轮廓无法判断显著性。
- 用户隐藏轮廓，或当前为降采样预览，小范围结构可能没被采样。
- 辅助网格坐标/尺寸不一致，或边界超过预算：停止绘制整个边界并提示原因。

预览、结果与导出的热图和显著性网格使用一致的坐标取样规则，显示值对应原始坐标。缩略预览可能遗漏小范围结构；结果页会在首次显示、缩放、平移或调整大小后按当前视区细化，即时预览不会自动细化，见[即时预览](live_preview.md)。

图形导出按目标分辨率准备数据，最多使用 4,194,304 个栅格样本和 100,000 条边界线段。超过预算时停止绘制整个边界并提示；导出会报告失败，可缩小区域或关闭边界后重试。

PNG 和 PDF 保留当前配色、颜色映射与轮廓，PDF 轮廓保持矢量。CSV 总是原始数值。

## 坐标气泡

- 读数显示来源、坐标和单位，曲线以颜色和线型辅助识别。数值显示为 8 位有效数字，“复制”保留当前取样值的完整精度。
- 在曲线采样点/峰值附近单击，选择附近最近的可见采样点，同位置优先峰值标记。展示曲线名、X/Y 与单位；频谱正频率另显示倒数周期。读数对应采样点坐标。
- 热图显示当前格点实际采用的数据坐标和 Z 值，保留对数周期轴与交换轴转换。颜色对数映射不会把 Z 改成 log(Z)；被屏蔽的非正值不弹出气泡。开启像素平滑时仍读取格点值，不读取视觉插值产生的中间值。
- 每个子图最多一个气泡。点另一个位置更新，点空白、×、Esc、拖动、缩放、改变样式、切换/清空数据时关闭，避免留下过期坐标。
- 读数浮窗不会进入 PNG/PDF 图形导出。
- 抽稀数据会明确提示“预览采样值”。数据库图可放大请求更细的数据；即时预览受显示预算限制，读到的是当前保留的样本，不是对完整原始文件的任意点查询。

## 峰值参数与数据库一致性

最小突出度设为 0 时，数值有效但极小的局部起伏也会作为局部峰保留。在线性大范围图中，低突出度峰可能难以辨认，可缩小坐标范围或查看峰值表。

MTM 的 **相对突出度（%）** 默认 **0.1**。以完整功率谱的极差为尺度，有效阈值取以下三者最大值：

1. 用户设置的绝对最小突出度；
2. 相对百分比 / 100 × (最大功率 − 最小功率)；
3. 64 × double 机器精度 × 最大绝对功率（浮点舍入保护）。

峰必须高于两侧基底形成的等高线，突出度为峰顶与较高一侧基底的高度差；平顶只保留一个中心。检测同时受峰高、峰距、半突出度峰宽和搜索半径约束。

**相对阈值是幅度筛选，不是统计显著性检验。** 弱峰可能低于默认 0.1%，可调低或设为 0；设为 0 仍保留浮点舍入保护，绝对阈值也仍生效。该阈值只控制峰值筛选，不参与主功率谱和 AR1/SWA/FDR 的统计计算。

MTM 方法版本为 7；报告记录相对比例与有效阈值。绘图标记、峰值表和数据库频率索引使用同一份检测结果。已有数据库记录保留当时的方法版本与检测结果，重新运行才会产生新结果。

## 加载与刷新

加载期间可继续操作；刷新保留手动样式，坐标读数基于当前显示样本。视区细化与精度提示见上方“显示精度状态”。

## 交叉谱结果

交叉谱结果以完整数值表保存，显示时选择平方相干度、交叉谱幅值、相位、实部/虚部或双方自谱。表格、预览和 CSV 保留未定义单元格；曲线不跨未定义频点连接，相位跨 ±180° 的包裹跳变也断开。缺口不等于数值为零。

切换指标或缩放只改变显示，不重新估计交叉谱。PNG/PDF 导出当前指标与样式，CSV 导出所有列及单位。相位和复数分量可为负，应按所选指标解释。方法、坐标前提与解释范围见[交叉谱说明](../methods/cross_spectrum.md)。

绘图数据、默认样式和刷新接口见[开发文档](../development/plotting.md)。
