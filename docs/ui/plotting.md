# 绘图交互与样式

## 界面层级

任务页、结果页和对话框使用同一套主题。浅色面板保持白底、深色文字；深色面板共用同一暗色底面。外层面板使用 1 个逻辑像素的边界，内部分组使用标题、细线和留白。控件边框、分区线和选中状态分别使用 `controlBorder`、`divider` 和 `selection` 主题角色。

界面正文字号为 10 pt，面板标题 10.5 pt，预览方法标题 11 pt，辅助信息 9 pt；使用点单位以适应系统缩放。绘图字号继续由绘图样式独立控制。输入区、上下预览及图形/步骤之间的分隔线保持较宽拖拽范围，悬停时加深。

## 结果目录

第一行用小型 ID 标签和较小的弱色时间，第二行用加粗文件名、状态圆点。选中时显示中性灰底色及清晰边框；长文件名从中部省略，完整路径仍在提示中。目录使用一个委托按需绘制，不为每条记录创建一组子窗口。ID、选择、打开、重命名、备注和删除使用独立的数据角色，不从显示字符串反解析。
目录底部的“全选”勾选全部筛选结果（含未加载的页），“取消勾选”仅清除筛选范围内的勾选，“清空全部”还包括筛选范围外的勾选。切换筛选条件与分页不改变已有勾选。

## 结果侧栏导航

顶端“绘图 / 导出 / 来源”占满侧栏宽度，为一级功能导航；绘图页内依次显示独立的“编辑对象”信息区与画布、坐标轴、曲线、热图类别。一级入口使用更大的点击区域和实色选中态，类别使用较紧凑的下划线导航。当前子图未就绪时不显示不可编辑的参数表，子图就绪后恢复参数区。

## 样式设置

| 页 | 内部分组 |
|---|---|
| 画布 | 标题与字体、背景、图例与方向 |
| 坐标轴 | 顶端固定 X/Y 选择器；坐标与范围、主轴与刻度、主网格、次网格、对侧轴 |
| 曲线 | 显示与图例、线条与连接、数据点标记、基线填充 |
| 热图（仅 Grid 输出显示） | 配色与色阶、数值到颜色、像素显示、显著性边界 |

X/Y 选择器固定在坐标轴页顶部，控制下方整页的编辑对象，滚动设置列表时保持可见。两轴参数分别保存。

组内保留全宽标签/输入行，使用加粗标题、标题下方细线及组间留白分区。坐标与范围、主轴与刻度等分组共用同一条左边界。过长说明自动换行。填充颜色跟随“填充至基线”启用，标记填充/边框跟随标记选项启用。中英文标签来自语言资源 JSON；边框与标题颜色来自同一主题模板。样式修改实时生效；数字和文本编辑合并短时间内的多次变化。

热图提供科学、灰度、热力、发散、光谱五种配色，可反转；颜色级数 2–1024，默认 256；可隐藏色标。线性/对数指**数值到颜色的映射**，与 X/Y 轴对数设置相互独立。对数使用正值范围，零/负值像素留空；当前没有正值时拒绝新启用对数并保留上一个有效样式。固定范围要求有限且递增，对数下限必须为正。自动范围随当前显示数据变化，控件同步显示实际范围；跨图比较请使用相同固定范围。清晰色块/平滑显示只改变视觉插值。

这些选项不修改 DataRef、数据库或 CSV。字体/配色变更不重新扫描原始矩阵；改变线性/对数映射时只重建有上限的显示栅格并保留视口。缩放后的数据刷新只更新颜色范围和提示，不覆盖正在输入的样式文本。
## 单轴操作

鼠标停留在 X/Y 轴上可查看操作提示：滚轮缩放该轴，沿轴拖动平移；在绘图区操作则同时影响两轴。数值框只有主动点击或通过 Tab 聚焦后才接受滚轮，关闭的下拉框不响应滚轮选择。

## 小波影响锥与显著性轮廓

CWT 的 `significance_ratio` 用于绘制局部显著性轮廓，`coi` 用于影响锥；两者来自独立输出。没有轮廓时，应检查比值是否越过阈值、该输出是否生成及显示是否启用，不能只凭影响锥判断显著性。

轮廓绘制 **功率 / 局部 95% AR1 阈值 = 1** 的边界，默认开启，黑线配一条细浅色衬线保证深色配色中的可见性；颜色、宽度及开关独立设置。影响锥在“曲线”页编辑。该边界表示局部名义检验，不控制整张热图的全局误报率。

绘制约定参考 Torrence–Compo 作者的 [wavetest.m](https://github.com/ct6502/wavelets/blob/main/wave_matlab/wavetest.m)：在显著性比值 1 处绘线，周期为对数显示时在 log2(period) 坐标上插值。实现使用 marching squares，并用双线性鞍点判别处理歧义格；没有复制作者代码。

没有轮廓可能有多种原因，面板会区分：

- 没有存储比值：计算时关闭了显著性，或红噪声估计不适用，应查看任务报告。旧记录若已保存该输出，直接重新打开即可；未保存的需要重新计算。
- 当前网格没有跨越 1：全部低于或全部高于都不会产生内部闭合边界；仅凭没有闭合轮廓无法判断显著性。
- 用户隐藏轮廓，或当前为降采样预览，小范围结构可能没被采样。
- 辅助网格坐标/尺寸不一致，或边界超过预算：停止绘制整个边界并提示原因。

结果页的热图强度概览保留块极值；显著性网格取对应坐标上的原样本，避免块最大值把显著区域扩张。任务页的即时预览则对功率与显著性网格使用相同的坐标抽样，见[即时预览](live_preview.md)。缩略预览不是完整精度等值线；结果页放大后会按视口重读，即时预览不会自动细化。导出按目标分辨率准备数据，仍受显示预算约束。最多 4,194,304 栅格样本和 100,000 条边界线段；超限时整个边界停止绘制，导出会明确失败，可缩小区域或关闭边界，不会静默输出残缺边界。

PNG 和 PDF 使用相同 PlotView、配色、映射与轮廓，PDF 轮廓保持矢量。CSV 总是原始数值。

## 坐标气泡

- 在曲线采样点/峰值附近单击，按屏幕距离选择最近的可见点（14 个逻辑像素内），同位置优先峰值标记。展示曲线名、X/Y 与单位；频谱正频率另显示倒数周期。读数对应采样点坐标。
- 热图显示当前格点实际采用的数据坐标和 Z 值，保留对数周期轴与交换轴转换。颜色对数映射不会把 Z 改成 log(Z)；被屏蔽的非正值不弹出气泡。开启像素平滑时仍读取格点值，不读取视觉插值产生的中间值。
- 每个子图最多一个气泡。点另一个位置更新，点空白、×、Esc、拖动、缩放、改变样式、切换/清空数据时关闭，避免留下过期坐标。
- 气泡为独立子控件，样本是数值快照；不保存可能被后台细化替换的曲线指针。它不会进入 PNG/PDF 图形导出。
- 抽稀数据会明确提示“预览采样值”。数据库图可放大请求更细的数据；即时预览受显示预算限制，读到的是当前保留的样本，不是对完整原始文件的任意点查询。
## 峰值参数与数据库一致性

最小突出度设为 0 时，数值有效但极小的局部起伏也会作为局部峰保留。在线性大范围图中，低突出度峰可能难以辨认，可缩小坐标范围或查看峰值表。

MTM 的 **相对突出度（%）**，注册描述默认 **0.1**；UI 和后台使用同一个声明。以完整功率谱的极差为尺度，有效阈值取以下三者最大值：

1. 用户设置的绝对最小突出度；
2. 相对百分比 / 100 × (最大功率 − 最小功率)；
3. 64 × double 机器精度 × 最大绝对功率（浮点舍入保护）。

峰必须高于两侧基底形成的等高线，突出度为峰顶与较高一侧基底的高度差；平顶只保留一个中心。检测同时受峰高、峰距、半突出度峰宽和搜索半径约束。

**相对阈值是幅度筛选，不是统计显著性检验。** 弱峰可能低于默认 0.1%，可调低或设为 0；设为 0 仍保留浮点舍入保护，绝对阈值也仍生效。该阈值只控制峰值筛选，不参与主功率谱和 AR1/SWA/FDR 的统计计算。

MTM 方法版本为 7；报告记录相对比例与有效阈值。绘图标记、峰值表和数据库频率索引使用同一份检测结果。已有数据库记录保留当时的方法版本与检测结果，重新运行才会产生新结果。
## 加载与刷新

数据、布局和可见状态就绪后合并刷新。平移和缩放按视口在后台读取数据，并遵守显示预算；单击读取坐标复用当前显示数据。

当前回归覆盖隐藏时设数据再显示、首次显示、尺寸改变、多个曲线和点击不重载。各平台还须检查首次显示、窗口缩放和大数据图形；自动化覆盖不能替代原生桌面验收。
