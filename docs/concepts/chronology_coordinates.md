# 深度、年龄与速率的共同约定

本页供年代模型、逐周期赋龄、COCO 和天文数据共同引用。具体任务的操作见[年代模型](../methods/chronology_usage.md)、[COCO](../methods/coco_usage.md)和[天文曲线](../methods/astronomy_usage.md)。

<a id="coordinates"></a>
## 先确认 X 代表什么

深度、年龄和频率是不同的坐标。给坐标改名或改单位文字，不会把深度转换成年龄。年代模型需要深度—年龄关系；COCO 在候选沉积速率下比较频谱，不直接转换整条序列。

本组深度任务要求 X 严格递增。重复值、倒序或非有限值应先核查原始记录，再决定是否整理；程序不会替用户修复地层关系。深度递增而年龄递减的控制表也不符合当前年龄模型约定。

<a id="units"></a>
## 单位换算与深度基准

深度参数可选 m、dm、cm、mm、ft、km；年龄可选 yr、ka、Ma。ka 为千年，Ma 为百万年。核对输入单位、模型表单位和目标输出单位，不能只看数值大小猜测。

输入已有非空单位时须与所选参数相符；没有单位时，程序按显式参数解释并提示。mcd、rmcd 可按米的长度尺度处理，但程序不转换钻孔拼接深度或修订深度基准。同为“米”的两份数据仍可能需要先对齐深度基准。

COCO 的候选速率固定用 cm/ka，目标周期用 ka，频率用 1/ka。例：深度间隔 0.02 m、速率 2 cm/ka 对应时间间隔 1 ka。这是单位换算示例，不是推荐速率。

<a id="epoch"></a>
## 年代基准不会自动换算数值

年龄模型中的“未声明／BP（1950）／2000 年之前／相对年龄”用于记录年龄含义，改变选项不会平移数值，也不会校准放射性碳年龄。首年龄、控制表及比较资料须由用户统一基准。

内置天文曲线使用 J2000 之前的 ka，向过去为正。对同一个时刻，在本程序使用的年份基准约定下，J2000 年龄 = BP1950 年龄 + 0.05 ka。这个零点差不能代替放射性碳校准、历法转换或地质年龄模型。

“首年龄”属于实际的第一个深度或第一个周期标记，不一定属于深度 0；相对年龄 0 也不意味着现代。

<a id="coverage"></a>
## 控制范围、边界与不确定性

控制点之间采用分段线性年龄插值。“应用年龄模型”默认拒绝控制范围之外的输入，不会自动裁剪。可以先裁剪输入，或在有依据时显式启用端部线性外推；外推沿首尾控制区间延长，并不增加年龄证据。

当前模型不自动估计年龄置信区间、不传播控制点误差，也不推断缺失周期、沉积间断或侵蚀。只有正速率和递增控制点的模型不能表达所有地层过程。

<a id="sampling"></a>
## 换年龄轴后还要检查采样

应用年龄模型保留原始 Y 和样本数，只替换 X；不会自动生成等时间间隔网格。等深度采样经变速率模型转换后通常成为不等时间采样。

下一步算法若要求等间隔输入，应先检查新年龄轴，再按研究目的决定重采样；插值不增加原始信息。参见[采样与重采样](sampling.md)。比较不同记录时，还应检查相同年龄范围内的采样密度与控制点覆盖。

<a id="files"></a>
## 外部模型文件与保存的结果

“应用年龄模型”的控制表和可选 PT 轨道表都作为文件参数读取。运行会记录实际使用的内容信息；已经保存的结果不会因外部文件后来改变而自动改写。

重新运行需要当前文件可读。外部文件内容变更后请主动重新计算，不能把仍显示的旧预览当作已更新。批量计算期间尽量保持文件稳定；单次节点执行的内容快照不等于整个批次使用同一份冻结文件。
