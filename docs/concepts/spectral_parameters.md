# 窗口、FFT 与频谱显示

[方法说明](../methods/README.md) · [功率谱任务操作](../methods/power_spectra.md) · [English](spectral_parameters_en.md)

本页解释频谱任务共用的概念。各任务的默认值、允许范围和具体换算仍由任务说明与参数参考给出。

<a id="windows"></a>
## 三种“窗口”不要混用

| 名称 | 作用 | 对应示例 |
| --- | --- | --- |
| 分析窗口或分段 | 选出一段观测，用它估计一次频谱 | Welch 的每段点数、演化谱的窗口点数 |
| 平滑邻域 | 利用相邻样本或频点估计平滑值 | 移动平均的点数窗口、谱背景的平滑范围 |
| 窗函数 | 对选出的分析段内各样本加权 | Hann、矩形窗；MTM 使用多组 DPSS 窗 |

同一个“窗口”字样不能说明单位或作用。例如，移动平均的窗口点数与 MTM 背景平滑的频带比例，不能互相套用。

分析窗口长度应与目标周期联系起来：窗口中只有一个或很少几个周期时，难以可靠地区分相近频率。加长窗口通常有利于区分邻近频率，但会混合更长区段的变化；缩短窗口有利于定位变化，却减少可用于估计每个谱的观测。没有对所有记录通用的最佳百分比。

若窗口含 L 个等间隔样本、间隔为 Δx，首末坐标之间的跨度是 `(L−1)×Δx`，FFT 频率刻度对应的时长为 `L×Δx`。两者相差一个采样间隔，并不矛盾。改变窗口长度会改变实际参与谱估计的数据；仅增加 FFT 点数没有这种作用。

<a id="overlap"></a>
## 步长、重叠和窗口数量

步长 S 表示两次分析的起点相隔多少个样本，实际移动距离为 `S×Δx`。窗口 L 点、重叠 O 点时，`S=L−O`；重叠率为 `100×O/L`。Welch 的重叠输入是点数，演化谱的重叠率输入是百分比，二者不能直接抄同一个数字。

步长只能是整数，因此输入的重叠率未必能精确达到。例如窗口 100 点，99.2% 对应理论步长 0.8 点；取整并至少移动 1 点后，实际重叠率为 99%。

对 N 点输入，仅使用完整窗口时，窗口数量为 `floor((N−L)/S)+1`，要求 `N≥L`。更小步长使窗口位置更密，也使相邻窗口共享更多样本；它不会增加独立观测，更不会补偿窗口过短造成的频率分辨限制。

不同任务如何换算目标窗口数、处理尾部和限制步长，见[演化谱设置](../methods/power_spectra.md#evolution-settings)。实际重叠率应以计算报告为准。

<a id="taper-trend"></a>
## 去趋势与窗函数

去均值减去分析段的平均值；线性去趋势减去该段拟合的直线，包含截距和斜率。它们会改变参与频谱计算的序列，尤其影响低频部分。研究长期变化时应同时查看原始记录和去趋势设置，不能把低频减弱一概当作数据没有长周期。

Hann 窗降低片段边缘的权重，通常可减轻有限截断产生的谱泄漏，但会改变谱峰宽度；矩形窗保留等权样本，对边界不连续更敏感。窗函数选择影响谱估计，不能与热图的颜色插值混为一谈。

MTM 的多个 DPSS 窗是同一分析段的不同加权方式，不是沿时间或深度移动的多个窗口。时间带宽参数 NW 控制该谱估计中的平滑与分辨折中；演化谱目标窗口数控制的是分析位置密度。

<a id="fft-padding"></a>
## FFT 点数与补零

FFT 点数至少应容纳实际分析段。以 NFFT 表示 FFT 点数，频率网格间隔为 `1/(NFFT×Δx)`。增加 NFFT 会在同一谱估计上给出更密的频率采样，不会增加观测时长，也不等于提高分开邻近周期的能力。

例如 100 点、间隔 0.2 ka 的窗口，FFT 取 100 点时网格间隔为 0.05 /ka；取 400 点时为 0.0125 /ka。观测窗口仍是同一批 100 点。窗口长度、窗函数、MTM 带宽和信噪比仍影响峰的宽度与可分辨程度，不能只看频率网格有多密。

“FFT 点数 = 0”不是通用的固定长度：整段 FFT 使用整条输入的点数，Welch 使用每段点数，演化谱使用每个分析窗口的点数。它不表示统一补到下一个 2 的幂。

对已截取分析段补零，与在整条记录两端补造样本后再滑窗，是不同操作。这里涉及的四个功率谱任务只使用完整分析段，不靠两端补零增加分析位置。

<a id="frequency"></a>
## 频率、周期与频率上限

频率单位为 X 单位的倒数。例如 X 为 ka，0.01 /ka 对应周期 100 ka；X 为 m，则对应空间波长 100 m。深度域的频率不能直接当作时间周期，需有明确的深度—时间关系。零频率不对应有限周期。

等间隔输入的奈奎斯特频率为 `1/(2×Δx)`。补零不改变这个上限。有限 FFT 网格的最高输出频点未必恰好等于奈奎斯特频率，尤其当 NFFT 为奇数时。

演化谱的频率上限裁剪实际输出热图和平均谱；它不是只把图像缩放到某个范围。缩小上限可减少输出网格，但不会缩短每个窗口的 FFT，也不会把完整频段内的归一化改成对可见频段重新归一化。

<a id="power-units"></a>
## PSD、功率与振幅

FFT、Welch 和未逐窗归一化的演化谱输出单边功率谱密度（PSD）。若 X 单位为 ka、Y 单位为 u，PSD 单位为 `u²·ka`，频率单位为 `/ka`。任一输入单位缺失时，程序不会猜测完整的 PSD 单位。

PSD 的峰高度不是原信号的振幅；频率网格、窗函数和谱峰宽度都会影响峰高。对 PSD 在频率上积分才得到对应的平方量；去趋势和加窗会影响它与原始记录方差的关系。比较不同记录时，应先统一输入单位、采样基准及谱估计设置。

<a id="normalization"></a>
## 逐窗归一化改变保存的功率

演化谱关闭逐窗归一化时保留 PSD。开启后，各窗口除以自身完整单边频谱的最大功率，结果为无量纲相对功率；全零窗口仍为零。分母在频率裁剪之前确定，所以裁剪后的可见频带最大值可能小于 1。

它便于比较谱形和峰的位置，但去除了窗口之间的绝对强弱差异。强、弱甚至主要为噪声的窗口，都可能出现相同亮度的相对峰；亮色不是显著性证据。热图数值、CSV 和窗口平均谱都会随该计算选项改变，需要重新计算才能得到另一种输出。

窗口平均谱对各窗口的输出功率取算术平均。归一化开启时，它平均的是各窗相对功率，不是“先平均 PSD，再归一化”；它也不等于整段序列直接计算的频谱。

<a id="display"></a>
## 显示设置改变图像，不改计算值

| 设置 | 作用 | 保存的功率与数值导出 |
| --- | --- | --- |
| 功率平方根显示（旧称“振幅”） | 对非负功率取平方根；归一化后显示相对振幅，否则为 PSD 平方根 | 保持原功率，探针和窗口平均谱也保持功率 |
| 对数颜色映射 | 改变正值到颜色的映射；零或负值像素留空 | 不变，不等同于对输入 Y 做对数变换 |
| 平滑显示 | 在绘制像素时插值，使色块边界连续 | 不变，不新增计算频点或窗口 |
| 色标范围和配色 | 改变同一个值显示成什么颜色 | 不变；不同图比较需统一显示量、映射和色标范围 |

PSD 的平方根仍不是原信号振幅，其单位是 PSD 单位的平方根。图片导出保存当前视觉效果，CSV 则输出计算数值，因此不必与当前色标数字逐项相同。

图像更连续，可能来自更密的滑窗、更密的频率网格、逐窗归一化、平方根／对数映射或像素插值；这些原因的含义不同。建议先比较数值、坐标与单位，再统一显示设置，最后比较图像。

更换软件进行对照时，还应核对实际整数窗口和步长、去趋势、窗函数、是否补边界、频段及归一化基准。仅看到相同的“99.2%”或相似配色，不足以说明设置相同。
