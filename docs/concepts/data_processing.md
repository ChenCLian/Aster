# 数据处理的作用与参数

[方法说明](../methods/README.md) · [English](data_processing_en.md)

先明确希望改变什么，再选择处理方法。平滑、去趋势、标准化和异常值处理解决的是不同问题，不能只凭曲线变得平顺判断处理是否合适。

<a id="effects"></a>
## 数值处理与图像显示

本页涉及的任务生成新的输出序列，不覆盖原始文件。下游接收到的是所选输出端口的数据；调整配色或显示插值不会产生同样的数值改变。

| 操作 | 改变什么 | 使用时需保留的判断 |
| --- | --- | --- |
| 平滑 | 用邻域信息改变 Y | 可能压低真实峰值、合并短周期变化 |
| 去均值／去趋势 | 移除常量基线或拟合背景 | 长期变化也可能是研究信号 |
| 标准化 | 将 Y 换算为距均值多少个标准差 | 失去原单位下的绝对幅度比较 |
| 非线性变换 | 改变幅度比与分布 | 后续频谱描述的是变换后的序列 |
| 异常值处理 | 标记、排除或替换选中的点 | 被识别的极值不一定是错误 |
| 滤波 | 按频率改变成分权重 | 保留的频带不等于已证实的周期来源 |

没有固定的“全套预处理”适合所有数据。保留原始分支，记录每一步参数并比较处理前后；尽量只做研究目标需要的操作。

<a id="neighborhoods"></a>
## 邻域点数、比例与物理跨度

移动平均、SG 和 Hampel 的窗口按样本点数定义；LOWESS 用输入点数的比例确定邻域规模，并按 X 距离加权。它们都不是固定的年数或米数。

等间隔数据的 W 点邻域首末跨度为 `(W−1)×Δx`。不等间隔数据在不同位置的邻域跨度可能差很多；大的间隔不会自动把处理分成两段。若不能跨越地层缺失或采样断口，应先分段处理。与频谱分析窗、窗函数的区别见[窗口定义](spectral_parameters.md#windows)。

窗口越大通常越平滑，但会混合更长区段。窗口小也不代表更真实：它可能追随噪声、把趋势一同留在残差里，或使异常点判断不稳定。应对照目标变化尺度和邻域内实际样本分布。

<a id="boundaries"></a>
## 端点与缺口

不同算法对端点有不同约定：移动平均缩短邻域，SG 用首尾完整窗口拟合，LOWESS 的邻域在边缘不对称；滤波可能采用延拓或补零。数值仍然输出不代表端点和中部同样可靠。

这些任务不会识别地质间断，也不会自动补回排除的点。排除点可能破坏等间隔条件；后续任务要求等间隔时，先[检查采样](../methods/preprocessing.md#inspection)，再决定分段还是显式重采样。插值跨过缺口的含义需单独判断，不能以“让软件运行”为唯一依据。

<a id="units"></a>
## 单位与幅度比较

平滑、去均值、去趋势、带通、高低通和 Hilbert 包络保留 Y 单位。Z-score 和 `ln/log10/asinh/tanh` 数值变换输出无量纲值，单位标为 `1`。滤波响应的纵轴是无量纲幅值增益，横轴为频率，不能作为时间／深度曲线直接接着处理。

缩放与平移保留原有单位标签，不自动推断单位换算。若用倍率把一种单位换成另一种，需同步核对输出标注和后续解释；把 ppm 数值乘 0.001 不会自动把标签改为另一单位。

频率单位是 X 单位的倒数。标准化后的功率不再表达原单位下的能量差异；PSD 与显示平方根见[频谱单位](spectral_parameters.md#power-units)。

<a id="centering"></a>
## 去均值、标准化与缩放

- **去均值**：`y′=y−mean(y)`。常量序列输出零；不移除斜率或非线性趋势，X 与 Y 单位不变。
- **标准化（Z-score）**：`z=(y−mean(y))/s`。默认样本标准差 `s=sqrt(sum((y−mean(y))²)/(N−1))`；总体模式分母为 N。默认模式至少需要 2 点，常量序列在两种模式下都不能标准化。
- **缩放与平移**：先乘倍率再加偏移，即 `y′=a×y+b`。负倍率翻转符号，零倍率得到常量；偏移量按缩放后的数值基准解释，X 不变。

例如 Y=[1,2,3]，去均值后为 [-1,0,1]；样本标准化也是 [-1,0,1]，总体标准化约为 [-1.224745,0,1.224745]。这是标准差约定的差别，不是计算错误。

Z-score 不会自动使分布变成正态，也不会把异常点删除；它和演化谱的[逐窗最大值归一化](spectral_parameters.md#normalization)不是同一操作。这三种逐值或整体幅度处理本身不要求 X 等间隔，也不替用户排序或重采样。

任务参数：[去均值](../reference/task_parameters.md#m-demean) · [标准化](../reference/task_parameters.md#m-standardize) · [缩放与平移](../reference/task_parameters.md#m-affine)。

<a id="decisions"></a>
## 自动识别与手动决定

异常值识别给出候选点，手动决定表达用户对具体点的处理意图，两者在记录中分别保存。“手动排除”优先于节点的自动操作，包括“仅标记”；“手动保留”则防止该点被自动排除或替换。返回自动识别会撤销该点的手动决定。

具体规则、输出及适用范围见[异常值处理](../methods/outliers_and_transforms.md#outliers)。不要把一次数据上的手动点位决定复制到另一条记录。
