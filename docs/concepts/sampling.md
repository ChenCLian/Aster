# 采样、重复坐标与插值

[文档索引](../README.md) · [任务操作说明](../methods/preprocessing.md) · [English](sampling_en.md)

本页解释多个任务共用的概念。具体默认值、允许范围和可选方法仍以各任务的参数参考为准。

<a id="coordinates"></a>
## 先确认 X 表示什么

X 可以是时间、年龄或深度，Y 是对应观测量。采样间隔是相邻两个 X 的差，单位与 X 相同；修改单位文字不会自动把年换算为千年，也不会转换坐标数值。

“严格递增”表示每个 X 都大于前一个 X；“等间隔”还要求相邻间距在允许的数值误差内一致。曲线看起来平滑，不代表采样位置等间隔。是否需要等间隔，取决于后续方法；例如 FFT 与演化 FFT 要求等间隔，而不能据此推断所有分析任务都要先重采样。

如果年龄沿记录顺序递减，排序会改变排列顺序。应先确认坐标方向和研究含义，再决定是否排序。排序保持 X/Y 配对，不会只移动 X 而把 Y 留在原位置。

<a id="duplicates"></a>
## 重复 X 与重复 Y 不同

重复 X 指坐标数值完全相同。多个位置测到相同的 Y 不属于重复坐标；非常接近但不相等的 X 也不会自动合并。

| 处理方式 | 对同一个 X 的操作 | 选择前应确认 |
| --- | --- | --- |
| 取平均值 | 合并对应的 Y，保留一个 X | 这些记录是否确实可合并为同一位置的观测 |
| 保留首个 / 末个 Y | 按当前节点接收到的原始输入顺序保留一个值 | 输入排列是否具有明确含义，而非偶然排序 |
| 报错 | 遇到重复坐标就停止 | 希望先核对来源，再决定如何处理重复记录 |

例如输入 `(X,Y)=(2,20),(1,10),(1,14)`：排序并平均后为 `(1,12),(2,20)`；保留首个或末个时，X=1 对应的 Y 分别为 10 或 14。

“保留首个”不等于保留最小 Y，“保留末个”也不等于保留最大 Y。这里的输入顺序指到达当前节点时的顺序，上游操作可能已经改变过它。

<a id="spacing"></a>
## 采样间隔与网格密度

重采样先确定新的 X 网格，再用插值求这些位置的 Y。间隔越小，输出点数通常越多；它增加的是估计位置，不是独立观测。

- **不重采样**：保留整理后的采样位置。用于“整理与重采样”任务时，排序和重复 X 处理仍会执行。
- **均值 / 中位数**：根据整理后相邻间距确定一个代表间隔。中位数相对不易受少数大间隔影响，但不保证适合所有研究目的。
- **最小值**：采用最密的间隔；一个非常近的点对可能导致输出规模明显增大。
- **最大值**：采用最疏的间隔；输出可能难以保留较短尺度的变化。
- **指定间隔**：按明确的 X 单位输入数值，便于复现或满足后续方法的采样要求。

例如 X 以 ka 表示，间隔 0.1 就是 0.1 ka；若 X 实际仍以年记录，仅把单位改成 ka，间隔及后续频率解释都会出错。

较粗的重采样不是自动的抗混叠处理。“整理与重采样”不会先添加低通滤波；需要降采样时，应结合目标周期及输入中的高频变化决定是否先滤波。较细的插值也不能恢复原始采样未记录的高频信息。

<a id="interpolation"></a>
## 插值方法改变什么

| 方法 | 基本含义 | 使用时关注 |
| --- | --- | --- |
| 线性 | 用相邻点之间的直线估计 Y | 变化方式直观，但斜率在样本位置可能不连续 |
| 自然三次样条 | 用相连的三次多项式构成光滑曲线，端点二阶导数为零 | 光滑不等于更接近真实信号；局部可能超出已有值范围 |
| Akima | 根据局部斜率构造分段三次插值 | 仍是插值估计，不保证单调，也不替代异常值处理 |

选择方法时，比较插值后的曲线是否产生不合理的局部形态，特别是峰值、端点和长空缺附近。方法的最少样本要求、输出端点及是否外推由具体任务决定，不能把一种任务的边界规则套用到全部任务。

<a id="gaps"></a>
## 大间隔提示与记录空缺

较大的相邻间隔可能来自不均匀采样、删点、漏录或真实记录空缺。程序的间隔标记用于定位需要检查的位置，不能单独判定沉积间断，也不会自动分段、修复年龄模型或补齐缺失过程。

插值可以在空缺两侧之间生成数值，但这些数值不等于空缺期间的真实观测。“整理与重采样”没有自动跨间隔禁止规则；若不应跨越某段空缺，应先根据研究背景划分连续区段，分别分析。仅删除区间中间的点，不能阻止后续插值再次跨过两侧端点。

如果输入还存在逆序，先看排序和重复坐标问题，再解释间隔分布。检查任务按收到的原始相邻顺序计算间隔，排序后再次检查可能得到不同结果。

<a id="limits"></a>
## 三种“数量限制”要分清

| 层次 | 含义 | 导出是否能获得更多内容 |
| --- | --- | --- |
| 计算输入限制 | 决定任务是否接受这份输入；超出时任务会报错 | 导出不能绕过计算限制 |
| 任务输出明细上限 | 任务已经检查完整输入，但只保留有限行明细 | 导出该表仍只有已保留的明细 |
| 预览显示预算 | 为快速显示，对已有输出作缩略 | 正式结果的数值导出可读取实际保存的输出，但不会恢复上一层未保留的明细 |

采样检查中的具体上限和报告字段见[检查输出说明](../methods/preprocessing.md#inspection-output)；预览曲线、热图和表格的显示预算见[即时预览](../ui/live_preview.md#display-limits)。
