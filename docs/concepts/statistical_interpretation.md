# 频谱结果与统计解释

<a id="outputs"></a>
## 先确认数值表示什么

| 输出 | 可回答的问题 | 不能直接当作 |
| --- | --- | --- |
| FFT／Welch／MTM 功率谱密度 | 变化分布在哪些频率附近 | 原信号振幅或周期存在概率 |
| Lomb–Scargle 归一化功率 | 正弦、余弦加截距的拟合改善程度 | PSD、p 值或误警概率 |
| MTM 峰表 | 哪些局部峰满足几何筛选条件 | 已确认的天文周期清单 |
| 平方相干度 | 两条记录在当前估计条件下的频率相关结构 | 显著性概率、因果关系 |
| 小波功率图 | 不同位置与周期上的功率变化 | 整张图已通过统计检验 |
| AR1 全局 p 值 | 单条输入与指定 AR1 噪声假设是否相容 | 每个峰为真实信号的概率 |

单位、归一化与颜色映射分别核对。图像的亮暗和光滑程度不能替代数值及统计定义。[频谱单位与显示](spectral_parameters.md#power-units)。

<a id="local-global"></a>
## 局部阈值与全局检验

局部阈值比较一个频率或时频位置；全局检验针对事先定义的一组位置或整个记录。搜索很多位置后挑出最高峰，会改变问题，不能把单点 95% 曲线解释成“整条记录误报概率为 5%”。

普通 MTM 的 AR1／SWA 曲线和 CWT 的名义 95% 比值采用近似背景与分布约定。背景由数据估计、有限长度、相邻频点相关、预处理和边界都会影响实际误报表现。阈值数值实现正确与实际误报率达标，是两种不同的验证。

AR1 全局检验使用独立模拟参考及预先限定的参数集合，范围是**单条传入序列的正内部 Fourier 频点**，不含 DC；偶数 N 时也不含奈奎斯特频点。它不控制跨文件、跨方法或反复试参后挑选结果的问题。拒绝噪声假设也不说明是哪一个峰、哪种物理过程造成了拒绝。

<a id="fdr"></a>
## FDR 与峰值检测

FDR 指假发现比例的期望，在满足相应程序假设时讨论；它不是每个被选中峰为假的概率，也不等同于某一个频点的误报概率。

AstroBatch 普通 MTM 沿用所记录参考实现的带宽相关修正和 SWA 背景约定，**拟合背景下尚未建立实际 FDR 控制保证**。已有校准条件出现过超出名义水平的假发现，因此 q=0.05 只能按该约定下的名义参考解释，不能宣称实际假发现率必为 5%。多条 q 曲线可能重合，不能仅凭重合判定程序错误。具体证据范围见[统计限制](../methods/statistical_limits.md)。

突出度、峰高、峰宽、峰距是几何筛选条件。放宽它们会增加候选峰，不会让统计证据更强。频点数定义的宽度／距离会随 FFT 补零改变对应物理频率宽度；比较软件或参数时要同时核对频率网格。

<a id="background"></a>
## 背景与预处理

AR1 是一种噪声假设，不是对所有地质记录背景的通用描述。趋势、间断、强非平稳变化、非 Gaussian 噪声或处理链都可能影响适用性。输入通过有限值和等间隔检查，并不意味着模型假设已成立。

外部节点中的选段、去趋势、平滑、滤波或重采样不会自动在 AR1 全局参考模拟里重放。只有该任务的内部 LOWESS 开关会对观测和参考序列执行同样处理。反复改频带、窗口或随机种子直到得到显著结果，不属于一次预先确定检验的解释范围。

默认关闭内部 LOWESS 并非要求所有记录都不去趋势；是否处理、如何处理应由研究对象决定。报告中应保留输入来源、预处理、方法版本、参数、频率范围和随机种子，以便复现。

<a id="unavailable"></a>
## 未通过、未评估与不可判定

| 情况 | 如何读取 |
| --- | --- |
| MTM 峰表判定 1／0／−1 | 通过／未通过／未评估或不可用；−1 不是“不显著” |
| MTM 背景拟合失败 | 主谱可能仍有效；缺少对应阈值端口，查看警告 |
| CWT 不提供显著性比值 | 可能关闭开关、输入无正方差，或估计的背景不满足条件；查看报告 |
| 交叉谱相干度或相位显示“—” | 数学上未定义，不能替换为有效的 0；CSV 留空 |
| AR1 `test_available=0` | 候选参数集合为空，本次不可判定；保守记录 p=1，不作为阴性证据 |
| 任务失败 | 输入、参数、资源或数值问题；不产生可解释的检验结论 |

“任务运行成功”和“拒绝噪声假设”是不同状态。未拒绝也不证明记录中没有周期；可能存在功效不足或模型与分析尺度不匹配。

<a id="coi"></a>
## 小波边界与影响锥

COI 是与母小波相关的边界衰减惯例。周期大于当前位置 COI 周期的区域受边界影响；程序保留这些数值，不自动遮蔽。它不是置信区间、统一误差上限或边界外必为假的判决。

图轴反向、对数坐标和配色不会改变上述判据。靠近两端的长周期亮区即使局部比值超过 1，也需要同时检查边界和背景假设。[小波输出](../methods/spectral_inference.md#wavelet)。
