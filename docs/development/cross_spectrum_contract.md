# Welch 交叉谱方法约定

适用版本：Aster 1.2.0-beta.5。Welch 交叉谱支持同工作区内跨普通支路、跨源根节点配对。接口边界见[计算与结果接口](cross_spectrum_interfaces.md)。

## 方法和输出

采用 Welch 分段平均，当前输出交叉谱密度的幅值、幅值平方相干性以及相位差，并保留复交叉谱实部、虚部和双方自功率谱供复查。暂不提供 MTM 交叉谱、交叉小波、自动领先/滞后时间换算或显著性判定。

SciPy 的 `csd` 将 A 的 FFT 共轭与 B 的 FFT 相乘；`coherence` 使用复交叉谱平均后的模平方除以双方自功率谱。相位和相干性必须来自同一组分段、窗函数和平均结果。[1][2]

设输入均匀采样间距为 Δx，fs=1/Δx；每段长度为 L，重叠点数为 O，步长为 L−O；共保留 K 个完整段。对每段分别执行选定的去趋势，再乘窗 w，并计算采用负指数约定的 FFT。令其为 Aᵣ(k)、Bᵣ(k)，则：

```text
P_AB(k) = s(k) Σ conj(Aᵣ(k)) Bᵣ(k) / (K fs Σ w²)
P_AA(k) = s(k) Σ |Aᵣ(k)|²          / (K fs Σ w²)
P_BB(k) = s(k) Σ |Bᵣ(k)|²          / (K fs Σ w²)
C²_AB(k) = |P_AB(k)|² / (P_AA(k) P_BB(k))
phase_AB(k) = atan2(Im(P_AB(k)), Re(P_AB(k)))
```

矩形窗的去均值/线性去趋势含截距项，去趋势后的精确样本和为零。[4] 实现将这种配置的 DC 复谱和自谱显式置零，相干度与相位标为未定义；不以通用幅值阈值清除弱频点。Hann 窗乘权后不保证和为零，不使用此规则。

s(k) 为实输入单边谱系数：DC 为 1；偶数 FFT 长度下 Nyquist 为 1；其他保留频点为 2。不能先对各段复交叉谱取绝对值，再平均。

交叉谱密度单位为“Y_A 单位 × Y_B 单位 × X 单位”；相干性无量纲，相位在界面中使用度并注明 A/B 约定。两个 Y 单位可以不同，但 X 坐标必须可比较。

交换 A/B 后，交叉谱取共轭，相干性保持不变，相位符号反转（按圆周角比较）。相位符号以数值横轴递增方向定义；Age BP 的递增方向不能直接解释为现实时间向前。

## 参数和输入边界

- 默认使用周期 Hann 窗，段长 256、重叠 128 点；修改段长不自动修改重叠点数。平均方式为算术平均。参考计算使用显式窗数组，避免软件默认值变化。[1][2]
- 与现有 Welch 任务保持参数术语一致；保留分段长度、重叠点数、FFT 点数和段内去趋势。FFT 点数为 0 时采用自动值，记录实际使用值。
- 以完整段计算，不对不足一段的尾部自动补样；FFT 补零仅改变频率网格，不能补充观测信息。
- 至少需要两个完整段。只有一段时，相干性在有非零谱功率的频点退化为 1；这种情况应拒绝提供常规相干性结果。[3]
- 报告实际完整段数和丢弃的尾部点数。重叠段不是等量的独立重复，不能直接用段数作为有效独立样本数。
- 默认要求双方已对齐到相同的均匀 X 网格。坐标不匹配时明确报错，不补零凑齐较短序列，不按行号强行对应，不寻找使相干性最大的偏移。共同区间和重采样由上游显式准备，操作与输出解释见[用户方法说明](../methods/cross_spectrum.md)。
- 原始序列中的非有限值、重复或倒序坐标，应经过明确的数据处理或返回诊断。不能仅对其中一方删行后继续按索引配对。

## 未定义值和结果表示

常数/零序列去均值后可能没有谱功率。当任一自功率谱分母无效时，相干性未定义；复交叉谱为零时，相位未定义。数值结果应携带有效性掩码，不能将这些值替换为“相干性为 0/1”或“相位为 0”。接入绘图和 CSV 时需保留无效状态并防止跨缺口连线。

相干性的理论范围为 [0,1]。仅能在经过验证的浮点误差范围内收敛到端点；明显越界应报数值错误。不能使用无条件截断掩盖归一化或配对错误。

当前 `SpectrumData.power` 要求非负，且已有数据验证要求有限值。带符号的相位、复数分量和无效掩码使用显式表结构及逐单元格有效性掩码，不能直接套用功率字段。

## 数值验收

独立参考使用 SciPy `csd`、`welch` 和 `coherence`，固定输入、窗数组、段长、重叠、FFT 点数、去趋势和密度归一化；记录执行时的 SciPy/NumPy 版本。需要核对复数实部和虚部，不能只检查图形外观。

至少覆盖：

1. 同相、反相、已知相位偏移和有噪声的共同周期。
2. 独立噪声及共享信号加独立噪声；不得预期有限样本的相干性严格为零。
3. A/B 交换、幅度缩放、不同 Y 单位、奇偶 FFT 长度及补零。
4. 零序列、常数、短记录、无完整段、只有一段以及不匹配的坐标。
5. 极端数值幅度下的有限性和诊断。
6. 相同配置在预览、完整执行、数据库重载和 CSV 中的一致性。

正式显著性检验需另行验证零假设、有效自由度和多频率比较；现有单序列 MTM 的 AR1/SWA 阈值不能直接用于交叉谱。
