# Aster 1.3.0 开发记录

## 1.3.0-beta.20

- 检查自动参数、单条覆盖、批量作用范围、配对、撤销重做与保存重开；未发现新的参数串用问题。
- 删除两份已完成的阶段计划，将有效约定整合到文档维护与更新模块说明，修正现行指南的阶段性措辞。
- 未修改应用代码、算法、默认参数或数据库格式。平台验收状态见各版本检查记录。

## 1.3.0-beta.19

- 修复更新取消与立即重试的请求状态，补齐同版本更新信息附件的来源回退。
- 强化发布草稿状态与通道检查、并发控制及最终包失败报告；详见[发布说明](../history/releases/1.3.0-beta.19/RELEASE_NOTES.md)。

## 1.3.0-beta.16–beta.18

- 实现轻量更新窗口、官方 HTTPS 与 SHA-256 完整包下载、新目录解压、四平台 Actions 草稿准备及可选 Gitee 镜像。现行契约见[更新模块](updates.md)。

## 1.3.0-beta.12

- 删除输入前提交待保存参数，防止失效草稿阻塞编辑与撤销；配对管理同样在草稿提交后打开，避免立即失效关闭。
- 同名内置／复用输入按数据 ID 保持当前选择。
- 更换帮助搜索关键词立即清除旧结果；首次索引期间的回车请求在结果就绪后执行，查询或导航改变则取消。
- 五处问题均有修复前失败复现及定向回归，数值算法和默认值未改。


## 1.3.0-beta.11

- 批量设置保留每个现有输入的有效逐点决定，包括恢复时存于基础参数中的决定；新输入不继承逐点决定。
- 批量操作校验当前来源归属，拒绝已删除、空或跨流程的来源。
- 新增自动参数、同名重排、分支隔离、冻结请求、短输入失败隔离、配对保存重开及批量撤销重做的定向回归。
- 本版不变更数值算法、默认参数或数据库格式。


## 1.3.0-beta.10

- 帮助窗口接入五类多级可折叠目录，章节及任务参数直接定位。
- 新增全部内置帮助的章节全文搜索；页内查找独立提供计数、前后匹配和快捷键。
- 返回／前进保留阅读位置，增加目录路径提示、中英文去重与未译资料标记。
- 同步用户手册、维护说明与验证记录；本批不改计算算法、默认参数、数据库或既有结果。


## 1.3.0-beta.9

新建演化 FFT 默认采用原预设配置，按每条数据的实际上游输入解析自动规则。参数面板提供恢复默认入口，批量应用仍限定当前流程的本节点，保留逐点决定；兼容旧固定点数缺少模式字段的参数记录。预览失败的主要原因和建议移至图像区，采用大字号、纯文本换行及长内容滚动。相关中英文说明和生成参考同步。验证及平台限制见[当前验证](../validation_current.md)。帮助窗口多级目录与全局搜索为下一批。

## 1.3.0-beta.3 至 beta.8

分批完成 A/C 文档归类与内容精修：采样、预处理、频谱、统计、年代模型、天文数据、数据源与日常操作。全部 56 项注册任务提供中英文长文入口；公共参数集中维护。Qt 帮助窗口导航改造仍单独待办；历史具体检查见[beta.8 记录](../validation_results/1.3.0-beta.8/checks.json)。

## 1.3.0-beta.2

演化 FFT 预设采用中性名称，并以目标 500 窗口替代固定 99.2% 重叠率。FFT／MTM 共用新的目标窗口数模式，按当前节点实际输入计算整数步长，保持数量上限与完整窗口约定。目标过少导致窗口间隙时明确报错并提示最小数量；旧点数／重叠率模式不变。预览提供实际参数摘要和悬停详情，输入、参数变化时清除旧摘要。同步中英文任务与参数帮助、选参例子和预设来源说明。

纳入 beta.1 后的画布边框／滚动条交汇处修复，以及唯一兼容输入和下游连接时插入／替换免弹窗、撤销／重做与状态栏反馈。帮助窗口的视觉重设计和其他体验建议尚未实施。本版验证范围见[当前验证](../validation_current.md)，不将历史 Windows 返回结果算作 beta.2 原生验收。

## 1.3.0-beta.1

完成 beta 收尾：同步当前文档与 Windows 返回验收记录；版本工具识别并更新带 v 前缀的标签，新增漏检回归；Actions 增加依赖安装前的版本检查；macOS/Linux 包探测清除开发机动态库和 Qt 插件路径。本版不修改应用算法或数据库格式。反复销毁并重建整窗的内存增长按维护决定暂缓追查，不作为本次 beta 阻塞项。原生打包与干净主机验收仍按平台执行。

## 1.3.0-alpha.6 及后续 alpha 检查


本次新增窗口跨度百分比、窗口重叠率、FFT 倍数与可编辑 LAH 风格预设；热图振幅变换只作用于绘图。输入列表多选直接批量修改读取设置，校验失败保留原配置，排队操作保持选择与数据身份；右侧节点参数保持独立。节点批量区显示文件名并独立分隔，输入列表新增本地快捷操作帮助。


新增按数据／配对的节点参数差异表，批量应用只作用于当前节点。执行计划冻结实际参数，数据库记录保存实际运行设置；输入数据数组仍以不可变引用共享。含差异表的工作流采用 schema 2；无差异表仍使用 schema 1，读取端兼容两者。

新增异常值识别与处理、数值变换任务；逐点决定使用输入内容标识及位置保存，禁止跨数据批量复制。源文件不被改写。

改进自动导入设置、数据树间移动、多个坐标气泡、真实采样点吸附与 MTM 峰值三态判定。峰值表模式通过 `peak_schema_version=2` 标识；MTM 估计器与参数版本不变。

数据移动后自动定位目标树并保持所选数据；撤销／重做跟随数据恢复对应树。打开移动窗口前提交待应用的节点参数，异常值图例使用界面语言中的输出名称。

绘图区尺寸变化时复用气泡文字控件并重新布局，避免导出提示、窗口调整或输出区收放后坐标正文被压缩。新增读数实际可见性回归，覆盖尺寸变化及重复点击同一采样点。

当前验证范围见 [验证记录](../validation_current.md)。

本次新增结果文件名 CSV 导出，逐行读取当前筛选的全部结果，不加载数值 BLOB。导出通过后台服务和 QSaveFile 完整提交。撤销/重做历史最多 100 步，并受 64 MiB 元数据保守估算预算约束；共享数值数组不重复复制，预算不是整个进程内存的硬上限。历史超预算时从最旧状态开始淘汰。删除节点仍支持撤销，因此历史保留期间的引用不视为泄漏。

修复：异步导入校验同时检查数据 UUID，删除后重新导入同一路径不会接受旧请求；传输取消标记在任务实际开始时绑定，新增排队任务不覆盖当前任务的取消标记；结果目录服务先登记队列忙状态再通知外部，防止回调重入启动并行线程，完成回调使用对象存活检查。新增对应回归。

ASan 检出逐点决定调用独立参数编辑时的节点 ID 悬空引用；参数编辑入口改为按值接收 ID，避免工作流提交替换节点后再读取旧节点。新增最小回归，并重新运行完整功能与内存检测测试。

UBSan 又检出样式编辑器和文件读取设置编辑器关闭失焦时访问已析构对象；两处析构函数提前停止定时器、断开子控件回调，新增带待提交输入的关闭测试。
