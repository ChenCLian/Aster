# Aster 1.3.0 开发记录

## 1.3.0-beta.1

完成 beta 收尾：同步当前文档与 Windows 返回验收记录；版本工具识别并更新带 v 前缀的标签，新增漏检回归；Actions 增加依赖安装前的版本检查；macOS/Linux 包探测清除开发机动态库和 Qt 插件路径。本轮不修改应用算法或数据库格式。反复销毁并重建整窗的内存增长按维护决定暂缓追查，不作为本次 beta 阻塞项。原生打包与干净主机验收仍按平台执行。

## 1.3.0-alpha.6 及后续 alpha 检查


本次新增窗口跨度百分比、窗口重叠率、FFT 倍数与可编辑 LAH 风格预设；热图振幅变换只作用于绘图。输入列表多选直接批量修改读取设置，校验失败保留原配置，排队操作保持选择与数据身份；右侧节点参数保持独立。节点批量区显示文件名并独立分隔，输入列表新增本地快捷操作帮助。


新增按数据／配对的节点参数差异表，批量应用只作用于当前节点。执行计划冻结实际参数，数据库记录保存实际运行设置；输入数据数组仍以不可变引用共享。含差异表的工作流采用 schema 2；无差异表仍使用 schema 1，读取端兼容两者。

新增异常值识别与处理、数值变换任务；逐点决定使用输入内容标识及位置保存，禁止跨数据批量复制。源文件不被改写。

改进自动导入设置、数据树间移动、多个坐标气泡、真实采样点吸附与 MTM 峰值三态判定。峰值表模式通过 `peak_schema_version=2` 标识；MTM 估计器与参数版本不变。

数据移动后自动定位目标树并保持所选数据；撤销／重做跟随数据恢复对应树。打开移动窗口前提交待应用的节点参数，异常值图例使用界面语言中的输出名称。

绘图区尺寸变化时复用气泡文字控件并重新布局，避免导出提示、窗口调整或输出区收放后坐标正文被压缩。新增读数实际可见性回归，覆盖尺寸变化及重复点击同一采样点。

当前验证范围见 [验证记录](../validation_current.md)。

本次新增结果文件名 CSV 导出，逐行读取当前筛选的全部结果，不加载数值 BLOB。导出通过后台服务和 QSaveFile 完整提交。撤销/重做历史最多 100 步，并受 64 MiB 元数据保守估算预算约束；共享数值数组不重复复制，预算不是整个进程内存的硬上限。历史超预算时从最旧状态开始淘汰。删除节点仍支持撤销，因此历史保留期间的引用不视为泄漏。

本轮 Debug：异步导入校验同时检查数据 UUID，删除后重新导入同一路径不会接受旧请求；传输取消标记在任务实际开始时绑定，新增排队任务不覆盖当前任务的取消标记；结果目录服务先登记队列忙状态再通知外部，防止回调重入启动并行线程，完成回调使用对象存活检查。新增对应回归。

ASan 检出逐点决定调用独立参数编辑时的节点 ID 悬空引用；参数编辑入口改为按值接收 ID，避免工作流提交替换节点后再读取旧节点。新增最小回归，并重新运行完整功能与内存检测测试。

UBSan 又检出样式编辑器和文件读取设置编辑器关闭失焦时访问已析构对象；两处析构函数提前停止定时器、断开子控件回调，新增带待提交输入的关闭测试。
