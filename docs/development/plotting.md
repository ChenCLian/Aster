# 绘图数据、样式与刷新接口

适用版本：Aster 1.2.0-beta.7。用户操作见[绘图说明](../ui/plotting.md)。

## 界面层级

任务页、结果页和对话框使用同一套主题。浅色面板保持白底、深色文字；深色面板共用同一暗色底面。外层面板使用 1 个逻辑像素的边界，内部分组使用标题、细线和留白。控件边框、分区线和选中状态分别使用 `controlBorder`、`divider` 和 `selection` 主题角色。

界面正文字号为 10 pt，面板标题 10.5 pt，预览方法标题 11 pt，辅助信息 9 pt；使用点单位以适应系统缩放。绘图字号继续由绘图样式独立控制。输入区、上下预览及图形/步骤之间的分隔线保持较宽拖拽范围，悬停时加深。

## 默认样式与存储边界

`plotPreset` 集中生成字体、配色、轴方向、曲线/图例等初始样式，按稳定输出端口、数据类型及科学坐标/报告语义识别频谱、小波与交叉谱；不从翻译后的标题或函数名称反解析。任务预览、结果页与 PNG/PDF 都经由 `PlotView` 使用该默认入口。用户覆盖在默认样式之后应用；切页与后台细化保留当前覆盖，恢复默认使用当前规则。

计算参数、单位、数值和来源继续由结果仓库保存。绘图配置只属于本次会话的图页/子图，不写入分析数据库，也不需要重算历史结果。图页关闭或应用退出后不提供样式恢复。

批量叠加先在后台读取并检查所有候选，成功后一次更新子图引用和显示；失败不移除已有图形或覆盖其样式。列表只读取输出元数据，不解码每项数值；非活动图页不保留数值缓冲区。

## 加载与刷新

`styleForReload()` 保留自动轴与手动视区的区别；`styleWithViewport()` 用于导出时固定当前视野。叠加重建后仅自动轴重新适应数据，手动轴继续保留范围。界面与导出默认标题共用 `defaultPlotTitle()`，不使用内部端口名作为默认展示名称。

数据、布局和可见状态就绪后合并刷新。旧读图完成时保留尚未发出的新视口请求；叠加失败或候选来源被移除后，原图也会按当前视口补读；“恢复默认”按恢复后的范围重新读取数据。平移和缩放按视口在后台读取数据，并遵守显示预算；单击读取坐标复用当前显示数据。

## 输出组合与显示数据

`plot_recipe.h` 以稳定方法 ID 和输出 ID 声明组合关系；`plotPreset` 根据稳定端口、类型及科学坐标/报告语义生成初始样式，用户覆盖最后应用。预览、默认投图、手动投图及 PNG/PDF 共用这些规则，不从翻译后的标题推断领域含义。

科学报告元数据及抽稀前坐标属性进入运行时绘图描述。计算参数、单位、数值和来源由结果仓库保存；绘图样式和布局不写入算法结果。非活动图页释放数值缓冲区，引用身份与手动样式保留在当前会话。

曲线和热图通过 `PlotDataLoader` / `plot_reader` 后台读取。`grid_sampling.h` 为功率和显著性比值选择同一批实际坐标样本；轴类型按完整坐标及科学语义确定，不从抽稀坐标猜测。自动色阶取完整输出范围，视口细化不重新估计色阶。字体、配色改变不重新扫描原始矩阵。

显著性边界使用 marching squares 及双线性鞍点判别；周期对数显示时在 log2(period) 坐标插值。栅格和边界线段均有预算，超限须明确失败，不能截断后导出残缺边界。PNG/PDF 共用 `PlotView`，PDF 轮廓保持矢量。

## 坐标读数

每个子图至多保留一个读数浮窗，内容是当前显示样本的数值快照，不保存可被后台细化替换的曲线指针。曲线命中按屏幕距离，14 个逻辑像素内选择最近的可见点，同位置优先峰值标记；热图读取当前格点，不读取颜色插值结果。视图、样式或数据变化使读数关闭；浮窗不进入图像导出。

## 布局与验收

图页的分割树、标题拖放及导出快照见[架构](../architecture.md#图页布局与导出)。界面回归的版本和环境见[验证入口](../validation_current.md)；自动化测试不代替原生桌面验收。

## 清空与空位初始化

`PlotView::clearByUser` 仅用于显式清空命令；加载和错误提示继续使用 `clear`。工作区接收 `clearedByUser` 后取消该子图的排队与在途读取、递增世代号，清除已提交/候选引用及样式，并同步标题、精度状态和编辑对象。布局节点及其身份保留，切换图页不重新加载已清空的数据。

空位初始化沿用批量叠加的加载与原子提交路径。绘图配方先确定主输出（热图先于影响锥、频谱先于峰值表），成功后采用该输出的默认样式；失败保留空位。加载中或保留已提交引用的失败子图不作为空位。数值计算及已有轴兼容性规则不变。
