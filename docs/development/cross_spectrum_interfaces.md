# 交叉谱：计算与结果接口

适用版本：Aster 1.2.0-beta.7。

Welch 交叉谱已接入同工作区配对界面、预览控制、正式运行、结果保存与绘图导出。基础数值证据保留在 alpha.2 的验证记录中；真实数据、桌面边界和规模检查按版本单独记录，不能代替 Windows/macOS 原生平台验收。

## 调用边界

| 接口 | 输入与职责 | 输出 |
| --- | --- | --- |
| `numeric::crossSpectrum` | 等长有限实数组、已验证采样间距、Welch 参数、取消与进度回调 | 复交叉谱、自谱、幅值平方相干性、相位及有效性掩码 |
| `CrossSpectrumTask` | A=`TaskInput.data`，B=`TaskInput.second`；再次校验描述符参数、数据、X 网格及声明单位 | `cross_spectrum` 表和计算报告 |
| `registerCrossSpectrum` | 为独立调用显式注册；生产注册表通过科学任务目录注册 | `pairedInput=true`、`catalogVisible=true` 的任务 |
| `BatchWorkflowExecutor` | 经过校验的冻结计划，按组调度实际选定的两份上游输出 | 完成回调中的数值结果；摘要和分组来源 |
| `crossSpectrumCurves` | 完整结果报告、表、所选指标列 | 分开的连续 `SeriesData` 路径；未定义频点和相位跳变处断开 |
| `crossSpectrumCsvData` | 完整结果和报告 | 带单位列标题及掩码的表，交给现有 `exportDataCsv` |
| 现有存储与导出 | `TableData` 可选逐单元格有效性掩码 | SQLite 载荷、完整/有限行数读取、预览和 CSV |

`makeScientificRegistry()` 注册该方法。含联合节点的根任务由 `WorkflowDocument::plan()` 生成批次计划，应用运行器分派至 `BatchWorkflowExecutor`；单文件执行器继续拒绝双输入节点。

## 参数与坐标

沿用现有 Welch 任务的参数标识：

| 标识 | 默认值 | 含义 |
| --- | --- | --- |
| `psd_window` | 256 | 每段样本数，最小 8 |
| `psd_overlap` | 128 | 相邻段重叠样本数，必须小于段长 |
| `psd_nfft` | 0 | 0 表示采用段长；显式值不得小于段长 |
| `psd_taper` | `hann` | 周期 Hann；也支持 `rectangular` |
| `psd_trend` | `mean` | 段内去均值；也支持 `linear` 和 `none` |

默认值是固定参数，修改段长不会隐式改写重叠点数。非法组合返回明确错误。至少需要两个完整段，不自动缩短段长，也不补齐不足长度的输入；尾部不足一段的样本数记入报告。

双方 X 必须严格递增、各自均匀、等长。X 名称和单位去除首尾空白后必须一致；名称检查可阻止明显不同年龄基准被误认为相同坐标，但不能证明任意用户标签背后的科学含义一致。比较坐标的绝对容差为双方较小采样间距的百万分之一，不随绝对时间原点放宽。已验证的 A 网格作为频率计算依据，接受容差内舍入差异不会重新采样。

不自动换算单位、截取共同区间、插值、平移或配准。不同 Y 名称和单位可以联合分析。频率单位为 `1/(X单位)`；交叉谱密度为 `YA单位 × YB单位 × X单位`；自谱为各自 `Y单位² × X单位`；相干性无量纲；相位为度。

## 数值含义

计算采用各段 `conj(FFT(A))*FFT(B)` 的复数算术平均，再求幅值、相干性与相位。默认窗为周期 Hann，密度归一化与单边频点系数遵循[实现约定](cross_spectrum_contract.md)。交换 A/B 会改变相位符号，不改变相干性。

相位以数值 X 递增方向定义；年龄轴递增不能直接解释为时间向前。相位不自动展开，也不自动换算领先/滞后时间。低相干性处相位即使数值有定义，也可能不稳定。当前不提供显著性判断、有效自由度估计、MTM 交叉谱或交叉小波。

输入先根据实际参与完整分段的样本分别缩放，以控制 FFT 及中间乘积范围；被丢弃的尾部不能改变估计结果。密度恢复使用指数分解，避免依赖 Windows 上并不存在的扩展 `long double` 范围。超出双精度表示范围的非零密度返回错误，不能静默变成零。相干性只允许在明确的浮点容差内收敛到 1；明显越界返回错误。

矩形窗且段内去均值或线性去趋势时，精确算术中的样本和为零；零频点因此显式设置为零自谱和零复交叉谱，相干度、相位标记为未定义。此规则不采用幅值阈值，不清除其他频点，也不用于 Hann 窗。方法版本为 2；版本 1 的已存数值仍可显示，旧参数快照不会被静默当作版本 2 重算。

## 结果表与未定义值

`cross_spectrum_schema=1` 对应以下固定列顺序；每列单位保存在报告的 `column_units` 中：

| 列 | 含义 | 未定义条件 |
| --- | --- | --- |
| `frequency` | 单边频率 | 不允许未定义 |
| `cross_magnitude` | 平均复交叉谱的模 | 零是合法结果 |
| `coherence` | 幅值平方相干性 | 任一自谱为零 |
| `phase_degrees` | `atan2(Im, Re)`，单位度 | 平均复交叉谱为零 |
| `cross_real` | 复交叉谱实部 | 允许负值 |
| `cross_imaginary` | 复交叉谱虚部 | 允许负值 |
| `auto_a` | A 的自功率谱密度 | 零是合法结果 |
| `auto_b` | B 的自功率谱密度 | 零是合法结果 |

`TableData.defined` 为空表示旧式的全有效表；否则必须与每行、每列完全同形，每个元素只能为 0 或 1。未定义单元格在存储层以 0 为规范占位值，读取时必须查掩码；该占位值没有数值含义。

- 表格显示未定义值为 `—`，保留正常的数值 0。
- 通过 `crossSpectrumCsvData` 导出时，CSV 标题保留每列单位，未定义单元格输出空字段，保留所在频率行及列位置。
- 有限行数数据库读取和预览裁剪同时裁剪掩码。
- 曲线与 CSV 适配器要求完整表及匹配的报告，拒绝已裁剪的表格预览数据。曲线入口应先按完整表生成路径，再进行图形抽稀。
- 曲线适配器按有效连续区段返回独立路径；相位跨 ±180° 时也分段。桌面绘图以 NaN 显示断点连接这些路径，不跨缺口连线；NaN 只存在于绘图缓冲区，不写入数值载荷。
- 报告保存未定义频点数量、实际段数、FFT 点数、尾部样本数、归一化、A/B 方向、双方轴单位和来自调度器的配对来源。

## 持久化兼容性

SQLite 表结构仍为版本 3。原 Series/Spectrum/Grid 以及不带掩码的 Table 继续输出完全相同的 v1 二进制载荷；新掩码表采用 v2 载荷，沿用 Table 类型标记，在每行数值之后保存每列一字节掩码。v2 仅允许 Table 类型。完整解码会校验掩码维度、取值、截断和尾随字节。

本版能读取旧载荷。旧版程序不能读取新掩码载荷，会返回不支持的编码错误，不能将其视为可双向兼容的结果格式。beta 测试建议使用独立数据库；操作手册和发布说明均列出这一边界。普通旧格式记录没有被自动转换。

## 资源与验证

当前固定上限：每方 1,000,000 个样本、FFT 长度 262,144、完整段数 20,000。估算工作量 `K × (2 × NFFT × ceil(log2(NFFT)) + 4 × L)` 上限为 10 亿；这不是实测耗时，也不随硬件性能变化。调度器把有效性掩码字节计入中间输出缓存预算。算法逐段累加，不保存整幅分段复谱；在输入扫描、FFT 之间、段之间及结果转换时响应取消。一次 FFT 调用不能在内部强制打断。

`aster_cross_spectrum_tests` 为交叉谱测试目标，纳入项目构建及统一回归脚本。参考数据由 NumPy 2.3.5、SciPy 1.17.0 的 `csd`、`welch`、`coherence` 生成，显式固定窗、分段、重叠、FFT、去趋势和密度参数，并以小规模直接 DFT 复核。生成脚本和数据位于 `cross_spectrum_tests/fixtures/`；SciPy/NumPy 不是应用运行依赖。

完整验证范围、环境和限制见 [cross_spectrum_checks.json](../validation_results/1.2.0-alpha.2/cross_spectrum_checks.json)。参考比较含 16 种组合；极弱交叉谱处相位数值敏感，不用相位误差来替代复数分量核对。另有已知相位、交换输入、常数、零值、数值范围、取消、配对调度、载荷往返、CSV、数据库预览和合并测试。

当前桌面接入约定见[联合分析开发说明](batch_joint_analysis.md)。真实数据验证包含 8 组公开 ODP 记录的 SciPy 参考核对、PT-ZB18a 非默认端口检查、保存失败重试、计算中取消和 4/64/128 配对规模测试。数值核对不替代实际使用条件评估；Windows/macOS 原生验收仍需完成。

真实数据准备方式及零频点比较例外见[参考数据说明](../../cross_spectrum_tests/fixtures/README.md)。数值回归、性能测量及未覆盖项分别见 [alpha.4 数值与交互记录](../validation_results/1.2.0-alpha.4/integration_checks.json) 和 [alpha.5 性能记录](../validation_results/1.2.0-alpha.5/performance_checks.json)。

## 输出连接选择

普通后续节点存在多个兼容输出时，`OutputPicker` 负责选择稳定端口键，不修改批次或 A/B 分组。列表过滤、预选和取消不编辑工作流，确认后仍通过 `WorkflowDocument::addChild` 校验并提交。主窗口先完成旧菜单的焦点恢复，再显示锚定来源节点的选择窗口；工作流、源数据和运行状态变化使待选窗口失效。显示边界使用 Qt 逻辑坐标下主窗口与当前屏幕可用区的交集，长列表滚动。

`popup_placement` 统一显式弹出的根菜单位置；级联子菜单和按钮菜单仍由 Qt 处理方向与屏幕边界。输出选择窗口只提交稳定端口选择，不自行执行算法或改写存储。界面验证见 [alpha.6 记录](../validation_results/1.2.0-alpha.6/popup_checks.json)。

## 编辑事务

`WorkflowEditState` 包含工作流定义、源选择与配对。`WorkflowDocument::beginEdit()` 创建候选，`prepareEdit()` 返回校验后的只读令牌，`commitEdit()` 统一发布。图结构校验沿用 `validateWorkflow`；绑定校验检查源节点类型、稳定数据身份、配对身份、上游端口与数量限制。当前入口不增加第二父边。

准备令牌绑定文档身份和递增修订号。其他编辑、撤销、重做或运行锁状态改变后，旧令牌失效。取消选择只需放弃候选，不触发提交。现有添加、参数、删除、导入设置及配对操作均走同一机制；后续结构编辑必须提交完整候选，不能先改画布再补绑定。

空源列表、空分组以及移除数据后留下的既有缺失引用允许保留为未完成草稿。新建引用必须存在；旧引用不会按文件名或位置自动替换。配对输出端口必须与输入类型兼容，配对结果再次分组仍不支持。编辑校验不展开全部运行任务；正式执行继续由 `prepareRuns`/`prepareBatch`/`prepareLinkedBatch` 验证运行就绪状态、展开任务数量及数据条件。

节点删除会清理当前状态中该子树的源绑定和分组；它们保存在同一撤销快照中。最多保留 100 次有效编辑，数值数据共享不可变引用。文件内容、已写入数据库的结果、界面缩放与选中状态不属于此历史。验证见 [alpha.7 编辑记录](../validation_results/1.2.0-alpha.7/edit_checks.json)。


## 普通节点结构编辑

`inspectNodeRewrite` 按方法声明筛选可用输入和下游输出，`prepareNodeRewrite` 要求完整映射并返回编辑令牌。`NodeEditDialog` 展示候选，确认后统一提交；画布连线按钮、节点右键菜单及任务拖放共用这一路径。新方法参数从默认值开始，替换不复用旧方法的参数对象。

替换保留目标 ID、布局及子树；插入保持旧节点及配对身份，按相邻逻辑格整体平移下游子树。节点数量、网格边界、位置冲突、端口类型及源绑定仍由完整校验约束。直接影响联合节点结构的改写入口暂时禁止；跨节点输入通过独立配对引用设置。验证见 [alpha.8 结构编辑记录](../validation_results/1.2.0-alpha.8/rewrite_checks.json)。

## 显式跨节点输入接口

| 接口 | 约定 |
| --- | --- |
| `BatchSeriesRef.node` | 可选来源节点 UUID；为空沿用联合节点的树父节点 |
| `BatchSources` | 源根节点到带稳定 UUID 的数据列表的映射 |
| `prepareLinkedBatch` | 校验同工作区的跨支路/跨根引用，生成普通生产者在前、联合消费者在后的冻结计划 |
| `linkedInputOrigins` | 只返回类型兼容的普通节点，排除联合节点及其后继 |
| `batchDependencySlice` | 提取指定节点与配对的实际依赖，供双输入预览使用 |
| `BatchJob.sourceRoot` | 事件与保存项的实际所属根节点；旧单根计划为空时沿用计划根节点 |

`WorkflowDocument::plan()` 按引用关系连接源根节点，不连接的普通任务保持原执行入口。同一关联批次内 UUID 不可重复；数据、配对与任务数限制按整个关联批次计。生产者可由多个配对共享，缓存按最后一个消费者完成后释放。

旧分组 JSON 保持格式 1；显式节点引用使用格式 2。跨节点执行清单为格式 2，补充源数据所属根节点和根节点列表；工作流 JSON 仍为格式 1，SQLite 仍为结构 3。保存的配对记录保留实际 A/B 上游记录 UUID、节点、端口和源根节点。删除上游记录不会伪造可解析的链接。

桌面选择器与配对编辑器使用这些接口；原有隐式父节点引用仍兼容，已有显式父节点引用在未更改选择时保留原表示。普通树结构、科学算法参数和数值定义未改变。接口集成证据见 [alpha.9 验证记录](../validation_results/1.2.0-alpha.9/linked_input_checks.json)，其中真实 Welch 任务核对预览、执行和保存是否使用同一对输入；独立数值基准仍见先前记录。

## 桌面来源与配对选择

`JointInputDialog` 使用 `linkedInputOrigins` 提供节点树，选择节点后才显示其数据与兼容输出。搜索不改变引用，确认返回节点 UUID、数据 UUID 和端口键。`PairingDialog` 在本地维护完整分组草稿，所有修改通过一次 `prepareEdit` / `commitEdit` 提交；取消不改变文档。文档修订、源选择变化或销毁会使窗口失效，运行锁在确认时再次检查。已有缺失引用可显示并修复，不能按同名数据自动接管。

两个窗口为非阻塞窗口模态对话框，按主窗口与屏幕可见交集限制尺寸。来源选择器在窄窗口中上下排列；配对行等高，A/B 列等宽，完整名称与来源在悬停提示中显示。按需创建的候选表避免大量行控件。

`WorkflowCanvas::setPreviewPair` 与预览面板共享当前配对身份。选中联合节点或其后继时，仅绘制当前组的 A/B 引用；切换普通路径时隐藏。联合节点的原树连接使用点线表示放置关系，不代表额外的计算输入。失效来源显示 A!/B!，有效引用的提示包含实际节点、数据与输出。多输出来源卡片跟随实际引用端口。

验证见 [alpha.10 桌面联合输入记录](../validation_results/1.2.0-alpha.10/linked_input_ui_checks.json)。科学算法、数值限额、分组与数据库格式见本文对应章节。
