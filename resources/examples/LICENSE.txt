Aster selects columns, omits only missing X/Y pairs, and preserves all other values and row order.
No new interpolation, age tuning, species correction or smoothing is applied.
ODP 846 values were already interpolated by the original authors; ODP 1143 values already include the authors' species corrections.
ODP 926B age outputs use the published optional La2004-adjusted chronology.
These older published age models should not be treated as independent evidence of orbital forcing.
